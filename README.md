# Конспекты курсов

Личный Obsidian-волт с конспектами университетских курсов: лекции и практика 18 предметов, сквозной глоссарий терминов, конспекты научных статей и книги, на которые курсы опираются

Заметки написаны по лекциям, видеозаписям, рукописным тетрадям и учебникам. Часть курсов оцифрована с помощью ИИ и затем проверена вручную: формулы, доказательства и атрибуция лектору

## Что внутри

- **Курсы** — папки `01. Математический анализ` … `18. Численные методы`; в каждой заметки по темам, индексы тем и вложения
- **`00. Термины`** — сквозные термины и аббревиатуры, по заметке на понятие
- **`Статьи`** — конспекты научных статей, PDF лежат во вложениях
- **`Книги`** — учебники, на которые ссылаются конспекты
- **`Scripts`** — генераторы рисунков, интерактивных песочниц и транскриптов
- **`Templates`** — шаблон лекции

Распределение по курсам и папкам — в [index.md](index.md)

## Как открыть

Открыть папку репозитория как хранилище в Obsidian. Настройки, плагины, тема DDLC и сниппеты лежат в `.obsidian`, поэтому вид и поведение подхватятся сразу

## Чего в репозитории нет

Вложения `00. Вложения` и PDF в `Книги` в git не попадают: там чужие издания и тяжёлые картинки. Волт на диске их содержит, а клон репозитория нет — поэтому рисунки и ссылки на страницы PDF в клоне не откроются
