# Исходники рисунков курса "Линейная алгебра"

Каждый PNG во вложениях тем курса собирается из этой папки. Тема ddlc и шрифты волта приходят из общего набора `Scripts/ddlc_figures/`, его на `sys.path` ставит `course.py`, он же задаёт корень курса

- `figures/` — скрипты рисунков по темам (`01/` … `17/`) и общий модуль `lafig.py`: роли цветов, папки тем, сохранение
- `course.py` — корень курса; от него строятся все пути вывода

## Окружение

```bash
uv venv -p 3.12 <venv>
uv pip install --python <venv>/bin/python -r requirements.txt
```

Версии в `requirements.txt` закреплены: другая версия matplotlib меняет пиксели

## Рисунок

Скрипт рисунка называется так же, как файл: `figures/01/<имя>.py` пишет `<имя>.png` во вложения темы `01. Комплексные числа и многочлены`. Если такого скрипта нет, имя ищется в коде: `grep -l "<имя>" figures/*/*.py`

```bash
<venv>/bin/python figures/01/<имя>.py
```

## Песочницы

Страница `<тема>-песочница.html` лежит во вложениях темы и собирается из `interactive/`. Логика линала живёт в одном модуле `interactive/lacore.js` (чистые функции, ES-модуль), шаблоны страниц — в `interactive/pages/`. Общее с другими курсами лежит в vault: шрифты, тема ddlc, сборка и headless-проверка страницы — `Scripts/sandbox_kit/`, числовые механизмы (парсер формул, квадратура G7K15, LU, собственные числа, многочлен $\Delta(\lambda)$, текст задачи с вырожденным ядром, `formatNumber`) и редактор ядра с графиком — `Scripts/numkit/`, его README описывает состав и встраивание. `lacore.js` берёт общее из numkit строкой `import`, сборка убирает её и вставляет `numkit.js` в шаблон маркером `/*NUMKIT*/` перед `/*LACORE*/`

```bash
PY=<venv>/bin/python                             # venv из requirements.txt: numpy, scipy, sympy (с mpmath)
$PY interactive/export_fixtures.py               # эталоны линала, пишет fixtures.json
$PY "$HOME/Projects/conspect/Scripts/numkit/export_fixtures.py"   # эталоны numkit (парсер, квадратура, собственные числа)
node --test interactive/lacore.test.mjs          # линальские функции против эталонов
node --test "$HOME/Projects/conspect/Scripts/numkit/numkit.test.mjs"   # общие механизмы против эталонов
bash interactive/install_pages.sh                # собрать все страницы во вложения тем (PY=питон с fonttools и brotli)
$PY "$HOME/myWiki/.agents/skills/conspect/tools/check_page.py" <страница.html> <папка снимков> [шаг ...]
```

Шаги `check_page.py` и то, на чём он падает, описаны в его докстринге. Первым шагом нужен `wait:3000`: страница считает разложение после загрузки

Страницы, список тем лежит в `install_pages.sh`:

- `svd` — тема `12. Операторы в евклидовом пространстве`. Разложение считается односторонним методом Якоби: он вращает столбцы самой матрицы и сохраняет малые сингулярные числа с относительной точностью, а собственные пары $A^TA$ возводят число обусловленности в квадрат
- `matrix2` — тема `11. Строение линейного оператора`. Собственные числа матрицы $2\times2$ идут по формуле корней с выбором знака, при котором нет вычитания близких чисел, второй корень берётся из $\mu_1\mu_2=\det A$; двойной корень и жорданова клетка отличаются по дискриминанту с допуском $10^{-12}$ от квадрата нормы
- `pca` — тема `12. Операторы в евклидовом пространстве`. Центрирование, ковариация, собственные числа $\lambda_j$ и прямая МНК лежат в `lacore.js` чистыми функциями (`pca2` собирает всё, что показывает страница); числа $\lambda_j$ даёт `eig2` матрицы $2\times2$, а для корней ближе $10^{-6}$ масштаба, которые `eig2` склеивает в двойной, пара восстанавливается из дискриминанта. Направления $w^j$ берутся из угла поворота $\frac12\operatorname{atan2}(2c_{xy},c_{xx}-c_{yy})$, он точен при любой разности корней. При $\lambda_1-\lambda_2\leqslant10^{-9}\lambda_1$ облако считается круглым и ось не определена. Облако на странице порождает `generateCloud` из генератора mulberry32 по seed
- `fredholm-solver` и `fredholm-numbers` — тема `16. Теория Фредгольма`. Общее у них — редактор ядра и график из numkit (`kernel-editor.js`, `kernel-editor.css`; маркеры `/*KERNEL_CSS*/`, `/*KERNEL_JS*/` в шаблоне) и список примеров `presets.json`, из которого берут примеры и страницы, и тесты, и `export_fixtures.py`; сами примеры и вид полей ввода (`pages/_kernel.js`, `pages/_kernel.css`) остаются в линале. Формулы разбирает парсер numkit без `eval` и `Function`; интегралы считает адаптивная схема Гаусса–Кронрода G7K15 с глобальным контролем ошибки; собственные числа матрицы ядра — QR-итерации Фрэнсиса после балансировки и приведения к форме Хессенберга (всё это numkit); многочлен $\Delta(\lambda)$ — рекуррентная схема Фаддеева–Леверье (numkit), числа и функции ядра — `lacore.js`
