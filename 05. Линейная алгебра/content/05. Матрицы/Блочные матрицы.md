# Блочные матрицы

$$\boxed{\,C=AB,\quad C_{ij}=\sum_{q=1}^nA_{iq}B_{qj};\qquad \begin{vmatrix}A_{11}&A_{12}\\0&A_{22}\end{vmatrix}=|A_{11}|\,|A_{22}|\,}$$

## Разбиение на блоки

> [!note] **Блочная матрица** — матрица, представленная в виде
> $$A=\begin{pmatrix}A_{11}&A_{12}&\dots&A_{1n}\\A_{21}&A_{22}&\dots&A_{2n}\\\vdots&\vdots&\ddots&\vdots\\A_{m1}&A_{m2}&\dots&A_{mn}\end{pmatrix}$$
> где элементы $A_{ij}$ — **блоки**, сами матрицы. Блоки одной строки имеют одинаковое число строк, блоки одного столбца — одинаковое число столбцов[^sizes]

[^sizes]: В тетради (p051) написано наоборот: "элементы одной строки должны иметь одинаковое кол-во столбцов, в одном столбце — строк"; верно — у блоков одной строки одинаковое число строк, у блоков одного столбца одинаковое число столбцов

Одну матрицу можно разбить на блоки разными способами

## Сложение и умножение

Действия с блочными матрицами идут по тем же формальным правилам, что и с обычными, только элементами служат блоки

> [!success] Если блоки $A_{ij}$ и $B_{ij}$ имеют одинаковые размеры при всех $i,j$, то блоки суммы равны $C_{ij}=A_{ij}+B_{ij}$
> Если $A$ состоит из $m\times n$ блоков, $B$ — из $n\times p$ блоков, и все произведения $A_{iq}B_{qj}$ определены, то у $C=AB$ блоки
> $$C_{ij}=\sum_{q=1}^nA_{iq}B_{qj},\qquad i=1,\dots,m,\quad j=1,\dots,p$$
> Произведение $A_{iq}B_{qj}$ определено, когда число столбцов блока $A_{iq}$ равно числу строк блока $B_{qj}$. Значит, разбиение столбцов $A$ на группы должно совпадать с разбиением строк $B$
>
> > [!success]- Доказательство
> > Сумма: элемент суммы — сумма элементов, поэтому сложение идёт внутри блоков
> >
> > Произведение: элемент $c_{kl}$ матрицы $C=AB$ равен $\sum_{r}a_{kr}b_{rl}$ по всем столбцам $r$ матрицы $A$. Столбцы $A$ разбиты на группы $q=1,\dots,n$, строки $B$ разбиты так же, и сумма распадается на суммы по группам
> >
> > Сумма по группе $q$ — элемент произведения блока $A_{iq}$, содержащего строку $k$, на блок $B_{qj}$, содержащий столбец $l$. Складывая по $q$, получаем элемент блока $C_{ij}$ $\blacksquare$[^block-prod]

[^block-prod]: Тетрадь (p051) и пособие (стр. 109) пишут правило без вывода

> [!example] Произведение блочных матриц
> Столбцы $A$ разбиты на группы $2+2$, строки $A$ — на $2+1$; строки $B$ разбиты на $2+2$, столбцы — на $2+1$[^ex-block]
> $$\left(\begin{array}{cc|cc}3&5&1&8\\6&4&-2&0\\\hline8&8&2&1\end{array}\right)\left(\begin{array}{cc|c}1&3&1\\8&5&4\\\hline7&0&9\\6&2&3\end{array}\right)$$
> Блоки произведения
> $$C_{11}=A_{11}B_{11}+A_{12}B_{21}=\begin{pmatrix}43&34\\38&38\end{pmatrix}+\begin{pmatrix}55&16\\-14&0\end{pmatrix}=\begin{pmatrix}98&50\\24&38\end{pmatrix},\qquad C_{12}=A_{11}B_{12}+A_{12}B_{22}=\begin{pmatrix}56\\4\end{pmatrix}$$
> $$C_{21}=A_{21}B_{11}+A_{22}B_{21}=\begin{pmatrix}92&66\end{pmatrix},\qquad C_{22}=A_{21}B_{12}+A_{22}B_{22}=(61)$$
> Матрица $C$ состоит из этих блоков: [[Операции над матрицами#Произведение матриц|обычное произведение]] даёт то же

[^ex-block]: В тетради (p051) второй сомножитель имеет размер $3\times4$, и произведение не определено; здесь взята транспонированная матрица с разбиением строк $2+2$, вычисление блоков не из лекции

## Определители блочных матриц

Формулу определителя второго порядка на блоки перенести нельзя: вычисление определителей блочных матриц сложнее

### Блоки с единичной матрицей

> [!success] Для квадратных $A_{11}$, $A_{22}$ и прямоугольных $A_{12}$ справедливо
> $$\begin{vmatrix}I&A_{12}\\0&A_{22}\end{vmatrix}=|A_{22}|,\qquad\begin{vmatrix}A_{11}&A_{12}\\0&I\end{vmatrix}=|A_{11}|$$
>
> > [!success]- Доказательство
> > В первой матрице первый столбец — $(1,0,\dots,0)^T$. [[Определитель порядка n#Формула разложения|Разложение по первому столбцу]] даёт определитель той же формы с единичным блоком на единицу меньшего порядка. После шагов по всем столбцам единичного блока остаётся $|A_{22}|$
> >
> > Во второй матрице последняя строка — $(0,\dots,0,1)$, и аналогичное разложение по последней строке даёт $|A_{11}|\ \blacksquare$

### Блочно треугольная матрица

> [!success] Для квадратных $A_{11}$, $A_{22}$ справедливо $\begin{vmatrix}A_{11}&A_{12}\\0&A_{22}\end{vmatrix}=|A_{11}|\,|A_{22}|$
>
> > [!success]- Доказательство
> > Пусть $|A_{11}|=0$. По [[Определитель порядка n#Линейная зависимость строк|критерию]] столбцы $A_{11}$ линейно зависимы: есть $x_1\neq0$ длины $n_1$ — порядка $A_{11}$ — с $A_{11}x_1=0$. Для $x=(x_1,0,\dots,0)^T$ длины $n_1+n_2$ получаем $Ax=0$: столбцы $A$ зависимы, и $|A|=0=|A_{11}||A_{22}|$
> >
> > Пусть $|A_{11}|\neq0$. Проверкой убеждаемся, что
> > $$\begin{pmatrix}A_{11}&A_{12}\\0&A_{22}\end{pmatrix}=\begin{pmatrix}A_{11}&0\\0&I\end{pmatrix}\begin{pmatrix}I&A_{11}^{-1}A_{12}\\0&A_{22}\end{pmatrix}$$
> > По [[Определитель произведения матриц|определителю произведения]] и предыдущему утверждению (первая матрица — вторая форма при $A_{12}=0$) $|A|=|A_{11}|\,|A_{22}|\ \blacksquare$

> [!success] Определитель блочно верхней треугольной матрицы с квадратными диагональными блоками $A_{ii}$ равен $|A_{11}||A_{22}|\cdots|A_{nn}|$
> То же для блочно нижней треугольной
>
> > [!success]- Доказательство
> > Индукция по числу блоков $n$. Выделим $A_{11}$ и всё остальное $A'$ — блочно верхнюю треугольную матрицу из $n-1$ блоков: по предыдущему $|A|=|A_{11}||A'|=|A_{11}||A_{22}|\cdots|A_{nn}|$. Для нижней треугольной применим [[Определитель порядка n#Транспонирование|равенство]] $|A|=|A^T|$: $A^T$ — блочно верхняя с диагональными блоками $A_{ii}^T$ $\blacksquare$

> [!example] Определитель блочно треугольной матрицы
> $$\begin{vmatrix}2&1&3&0\\1&3&-1&2\\0&0&5&1\\0&0&1&3\end{vmatrix}=\begin{vmatrix}2&1\\1&3\end{vmatrix}\begin{vmatrix}5&1\\1&3\end{vmatrix}=5\cdot14=70$$[^ex-det]

[^ex-det]: Пример не из лекции

### Общий случай при невырожденном блоке

> [!success] Если $A_{11}$, $A_{22}$ квадратные и $|A_{11}|\neq0$, то
> $$\begin{vmatrix}A_{11}&A_{12}\\A_{21}&A_{22}\end{vmatrix}=|A_{11}|\,\bigl|A_{22}-A_{21}A_{11}^{-1}A_{12}\bigr|$$
> При блоках $1\times1$ это формула определителя второго порядка: $a(d-ca^{-1}b)=ad-bc$
>
> > [!success]- Доказательство
> > Умножим матрицу справа на $\begin{pmatrix}I&-A_{11}^{-1}A_{12}\\0&I\end{pmatrix}$, определитель которой по предыдущему равен $1$:
> > $$\begin{pmatrix}A_{11}&A_{12}\\A_{21}&A_{22}\end{pmatrix}\begin{pmatrix}I&-A_{11}^{-1}A_{12}\\0&I\end{pmatrix}=\begin{pmatrix}A_{11}&0\\A_{21}&A_{22}-A_{21}A_{11}^{-1}A_{12}\end{pmatrix}$$
> > По определителю произведения определитель исходной матрицы равен определителю блочно нижней треугольной матрицы справа, то есть $|A_{11}|\,|A_{22}-A_{21}A_{11}^{-1}A_{12}|\ \blacksquare$
