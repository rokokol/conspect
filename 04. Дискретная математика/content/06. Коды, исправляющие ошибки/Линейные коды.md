# Линейные коды

## $E_2^n$ как линейное пространство [1:12:07](https://www.youtube.com/watch?t=4327&v=lGYVr7tvAnc)

На $E_2^n$ уже введена метрика [[Коды, исправляющие ошибки#Расстояние Хэмминга [1 14 08](https //www.youtube.com/watch?t=4448&v=gRZJIIvvsxE)|расстояния Хэмминга]]. Теперь то же множество рассматривается как линейное пространство над полем **GF(2)** (Galois field, поле Галуа из двух элементов) с элементами $0$ и $1$ и операциями по модулю $2$ ([1:12:34](https://www.youtube.com/watch?t=4354&v=lGYVr7tvAnc)). Это самое маленькое поле: поле из одного элемента считается вырожденным ([1:13:10](https://www.youtube.com/watch?t=4390&v=lGYVr7tvAnc)). Над ним работает всё из линейной алгебры

Наборы складываются покоординатно по модулю $2$: $\tilde\alpha+\tilde\beta=(\alpha_1\oplus\beta_1,\dots,\alpha_n\oplus\beta_n)$. Умножение на константу вырождено: умножение на $1$ ничего не меняет, на $0$ даёт нулевой набор $\tilde0$ ([1:14:03](https://www.youtube.com/watch?t=4443&v=lGYVr7tvAnc))

## Линейный код [1:13:33](https://www.youtube.com/watch?t=4413&v=lGYVr7tvAnc)

> [!note] Линейный код [1:13:33](https://www.youtube.com/watch?t=4413&v=lGYVr7tvAnc)
> **Линейным кодом порядка $n$** называется любое линейное подпространство $L$ пространства $E_2^n$ ([1:14:10](https://www.youtube.com/watch?t=4450&v=lGYVr7tvAnc))

Нулевой набор $\tilde0$ лежит в любом линейном коде, как в любом подпространстве ([1:14:51](https://www.youtube.com/watch?t=4491&v=lGYVr7tvAnc)). Умножение на константу тривиально, поэтому подпространство задаётся двумя условиями: $\tilde0\in L$ и сумма любых двух слов из $L$ лежит в $L$ ([1:15:21](https://www.youtube.com/watch?t=4521&v=lGYVr7tvAnc))

Пример — [[Код Хэмминга#Мощность и исправление одной ошибки [41 59](https //www.youtube.com/watch?t=2519&v=lGYVr7tvAnc)|код Хэмминга]]: он задан однородной системой уравнений, и решения такой системы образуют подпространство размерности $n-k$. Контрольная сумма [[Циклический избыточный код|CRC]] в чистом виде тоже задаёт линейный код над GF(2)[^crc]

[^crc]: Остаток от деления многочлена над GF(2) на фиксированный многочлен линеен по сложению, поэтому слова вида "сообщение с приписанной суммой" замкнуты по сложению. CRC-32 кадра Ethernet стартует с регистра из единиц и инвертирует результат, поэтому допустимые кадры — сдвиг линейного кода с тем же кодовым расстоянием, а не подпространство. Лектор CRC не упоминает

## Вес набора [1:15:42](https://www.youtube.com/watch?t=4542&v=lGYVr7tvAnc)

> [!note] Вес набора [1:15:42](https://www.youtube.com/watch?t=4542&v=lGYVr7tvAnc)
> **Весом** набора $\tilde\alpha\in E_2^n$ называется число единиц в $\tilde\alpha$, обозначение $w(\tilde\alpha)$
>
> Для линейного кода $L$ **минимальный вес** $w_{\min}$ — наименьший вес ненулевого слова ([1:16:12](https://www.youtube.com/watch?t=4572&v=lGYVr7tvAnc))

## Кодовое расстояние линейного кода [1:16:12](https://www.youtube.com/watch?t=4572&v=lGYVr7tvAnc)

> [!success] Кодовое расстояние линейного кода равно минимальному весу его ненулевых слов [1:16:12](https://www.youtube.com/watch?t=4572&v=lGYVr7tvAnc)
> $$\rho_{\min}(L)=w_{\min}(L)$$
> Код содержит хотя бы одно ненулевое слово, иначе $\rho_{\min}$ не определено[^nonzero]
>
> > [!success]- Доказательство [1:17:41](https://www.youtube.com/watch?t=4661&v=lGYVr7tvAnc)
> > Пусть $C$ — линейный код, $\rho_{\min}$ — его кодовое расстояние, $w_{\min}$ — минимальный вес ненулевых слов ([1:18:01](https://www.youtube.com/watch?t=4681&v=lGYVr7tvAnc)). Докажем два неравенства
> >
> > **1) $w_{\min}\leqslant\rho_{\min}$** ([1:18:45](https://www.youtube.com/watch?t=4725&v=lGYVr7tvAnc)). В $C$ есть два набора $\tilde\alpha\neq\tilde\beta$ с $\rho(\tilde\alpha,\tilde\beta)=\rho_{\min}$. Код линеен, поэтому $\tilde\alpha+\tilde\beta\in C$, и $\tilde\alpha+\tilde\beta\neq\tilde0$, потому что наборы разные ([1:20:52](https://www.youtube.com/watch?t=4852&v=lGYVr7tvAnc))
> >
> > В сумме единица стоит там, где $\tilde\alpha$ и $\tilde\beta$ различаются: $0+0=0$, $1+1=0$, $1+0=0+1=1$ ([1:20:01](https://www.youtube.com/watch?t=4801&v=lGYVr7tvAnc)). Поэтому
> >
> > $$w(\tilde\alpha+\tilde\beta)=\rho(\tilde\alpha,\tilde\beta)=\rho_{\min}$$
> >
> > Ненулевое слово веса $\rho_{\min}$ существует, значит, $w_{\min}\leqslant\rho_{\min}$
> >
> > **2) $\rho_{\min}\leqslant w_{\min}$** ([1:21:12](https://www.youtube.com/watch?t=4872&v=lGYVr7tvAnc)). В $C$ есть ненулевое слово $\tilde\gamma$ с $w(\tilde\gamma)=w_{\min}$. Нулевой набор тоже лежит в $C$, и $\rho(\tilde\gamma,\tilde0)=w(\tilde\gamma)=w_{\min}$ ([1:22:04](https://www.youtube.com/watch?t=4924&v=lGYVr7tvAnc))
> >
> > Два разных слова кода находятся на расстоянии $w_{\min}$, а кодовое расстояние — наименьшее из попарных ([1:22:37](https://www.youtube.com/watch?t=4957&v=lGYVr7tvAnc)). Значит, $\rho_{\min}\leqslant w_{\min}$
> >
> > Из 1) и 2) следует $\rho_{\min}=w_{\min}$ ([1:23:03](https://www.youtube.com/watch?t=4983&v=lGYVr7tvAnc)) $\blacksquare$

Чтобы найти кодовое расстояние по определению, нужно перебрать все пары слов, а это порядка квадрата числа слов. Для линейного кода достаточно взвесить сами слова ([1:17:09](https://www.youtube.com/watch?t=4629&v=lGYVr7tvAnc))

[^nonzero]: Условие $\lvert L\rvert\geqslant 2$ лектор не оговаривает. Для $L=\{\tilde0\}$ пар слов нет, и $\rho_{\min}$ не определено

## Пример: код Хэмминга при $n=7$

[[Код Хэмминга#Пример: код Хэмминга при $n=7$|Код Хэмминга]] порядка $7$ состоит из $16$ слов. Четыре из них порождают все остальные суммированием по модулю $2$: слова с единственной свободной координатой $\alpha_3$, $\alpha_5$, $\alpha_6$ или $\alpha_7$

| Свободная координата | Слово |
|---|---|
| $\alpha_3$ | $1110000$ |
| $\alpha_5$ | $1001100$ |
| $\alpha_6$ | $0101010$ |
| $\alpha_7$ | $1101001$ |

Сумма первых двух слов $1110000+1001100=0111100$ — тоже слово кода, и оно равно слову со свободными координатами $(\alpha_3,\alpha_5,\alpha_6,\alpha_7)=(1,1,0,0)$. Веса всех $16$ слов

| Вес | $0$ | $3$ | $4$ | $7$ |
|---|---|---|---|---|
| Число слов | $1$ | $7$ | $7$ | $1$ |

Минимальный вес ненулевых слов равен $3$, поэтому по теореме $\rho_{\min}=3$. Для этого достаточно просмотреть $15$ слов вместо $\binom{16}{2}=120$ пар. Так как $3\geqslant 2\cdot 1+1$, [[Коды, исправляющие ошибки#Критерий исправления $r$ ошибок [1 19 29](https //www.youtube.com/watch?t=4769&v=gRZJIIvvsxE)|критерий]] подтверждает, что код исправляет одну ошибку[^ex]

> [!note] Расстояние кода Хэмминга при $n\geqslant 3$ равно $3$
> Лектор этого не утверждает. Код исправляет одну ошибку, поэтому по критерию $\rho_{\min}\geqslant 3$. Набор с единицами в позициях $1,2,3$ и нулями в остальных удовлетворяет системе: позиции $1$ и $3$ входят в $D_0$, позиции $2$ и $3$ — в $D_1$, и каждая сумма равна $1+1=0$. Это слово веса $3$, и по теореме $\rho_{\min}=w_{\min}=3$

[^ex]: Не из лекции: лектор числового примера не разбирает. Минимальное расстояние по всем $120$ парам и минимальный вес по $15$ ненулевым словам оба равны $3$. Для всех $3\leqslant n\leqslant 14$ код Хэмминга порядка $n$ имеет $\rho_{\min}=3$ по перебору всех пар. Линейность существенна: у $\{011,101,111\}$ минимальное расстояние $1$, а минимальный вес $2$
