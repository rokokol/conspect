# Программный интерфейс приложения
> [!note] **Программный интерфейс приложения** (**API** — Application Programming Interface)
> Набор функций, типов, протоколов и соглашений, через которые одна программа пользуется возможностями другой, не завися от её внутреннего устройства. Примеры — системные вызовы [[Операционная система|ОС]], [[Obsidian API|API плагинов Obsidian]], веб-API поверх [[HTTP]] в стиле [[Дизайн REST API|REST]]
