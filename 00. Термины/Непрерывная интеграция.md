# Непрерывная интеграция
> [!note] **Непрерывная интеграция** (**CI** — Continuous Integration)
> Практика разработки, при которой каждый участник вливает свои изменения в общую кодовую базу хотя бы раз в день, а каждое слияние проверяется автоматической сборкой с тестами, чтобы ошибки интеграции находились как можно раньше. На практике CI — сервис, который прогоняет сборку и проверки на каждый push и pull request, например GitHub Actions
