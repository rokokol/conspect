# Прямая коррекция ошибок
> [!note] **Прямая коррекция ошибок** (**FEC** — Forward Error Correction)
> Передача данных вместе с избыточным кодом, по которому приёмник сам исправляет часть искажений или потерь без повторной передачи. Плата — доля полосы, занятая избыточностью
