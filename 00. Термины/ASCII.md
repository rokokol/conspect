# ASCII
> [!note] **ASCII** (American Standard Code for Information Interchange)
> 7-битная кодировка символов: 128 кодов, из них 33 управляющих и 95 печатных — латиница, цифры, знаки препинания, пробел. Первые 128 кодов UTF-8 совпадают с ASCII, поэтому ASCII-текст — корректный UTF-8
