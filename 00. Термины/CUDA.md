# CUDA
> [!note] **CUDA** (Compute Unified Device Architecture)
> Платформа NVIDIA для вычислений общего назначения на её [[Графический процессор|GPU]]: расширение C/C++ для ядер, которые исполняют тысячи потоков сразу, плюс драйвер, рантайм и библиотеки вроде cuBLAS и cuDNN. Через неё фреймворки машинного обучения считают на видеокартах NVIDIA
