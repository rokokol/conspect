# POSIX
> [!note] **POSIX** (Portable Operating System Interface, интерфейс переносимой операционной системы)
> Семейство стандартов [[IEEE]] 1003.n, оно же [[ISO]]/[[IEC]] 9945, — общий интерфейс [[Операционная система|ОС]] для переносимых программ: системные вызовы и функции языка C, командная оболочка и утилиты. Цель — переносимость программ на уровне исходного кода между совместимыми системами; первым был IEEE Std 1003.1-1988
