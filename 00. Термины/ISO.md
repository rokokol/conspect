# ISO
> [!note] **ISO** (International Organization for Standardization, Международная организация по стандартизации)
> Независимая негосударственная организация, объединяющая национальные органы по стандартизации; крупнейший в мире разработчик международных стандартов, секретариат в Женеве. Электротехника — область [[IEC]], а стандарты по информационным технологиям обе организации выпускают совместно, через объединённый технический комитет по информационным технологиям (ISO/IEC Joint Technical Committee 1), под общим номером ISO/IEC
>
> "ISO" — не аббревиатура, а короткое имя от греческого *isos*, "равный": полное название на разных языках даёт разные сокращения, а это одно на всех
