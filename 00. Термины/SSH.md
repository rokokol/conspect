# SSH
> [!note] **SSH** (Secure Shell)
> Протокол защищённого удалённого доступа поверх [[Заголовок TCP и установление соединения|TCP]], по умолчанию на [[Порты и сокеты|порту]] 22: шифрованный канал, проверка сервера по ключу хоста, вход клиента по паролю или ключу. Внутри канала работают командная оболочка, копирование файлов — scp и **SFTP** (SSH File Transfer Protocol) — и проброс портов
