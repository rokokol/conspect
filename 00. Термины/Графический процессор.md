# Графический процессор
> [!note] **Графический процессор** (**GPU** — Graphics Processing Unit)
> Процессор из тысяч простых ядер, которые параллельно исполняют одну программу над разными данными. Создан для построения изображения — вершинных и фрагментных шейдеров, — а через [[CUDA]] и аналоги считает и общие задачи вроде обучения [[Нейронная сеть|нейросетей]]
