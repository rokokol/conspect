# Пользовательский интерфейс
> [!note] **Пользовательский интерфейс** (**UI** — User Interface)
> Часть программы, через которую с ней взаимодействует человек: экраны, элементы управления и их отклик на ввод. В вебе UI — это [[HTML-документ и DOM-дерево|DOM]]-дерево страницы, его [[Каскад и селекторы|стили]] и [[События|обработчики событий]]. **GUI** (Graphical User Interface, графический интерфейс) управляется окнами, кнопками и указателем, в противовес текстовому [[Интерфейс командной строки|интерфейсу командной строки]]
