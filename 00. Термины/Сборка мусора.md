# Сборка мусора
> [!note] **Сборка мусора** (**GC** — Garbage Collection; так же сокращают и сам сборщик, Garbage Collector)
> Автоматическое управление памятью: среда выполнения сама находит объекты, на которые программа больше не ссылается, и освобождает их память, так что код не освобождает её вручную. Цена — паузы сборки, которые бьют по задержкам [[Подводные камни NoSQL-решений|баз данных на Java]]; тем же словом называют удаление недостижимых объектов в git
