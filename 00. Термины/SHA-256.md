# SHA-256
> [!note] **SHA-256** (Secure Hash Algorithm, 256 бит)
> Криптографическая хэш-функция семейства SHA-2: отображает вход любой длины в 256-битный отпечаток так, что практически невозможно ни восстановить вход по отпечатку, ни подобрать два входа с одинаковым отпечатком. Считается быстро, поэтому для хранения паролей не годится — там нужен [[Аутентификация и сессии#Пароли|медленный хэш]]
