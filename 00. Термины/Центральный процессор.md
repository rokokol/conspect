# Центральный процессор
> [!note] **Центральный процессор** (ЦП, **CPU** — Central Processing Unit)
> Устройство, которое выбирает из памяти машинные команды программы и исполняет их по [[Цикл обработки машинной команды|циклу обработки команды]]: вычисления ведёт [[Арифметико-логическое устройство|АЛУ]], порядок выполнения задаёт [[Устройство управления|устройство управления]]
