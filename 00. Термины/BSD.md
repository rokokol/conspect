# BSD
> [!note] **BSD** (Berkeley Software Distribution)
> Дистрибутивы исходного кода Калифорнийского университета в Беркли, изначально — расширения исследовательской версии Unix из Bell Labs. В 4.2BSD (1983) вошла первая широко распространённая реализация стека протоколов интернета, а с ней интерфейс [[Порты и сокеты|сокетов Беркли]]; сегодня BSD — семейство [[Операционная система|ОС]]-потомков: FreeBSD, NetBSD, OpenBSD
