# Исходники рисунков курса "Математическая физика"

Рисунки, у которых есть скрипт, собираются из этой папки. Тема ddlc и шрифты волта приходят из общего набора `Scripts/ddlc_figures/`, его на `sys.path` ставит `course.py`, он же задаёт корень курса. Старые рисунки тем 1–5 и 7 скриптов не имеют

- `figures/` — скрипты рисунков по темам (`06/` …) и общий модуль `mffig.py`: роли цветов, папки тем, сохранение
- `course.py` — корень курса; от него строятся все пути вывода

## Окружение

```bash
uv venv -p 3.12 <venv>
uv pip install --python <venv>/bin/python -r requirements.txt
```

Версии в `requirements.txt` закреплены: другая версия matplotlib меняет пиксели

## Рисунок

Скрипт рисунка называется так же, как файл: `figures/06/<имя>.py` пишет `<имя>.png` во вложения темы `06. Волноводы`. Если такого скрипта нет, имя ищется в коде: `grep -l "<имя>" figures/*/*.py`

```bash
<venv>/bin/python figures/06/<имя>.py
```

## Песочницы

Страница `<тема>-песочница.html` лежит во вложениях темы и собирается из `interactive/`. Логика живёт в одном модуле `interactive/wgcore.js` (чистые функции, ES-модуль), шаблон страницы — в `interactive/pages/`. Шрифты, тема ddlc, сборка и headless-проверка — общий набор `Scripts/sandbox_kit/`

```bash
PY=<venv>/bin/python                             # venv из requirements.txt: numpy, scipy, sympy (с mpmath)
$PY interactive/export_fixtures.py               # эталоны scipy и mpmath, пишет fixtures.json (в git не идёт)
node --test interactive/wgcore.test.mjs          # ядро против эталонов
bash interactive/install_pages.sh                # собрать страницы во вложения тем (PY=питон с fonttools и brotli)
$PY "$HOME/myWiki/.agents/skills/conspect/tools/check_page.py" <страница.html> <папка снимков> [шаг ...]
```

Шаги `check_page.py` описаны в его докстринге. Селекты и чекбоксы страницы слушают событие `input`, потому что шаг `set:` шлёт только его

- `waveguides` — тема `06. Волноводы`, три вкладки: круглый волновод, симметричный и несимметричный планарные
  - Функции Бесселя. $J_n(z)$ комплексного $z$ идёт по степенному ряду при $|z|<2$, иначе по обратной рекуррентности Миллера; масштаб задаёт производящая функция $e^{\pm iz}=J_0+2\sum(\pm i)^nJ_n$ со знаком, при котором $|e^{\pm iz}|=e^{|\operatorname{Im}z|}$ (обычное $1=J_0+2\sum J_{2k}$ теряет $e^{|\operatorname{Im}z|}$ в знаках). $Y_0$ и $Y_1$ — ряд Неймана по $J_{2k}$, дальше повышающая рекуррентность. $K_0$ и $K_1$ — интеграл $\int_0^\infty e^{-x\cosh t}\cosh\nu t\,dt$ по правилу трапеций с шагом $\min(0{,}25;0{,}55/\sqrt x)$, остальное — повышающая рекуррентность в виде отношений. $H^{(1)}_n=J_n+iY_n$ точна при $\operatorname{Im}z\leqslant0$, где живут вытекающие моды; при $\operatorname{Im}z>0$ теряется $J$ и $Y$, сокращающиеся в сумме
  - Поверхностные корни ищет сканирование по углу $\theta$ ($\lambda=V\cos\theta$, $\kappa=V\sin\theta$) с логарифмической сеткой при малых $\theta$ и метод Брента. Кривая $n=1$ строится без сканирования: при заданном $\kappa$ левая часть $\lambda J_{m+1}/J_m$ растёт монотонно, корень единственен
  - Вытекающий корень находится продолжением по $V$ от отсечки. У самой отсечки стартовое приближение даёт вещественный корень модели с одной $Y$-частью функции Ханкеля, дальше шаг $0{,}02$ с линейным предиктором и методом Ньютона. Голый метод секущих с угадыванием попадает на другие корни
