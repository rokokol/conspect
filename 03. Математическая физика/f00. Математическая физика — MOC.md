# Математическая физика — MOC
> Три курса КФУ 2025/2026: УМФ Глазыриной (темы 1–3), электродинамика Плещинского (темы 4, 5, 7) и спектральные задачи Карчевского по его блокнотам Colab (тема 6)

> [!tip] Три типа уравнений и где они живут
> - **Гиперболические** ($u_{tt} = a^2 u_{xx}$) — колебания струны, продольные колебания стержня. Методы: Даламбер, разделение переменных
> - **Параболические** ($u_t = a^2 u_{xx}$) — теплопроводность. Методы: разделение переменных, функция Грина
> - **Эллиптические** ($\Delta u = 0$) — стационарные задачи, гармонические функции, уравнение Гельмгольца
