# Решение задачи Коши для неоднородного уравнения колебания струны
$$
\frac{ \partial^{2}u }{ \partial t^{2} }=a^{2}\frac{ \partial^{2}u }{ \partial x^{2} } +f(x,t),~x \in (-\infty,\infty),~t>0
$$
$$
\begin{cases}
u(x,0)=\varphi (x) \\
\frac{ \partial u }{ \partial t } (x,0)=\psi(x)
\end{cases}
$$

Пусть решение уравнения имеет вид:
$$
u(x,t)=v(x,t)+w(x,t)
$$
Тогда для $v$ ищется решение в виде:
$$
\frac{ \partial^{2}v }{ \partial t^{2} } =a^{2}\frac{ \partial^{2}v }{ \partial x^{2} },~x \in(-\infty,\infty),~t>0
$$
$$
\begin{cases}
v(x,0)=\varphi (x) \\
\frac{ \partial v }{ \partial t } (x,0)=\psi(x)
\end{cases}
$$

А, в свою очередь, для $v$ — так:
$$
\frac{ \partial^{2}w }{ \partial t^{2} } = a^{2}\frac{ \partial^{2}w }{ \partial x^{2} } +f(x,t),~x \in(-\infty,\infty),t>0
$$
$$
\begin{cases}
w(x,0)=0 \\
\frac{ \partial w }{ \partial t } (x,0)=0
\end{cases}
$$

> Это справедливо из-за линейных свойств производной

Тогда решение для $v$ имеет вид *формулы Даламбера*:
$$
v(x,t)=\dfrac{\varphi (x+at)+\varphi (x-at)}{2}+\dfrac{1}{2a}\int\limits_{x-at}^{x+at}\psi(\alpha)d\alpha
$$

А для решения для $w$ введем *вспомогательную задачу*
## Вспомогательная задача для $w$
Введем функцию $w_{f}=w_{f}(x,t,\tau)$:
$$
\frac{ \partial^{2}w_{f} }{ \partial t^{2} } =a^{2}\frac{ \partial w_{f} }{ \partial x^{2} },~t>\tau,~x \in (-\infty,\infty)
$$
$$
\begin{cases}
w_{f}(x,\tau,\tau)=0 \\
\frac{ \partial w_{f} }{ \partial t } (x, \tau,\tau)=f(x,\tau)
\end{cases}
$$

Решение данной функции можно найти при помощи *формулы Даламбера*:
$$
w_{f}(x,t,\tau)=w_{f}(x,t-\tau,\tau)=\dfrac{1}{2a}\int\limits_{x-a(t-\tau)}^{x+a(t-\tau)}f(\alpha,\tau)d\alpha
$$
Второе равенство доказывается путем подстановки в формулу после замены $t'=t-\tau$. Тогда $t'>0$

Тогда решение исходного уравнения $w$ будет иметь вид:
$$
\boxed{ w(x,t)=\int\limits_{0}^{t}w_{f}(x,t,\tau)d\tau }
$$
### Доказательство
Итак, проверим последнюю формулу:
$$
w(x,t)=\dfrac{1}{2a}\int\limits_{0}^{t}\int\limits_{x-a(t-\tau)}^{x+a(t-\tau)}f(\alpha,\tau)d\alpha d\tau
$$
Тогда:
$$
\begin{gather}
\frac{ \partial w }{ \partial t } (x,t)=\frac{ \partial  }{ \partial t } \left( \int\limits_{0}^{t}w_{f}(x,t,\tau)d\tau \right) =\int\limits_{0}^{t}\frac{ \partial w_{t} }{ \partial t }(x,t,\tau)d\tau +\underbrace{ w_{f}(x,t,t) }_{ 0 }=\int\limits_{0}^{t}\frac{ \partial w_{t} }{ \partial t }(x,t,\tau)d\tau \\
\frac{ \partial^{2}w }{ \partial t^{2} } (x,t)=\int\limits_{0}^{t}\frac{ \partial^{2}w_{f} }{ \partial t^{2} } (x,t,\tau)d\tau+\underbrace{ \frac{ \partial w_{f}  }{ \partial t } (x,t,t) }_{ f(x,t) }=\int\limits_{0}^{t}\frac{ \partial^{2}w_{f} }{ \partial t^{2} } (x,t,\tau)d\tau +f(x,t) \\
\frac{ \partial^{2}w }{ \partial x^{2} } (x,t)=\frac{ \partial^{2} }{ \partial x^{2} } \left( \int\limits_{0}^{t}w_{f}(x,t,\tau) d\tau \right) =\int\limits_{0}^{t}\frac{ \partial^{2}w_{f} }{ \partial x^{2} } (x,t,\tau)d\tau=\dfrac{1}{a^{2}}\int\limits_{0}^{t}\frac{ \partial^{2}w_{f} }{ \partial t^{2} } d\tau
\end{gather}
$$
Путем простой подстановки получаем тождество, доказывающее наше предположение
