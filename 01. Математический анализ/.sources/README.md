# Исходники рисунков курса "Математический анализ"

Из рисунков курса сохранился исходник только у `catenary-arc.png`, `spherical-zone.png`, `sphere-volume.png` и `archimedes-zone-comparison.png`: это скрипт `revolution_figures.py`, восстановленный из журнала сессии codex от 13.06.2026. Скрипт последнего рисунка там собирался серией патчей, и восстановлена их последняя версия. Остальные рисунки сделаны в мае–июне 2026, их скрипты не сохранились ни в git, ни в журналах

Скрипт рисует в теме ddlc: каждый цвет — роль палитры, названная в начале файла по смыслу

## Запуск

Окружение — venv курса "Тренировки по ML" с закреплёнными версиями, его `.sources/README.md` говорит, как его собрать

```bash
~/.cache/ml-trainings-digitization/.venv/bin/python revolution_figures.py
```
