# Теорема Больцано–Коши о промежуточных значениях
## Теорема Больцано–Коши
### Формулировка

> [!important] Теорема Больцано–Коши (о промежуточных значениях)
> Пусть $f$ непрерывна на $[a, b]$, $A = f(a)$, $B = f(b)$, $A \ne B$. Тогда для любого $C$, заключённого между $A$ и $B$, найдётся точка $\xi \in [a, b]$ такая, что
> $$f(\xi) = C$$

![[bolzano-cauchy-ivt.png|620]]
*Любая горизонталь $y = C$ между уровнями $A = f(a)$ и $B = f(b)$ обязана пересечь график — в точке пересечения и сидит $\xi$ с $f(\xi) = C$*

### Доказательство делением пополам

> [!success]- Доказательство (метод половинного деления + вложенные отрезки)
> Пусть для определённости $A < B$ и $C$ — любое число, $A < C < B$. Разделим отрезок $[a, b]$ точкой $x_1$ пополам:
> - если $f(x_1) = C$ — цель достигнута, $\xi = x_1$
> - если $f(x_1) \ne C$ — то на одной из половин концы дают $C$ внутри: выберем половину $[a_1, b_1]$, где $f(a_1) < C < f(b_1)$
>
> Повторяем деление. Либо на каком-то шаге попадаем в точку $x_n$ с $f(x_n) = C$ (и всё), либо процесс бесконечен и рождает последовательность **вложенных отрезков** $[a_n, b_n]$ с длиной
> $$d_n = \frac{b - a}{2^n} \to 0, \qquad f(a_n) < C < f(b_n), \quad n \in \mathbb{N}$$
> По [[Аксиоматика действительных чисел#VI. Аксиома вложенных отрезков|аксиоме вложенных отрезков]] существует общая точка $\xi \in [a_n, b_n]$ для всех $n$. Из $0 \le \xi - a_n \le d_n \to 0$ и $0 \le b_n - \xi \le d_n \to 0$ следует
> $$\lim\limits_{n \to \infty} a_n = \xi, \qquad \lim\limits_{n \to \infty} b_n = \xi$$
> Функция $f$ непрерывна в точке $\xi$, поэтому по [[Непрерывность функции в точке#Два равносильных условия|Гейне]] $f(a_n) \to f(\xi)$ и $f(b_n) \to f(\xi)$. Перейдём в неравенстве $f(a_n) < C < f(b_n)$ к [[Свойства предела функции#T5. Предельный переход в неравенстве|пределу]]:
> $$f(\xi) \le C \le f(\xi) \ \Longleftrightarrow\ f(\xi) = C$$
> Значит $\exists\, \xi \in [a, b]: f(\xi) = C \quad\blacksquare$

### Следствие о смене знака

> [!success] Следствие. Корень между точками разного знака
> Если $f$ непрерывна на $[a, b]$ и на концах принимает значения **разных знаков**, то у неё есть нуль внутри:
> $$f(a)\cdot f(b) < 0 \ \Longrightarrow\ \exists\, \xi \in [a, b]: \ f(\xi) = 0$$

Это частный случай теоремы при $C = 0$: ноль лежит между $f(a)$ и $f(b)$, раз они разных знаков. Именно на этом следствии стоит численный **метод половинного деления** поиска корня

### Пример — уравнение cos x = x

> [!example]+ $\cos x - x = 0$ имеет корень на $(0, \pi)$
> Применим следствие к $f(x) = \cos x - x$ — она непрерывна на $[0, \pi]$ как разность [[Непрерывность функции в точке#Непрерывность элементарных функций|непрерывных]]. Значения на концах:
> $$f(0) = \cos 0 - 0 = 1 > 0, \qquad f(\pi) = \cos\pi - \pi = -1 - \pi < 0$$
> Знаки разные — значит $\exists\, \xi \in (0, \pi): \cos\xi - \xi = 0$, то есть $\xi$ — решение уравнения $\cos x = x$
