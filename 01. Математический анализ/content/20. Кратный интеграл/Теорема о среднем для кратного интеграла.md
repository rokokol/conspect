# Теорема о среднем для кратного интеграла
Непрерывная на связной области функция в некоторой точке принимает значение, равное своему среднему по области

## Формулировка
> [!success] $\int_A f=f(\xi)\,\mu(A)$
> Пусть $A\subset\mathbb{R}^n$ — измеримое, [[Непрерывность функции нескольких переменных#Компакт|компактное]], [[Теорема Больцано–Коши для функции нескольких переменных#Линейно связное множество|линейно связное]] множество, $f:A\to\mathbb{R}$ непрерывна. Тогда
> $$\exists\xi\in A\colon\quad \int_A f(x)\,dx=f(\xi)\cdot\mu(A)$$
>
> > [!success]- Доказательство через зажатие константами и теорему Больцано–Коши
> > Пусть $m=\min\limits_{x\in A}f(x)$, $M=\max\limits_{x\in A}f(x)$ — существуют по [[Непрерывность функции нескольких переменных#Теоремы Вейерштрасса|Вейерштрассу]]. Тогда $m\leqslant f(x)\leqslant M$ на $A$, и по [[Свойства кратного интеграла#Интегрирование неравенства|монотонности интеграла]]
> > $$m\,\mu(A)=\int_A m\,dx\leqslant\int_A f\,dx\leqslant\int_A M\,dx=M\,\mu(A)$$
> > При $\mu(A)>0$ делим на $\mu(A)$:
> > $$m\leqslant\lambda\leqslant M,\qquad \lambda:=\frac{1}{\mu(A)}\int_A f\,dx$$
> > По [[Теорема Больцано–Коши для функции нескольких переменных|теореме Больцано–Коши]] (о промежуточном значении непрерывной функции на связном множестве) найдётся $\xi\in A$ с $f(\xi)=\lambda$, откуда $f(\xi)\,\mu(A)=\int_A f\,dx$ $\blacksquare$
>

## Случай нулевой меры
> [!note] При $\mu(A)=0$ годится любая точка
> Если $\mu(A)=0$, обе части равенства равны нулю, поэтому в качестве $\xi$ можно взять любую точку из $A$

> [!tip] Связь с одномерным случаем
> Это прямое обобщение [[Теорема о среднем для определённого интеграла|теоремы о среднем на отрезке]]: там $\mu(A)=b-a$ и $\int_a^b f=f(\xi)(b-a)$. Роль длины отрезка играет мера области, а свойства отрезка $[a,b]$ заменяется линейной связностью $A$
