# Таблица неопределённых интегралов
## Таблица

Всюду $C \in \mathbb{R}$ — произвольная постоянная, $\Delta$ — промежуток, на котором формула верна

|  №   | $\displaystyle\int f(x)\,dx$                                                                 | Область $\Delta$                                   |
| :--: | -------------------------------------------------------------------------------------------- | -------------------------------------------------- |
|  I   | $\displaystyle\int x^{\alpha}\,dx = \dfrac{x^{\alpha+1}}{\alpha+1} + C,\quad \alpha \neq -1$ | зависит от $\alpha$ (см. ниже)                     |
|  II  | $\displaystyle\int \dfrac{dx}{x} = \ln\lvert x\rvert + C$                                    | $(-\infty, 0) \cup (0, +\infty)$                   |
| III  | $\displaystyle\int a^{x}\,dx = \dfrac{a^{x}}{\ln a} + C,\quad 0 < a \neq 1$                  | $\mathbb{R}$                                       |
|  IV  | $\displaystyle\int e^{x}\,dx = e^{x} + C$                                                    | $\mathbb{R}$                                       |
|  V   | $\displaystyle\int \sin x\,dx = -\cos x + C$                                                 | $\mathbb{R}$                                       |
|  VI  | $\displaystyle\int \cos x\,dx = \sin x + C$                                                  | $\mathbb{R}$                                       |
| VII  | $\displaystyle\int \dfrac{dx}{\cos^{2} x} = \tan x + C$                                      | $x \neq \tfrac{\pi}{2} + \pi n,\ n \in \mathbb{Z}$ |
| VIII | $\displaystyle\int \dfrac{dx}{\sin^{2} x} = -\cot x + C$                                     | $x \neq \pi n,\ n \in \mathbb{Z}$                  |
|  IX  | $\displaystyle\int \dfrac{dx}{\sqrt{1 - x^{2}}} = \arcsin x + C = -\arccos x + C$            | $(-1, 1)$                                          |
|  X   | $\displaystyle\int \dfrac{dx}{1 + x^{2}} = \arctan x + C = -\operatorname{arccot} x + C$     | $\mathbb{R}$[^domain-x]                            |

> [!tip] Как проверять строку таблицы
> Любую формулу можно мгновенно проверить дифференцированием правой части. Например, для IX: $\big(\arcsin x\big)' = \dfrac{1}{\sqrt{1 - x^2}}$ — ровно подынтегральная функция (см. [[Обратная функция и обратные тригонометрические|производные обратных тригонометрических]]). Знаки $\tan x = \dfrac{\sin x}{\cos x}$, $\cot x$, $\arcsin$, $\arctan$ берём из [[Производная функции#Базовые производные|таблицы производных]] и просто разворачиваем

[^domain-x]: В скане для строки X указана область $\Delta = (-1, 1)$ — это описка (вероятно, скопирована из строки IX). Функция $\dfrac{1}{1 + x^2}$ определена и непрерывна на **всей** числовой прямой, так что верная область — $\Delta = \mathbb{R}$

### Степенная функция — разбор

Показатель $\alpha$ в формуле I может быть любым **кроме** $-1$: при $\alpha = -1$ знаменатель $\alpha + 1$ обнулился бы, и степенное правило ломается — этот случай отдан строке II с логарифмом

> [!example] Положительная степень: $\displaystyle\int x^{2}\,dx = \dfrac{x^{3}}{3} + C$, $\;x \in \mathbb{R}$
> При $\alpha = 2$ функция $x^2$ определена и непрерывна на всей прямой, поэтому $\Delta = \mathbb{R}$

> [!example] Отрицательная степень: $\displaystyle\int \dfrac{dx}{x^{2}} = -\dfrac{1}{x} + C$
> Здесь $\alpha = -2$ ($\neq -1$, формула годится): $\dfrac{x^{-2+1}}{-2+1} = \dfrac{x^{-1}}{-1} = -\dfrac{1}{x}$. Но $x^{-2}$ не определена в нуле, поэтому $\Delta = (-\infty, 0) \cup (0, +\infty)$ — интеграл живёт на каждом луче **отдельно**

## Тонкости областей определения

> [!warning] Область $x^\alpha$ зависит от $\alpha$
> У формулы I единой области нет — она диктуется тем, как определена $x^\alpha$:
> - $\alpha \in \mathbb{N}$ (как $x^2$) — вся $\mathbb{R}$;
> - $\alpha < 0$ целое (как $x^{-2}$) — $\mathbb{R}$ без нуля;
> - $\alpha$ дробное / иррациональное — обычно $x > 0$, где $x^\alpha = e^{\alpha \ln x}$ корректна

> [!warning] Модуль в логарифме — не косметика
> В строке II стоит $\ln\lvert x\rvert$, а не $\ln x$: подынтегральная $\tfrac{1}{x}$ определена и при $x < 0$. На луче $(-\infty, 0)$ первообразная — это $\ln(-x)$, и $\big(\ln\lvert x\rvert\big)' = \tfrac{1}{x}$ на обоих лучах. Поскольку область распадается на две части, на каждой из них своя константа $C$

> [!info] Две формы у IX и X
> $\arcsin x$ и $-\arccos x$ отличаются на константу $\tfrac{\pi}{2}$ (ведь $\arcsin x + \arccos x = \tfrac{\pi}{2}$), поэтому обе записи задают **одно и то же** семейство первообразных. Аналогично $\arctan x$ и $-\operatorname{arccot} x$ различаются на $\tfrac{\pi}{2}$. Это прямое следствие [[Первообразная и неопределённый интеграл#Теорема о виде всех первообразных|теоремы о виде всех первообразных]]: любые две первообразные отличаются на $C$
