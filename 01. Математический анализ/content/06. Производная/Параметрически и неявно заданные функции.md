# Параметрически и неявно заданные функции
## Параметрическое задание

> [!important] Определение. Пусть функции $x = x(t)$ и $y = y(t)$ заданы на $T$, и пусть $E$ — множество значений $x = x(t)$. Если $x = x(t)$ обратима, $t = t(x)$, $x \in E$, то
> $$y = y(t(x)) = f(x)$$
> есть функция, заданная **параметрически**

> [!example] Четверть окружности: $x = \cos t$, $y = \sin t$
> Пусть $t \in T = \left[0, \tfrac{\pi}{2}\right]$, тогда $E = [0, 1]$ и $t = t(x) = \arccos x$. Исключая параметр:
> $$f(x) = y(t(x)) = \sin(\arccos x) = \sqrt{1 - \cos^2(\arccos x)} = \sqrt{1 - x^2}, \qquad x \in [0, 1]$$
> Параметр "спрятал" дугу окружности $x^2 + y^2 = 1$ в явную $y = \sqrt{1 - x^2}$

## Производная параметрической функции

> [!important] Теорема. Пусть $x = x(t)$ непрерывна и строго возрастает на $[a, b]$ (тогда есть обратная $t = t(x)$ на $[A, B]$, $A = x(a)$, $B = x(b)$, тоже строго возрастающая); $y = f(x) = y(t(x))$. Пусть $t_0 \in (a, b)$, $x'(t_0) \ne 0$, $\exists\, y'(t_0)$, $x_0 = x(t_0)$. Тогда
> $$\boxed{\ y'_x = \frac{y'_t}{x'_t}\ }$$
>
> > [!success]- Вывод
> > Берём производную сложной функции $f(x) = y(t(x))$ и пользуемся [[Правила дифференцирования#Производная обратной функции|производной обратной функции]] $t'(x_0) = \dfrac{1}{x'(t_0)}$:
> > $$f'(x) = y'(t(x)) \cdot t'(x_0) = \frac{y'(t(x_0))}{x'(t_0)}$$
> > Коротко это и есть $y'_x = \dfrac{y'_t}{x'_t}$

> [!note] Высшие порядки
> Вторая производная берётся тем же приёмом — $y'_x$ снова дифференцируется по $t$ и делится на $x'_t$:[^poryadok]
> $$y''_{x^2} = \frac{\left(y'_x\right)'_t}{x'_t} \qquad\Longrightarrow\qquad y^{(n)}_{x^n} = \frac{\left(y^{(n-1)}_{x^{n-1}}\right)'_t}{x'_t}$$

> [!example]+ Пример: $x = \ln(1 + e^{2t})$, $y = \operatorname{arctan} e^t$, $t \in \mathbb{R}$
> Производные по параметру:
> $$y'_t = \frac{e^t}{1 + e^{2t}}, \qquad x'_t = \frac{2 e^{2t}}{1 + e^{2t}}$$
> Тогда первая производная по $x$:
> $$y'_x = \frac{y'_t}{x'_t} = \frac{e^t}{1 + e^{2t}} \cdot \frac{1 + e^{2t}}{2 e^{2t}} = \frac{e^t}{2 e^{2t}} = \frac{1}{2 e^t} = \frac{e^{-t}}{2}$$
> Вторая производная — дифференцируем $y'_x$ по $t$ и снова делим на $x'_t$:
> $$y''_{x^2} = \frac{\left(\frac{e^{-t}}{2}\right)'_t}{x'_t} = \frac{-\frac{e^{-t}}{2}}{\frac{2 e^{2t}}{1 + e^{2t}}} = -\frac{(1 + e^{2t})\,e^{-t}}{4 e^{2t}} = -\frac{1 + e^{2t}}{4 e^{3t}}$$

[^poryadok]: Запись $y^{(n)}_{x^n}$ — это производная $n$-го **порядка** по $x$, а не $n$-я степень. Важно не делить просто на $(x'_t)^n$: каждый шаг — отдельное дифференцирование по $t$ с делением на $x'_t$

## Неявное задание

> [!important] Определение. Функция $y = f(x)$, $x \in X$, задана **неявно** уравнением $F(x, y) = 0$, если
> $$F(x, f(x)) = 0, \qquad x \in X \qquad (*)$$
> Чтобы найти производную неявной функции, надо продифференцировать $(*)$ по $x$, считая $y = y(x)$ [[Правила дифференцирования#Производная сложной функции|сложной функцией]], и из полученного уравнения выразить $y'$

> [!example]+ Окружность $x^2 + y^2 - 25 = 0$
> Считаем $y = y(x)$ и дифференцируем по $x$ (помня, что $y^2$ — сложная функция):
> $$2x + 2y \cdot y' = 0 \quad\Longrightarrow\quad y' = -\frac{x}{y}$$
> Дифференцируем равенство $x + y y' = 0$ ещё раз, чтобы найти $y''$:
> $$1 + (y')^2 + y \cdot y'' = 0 \quad\Longrightarrow\quad y'' = -\frac{1 + (y')^2}{y} = -\frac{1 + \frac{x^2}{y^2}}{y} = -\frac{x^2 + y^2}{y^3} = -\frac{25}{y^3}$$
> На последнем шаге подставили $x^2 + y^2 = 25$ — связь, которой удовлетворяют сами точки кривой
