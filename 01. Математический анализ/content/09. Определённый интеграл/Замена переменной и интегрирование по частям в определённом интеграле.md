# Замена переменной и интегрирование по частям в определённом интеграле
$$\boxed{\int_a^b u\,dv = uv\Big|_a^b - \int_a^b v\,du} \qquad \boxed{\int_a^b f(x)\,dx = \int_{\varphi^{-1}(a)}^{\varphi^{-1}(b)} f\bigl(\varphi(t)\bigr)\varphi'(t)\,dt}$$
Те же приёмы, что для [[Замена переменной в неопределённом интеграле|неопределённого интеграла]], но возвращаться к старой переменной не нужно
## Интегрирование по частям
Та же формула, что и для [[Интегрирование по частям|неопределённого интеграла]], только внеинтегральное слагаемое $uv$ берётся в пределах

> [!summary] $\displaystyle\int_a^b u\,dv = uv\Big|_a^b - \int_a^b v\,du$
> Пусть $u = u(x)$ и $v = v(x)$ непрерывно дифференцируемы на $[a, b]$ (имеют непрерывные производные). Тогда формула интегрирования по частям выглядит так
>
> > [!success]- Вывод из правила производной произведения
> > Стартуем с [[Правила дифференцирования|производной произведения]]: $(u(x)v(x))' = u'(x)v(x) + u(x)v'(x)$, откуда
> > $$u(x)\,v'(x) = \bigl(u(x)v(x)\bigr)' - u'(x)\,v(x)$$
> > Проинтегрируем по $[a, b]$. Первообразная от $(uv)'$ — это само $uv$, поэтому по [[Интеграл с переменным верхним пределом. Формула Ньютона–Лейбница#Формула Ньютона–Лейбница|Ньютону–Лейбницу]] $\int_a^b (uv)'\,dx = uv\big|_a^b$:
> > $$\int_a^b u(x)\,v'(x)\,dx = u(x)v(x)\Big|_a^b - \int_a^b u'(x)\,v(x)\,dx$$
> > В дифференциалах $v'(x)\,dx = dv$ и $u'(x)\,dx = du$, что и даёт компактную запись $\int_a^b u\,dv = uv\big|_a^b - \int_a^b v\,du$ $\blacksquare$

## Замена переменной
Подстановка $x = \varphi(t)$ переносит интеграл на новую переменную $t$ — и **пределы пересчитываются** вместе с переменной

> [!success] $\displaystyle\int_a^b f(x)\,dx = \int_{\alpha}^{\beta} f\bigl(\varphi(t)\bigr)\,\varphi'(t)\,dt$
> Пусть $f$ непрерывна на $[a, b]$, а $x = \varphi(t)$ непрерывно дифференцируема на отрезке с концами $\alpha, \beta$, причём $a = \varphi(\alpha)$, $b = \varphi(\beta)$. Тогда верна формула замены
>
> > [!success]- Доказательство
> > Пусть $\Phi$ — первообразная $f$ на $[a, b]$. По [[Интеграл с переменным верхним пределом. Формула Ньютона–Лейбница#Формула Ньютона–Лейбница|Ньютону–Лейбницу]] левая часть — это $\Phi(b) - \Phi(a) = \Phi(\varphi(\beta)) - \Phi(\varphi(\alpha))$. С другой стороны, $\Phi(\varphi(t))$ по [[Параметрически и неявно заданные функции|цепному правилу]] есть первообразная для $f(\varphi(t))\varphi'(t)$, поэтому правая часть тоже равна $\Phi(\varphi(\beta)) - \Phi(\varphi(\alpha))$. Части совпали $\blacksquare$

> [!warning] Главное отличие от неопределённого интеграла
> В [[Замена переменной в неопределённом интеграле|неопределённом]] интеграле после подстановки надо было **вернуться** к старой переменной. Здесь возвращаться не нужно — вместо этого пересчитываем **пределы**: $x = a \to t = \alpha$, $x = b \to t = \beta$. Интеграл по $t$ сразу даёт число

### Пример с иррациональностью
Классический приём — обозначить корень новой буквой

> [!example]- $\displaystyle\int_0^{\ln 2} \sqrt{e^x - 1}\;dx = 2 - \dfrac{\pi}{2}$
> **Подстановка.** Обозначим корень новой переменной: $\sqrt{e^x - 1} = t$. Тогда $e^x = t^2 + 1$, откуда $x = \ln(t^2 + 1)$ и дифференциал
> $$dx = \frac{2t}{1 + t^2}\,dt$$
> **Новые пределы.** $x = 0 \Rightarrow t = \sqrt{e^0 - 1} = 0$; $\quad x = \ln 2 \Rightarrow t = \sqrt{e^{\ln 2} - 1} = \sqrt{2 - 1} = 1$
>
> **Считаем.** Подставляем $\sqrt{e^x-1} = t$ и $dx$:
> $$\int_0^{\ln 2}\sqrt{e^x - 1}\,dx = \int_0^1 t\cdot\frac{2t}{1 + t^2}\,dt = 2\int_0^1 \frac{t^2}{1 + t^2}\,dt$$
> Выделяем целую часть дроби — $\frac{t^2}{1+t^2} = \frac{(t^2 + 1) - 1}{1 + t^2} = 1 - \frac{1}{1 + t^2}$:
> $$2\int_0^1\!\left(1 - \frac{1}{1 + t^2}\right)dt = 2\,t\Big|_0^1 - 2\arctan t\Big|_0^1 = 2 - 2\arctan 1 = 2 - 2\cdot\frac{\pi}{4} = 2 - \frac{\pi}{2}$$
> Никакого возврата к $x$ — пределы $t \in [0, 1]$ сразу дали ответ
