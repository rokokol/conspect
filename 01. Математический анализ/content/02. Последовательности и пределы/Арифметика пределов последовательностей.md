# Арифметика пределов последовательностей
## Ключевая лемма

> [!important] Лемма (разложение сходящейся через [[Бесконечно малые и бесконечно большие последовательности|БМП]])
> $$\boxed{ \lim_{n \to \infty} x_n = a \iff x_n = a + \alpha_n,~ \text{где}~ (\alpha_n) — \text{БМП} }$$
> "Сходимость к $a$ — это в точности то же самое, что $x_n$ есть $a$ плюс некоторая БМП"
>
> > [!success]- Доказательство
> > **$(\Rightarrow)$** Пусть $\lim x_n = a$, то есть $\forall \varepsilon > 0~ \exists\, n(\varepsilon)~ \forall n \geqslant n(\varepsilon)~ (|x_n - a| < \varepsilon)$
> >
> > Положим $\alpha_n := x_n - a$. Тогда $x_n = a + \alpha_n$ и
> > $$\exists\, n(\varepsilon)~ \forall n \geqslant n(\varepsilon)~ (|\alpha_n| < \varepsilon)$$
> > То есть $(\alpha_n)$ — БМП $\quad \blacksquare$
> >
> > **$(\Leftarrow)$** Пусть $\alpha_n = x_n - a$ — БМП. По определению БМП $\forall \varepsilon > 0~ \exists\, n(\varepsilon)~ \forall n \geqslant n(\varepsilon)~ (|\alpha_n| < \varepsilon)$, то есть $|x_n - a| < \varepsilon$ — значит, $\lim x_n = a$ $\quad \blacksquare$

> [!tip] Зачем эта лемма
> После этой переписи любая арифметика с пределами сводится к **арифметике БМП**: сумма пределов = сумма "$a + \alpha_n$" = $(a + b) + (\alpha_n + \beta_n)$, и нужно лишь знать, что сумма БМП — БМП. Без леммы пришлось бы каждый раз воевать с $\varepsilon$ и максимумами номеров

## Операции с пределами
### Предел суммы и разности

> [!important] Теорема 1 (предел суммы / разности)
> Пусть $(x_n)$ и $(y_n)$ сходятся. Тогда сходится и $(x_n \pm y_n)$, причём
> $$\boxed{ \lim_{n \to \infty}(x_n \pm y_n) = \lim_{n \to \infty} x_n \pm \lim_{n \to \infty} y_n }$$
>
> > [!success]- Доказательство
> > Пусть $a = \lim x_n$, $b = \lim y_n$. По [[Арифметика пределов последовательностей#Ключевая лемма|лемме]]
> > $$x_n = a + \alpha_n,~ y_n = b + \beta_n, \quad (\alpha_n), (\beta_n) — \text{БМП}$$
> > Тогда
> > $$x_n \pm y_n = (a \pm b) + \underbrace{(\alpha_n \pm \beta_n)}_{\text{БМП по сумме}}$$
> > [[Бесконечно малые и бесконечно большие последовательности#Сумма и разность двух БМП|Сумма / разность двух БМП — БМП]]. По обратной части леммы $\lim(x_n \pm y_n) = a \pm b$ $\quad \blacksquare$

### Предел произведения

> [!important] Теорема 2 (предел произведения)
> Пусть $(x_n)$ и $(y_n)$ сходятся. Тогда сходится и $(x_n y_n)$, причём
> $$\boxed{ \lim_{n \to \infty}(x_n y_n) = \left(\lim_{n \to \infty} x_n\right) \cdot \left(\lim_{n \to \infty} y_n\right) }$$
>
> > [!success]- Доказательство
> > По лемме $x_n = a + \alpha_n$, $y_n = b + \beta_n$, $(\alpha_n), (\beta_n)$ — БМП. Раскроем скобки:
> > $$x_n y_n = (a + \alpha_n)(b + \beta_n) = ab + \underbrace{a \beta_n + b \alpha_n + \alpha_n \beta_n}_{\gamma_n}$$
> > Заметим, что $\gamma_n = a \beta_n + b \alpha_n + \alpha_n \beta_n$ — БМП:
> > - $a \beta_n$ — произведение константы (ограниченной) на БМП — БМП
> > - $b \alpha_n$ — аналогично
> > - $\alpha_n \beta_n$ — [[Бесконечно малые и бесконечно большие последовательности#Произведение ограниченной на БМП|произведение двух БМП — БМП]]
> > - Сумма БМП — БМП
> >
> > Значит, $x_n y_n = ab + \gamma_n$ с БМП $\gamma_n$. По обратной части леммы $\lim x_n y_n = ab$ $\quad \blacksquare$

> [!success] Следствие — вынесение константы
> Пусть $(x_n)$ сходится, $c$ — константа. Тогда
> $$\lim_{n \to \infty} (c x_n) = c \cdot \lim_{n \to \infty} x_n$$
>
> _Доказательство_: возьмём в теореме 2 $y_n \equiv c$. Очевидно, $\lim y_n = c$. По теореме 2
> $$\lim (c x_n) = (\lim c)(\lim x_n) = c \lim x_n \quad \blacksquare$$

### Предел частного

> [!important] Теорема 3 (предел частного)
> Пусть $(x_n), (y_n)$ сходятся, $y_n \neq 0~ \forall n \in \mathbb{N}$ и $\lim y_n \neq 0$. Тогда
> $$\boxed{ \lim_{n \to \infty}\dfrac{x_n}{y_n} = \dfrac{\lim_{n \to \infty} x_n}{\lim_{n \to \infty} y_n} }$$
>
> > [!success]- Доказательство
> > Пусть $a = \lim x_n$, $b = \lim y_n$, $b \neq 0$. По лемме $x_n = a + \alpha_n$, $y_n = b + \beta_n$, $(\alpha_n), (\beta_n)$ — БМП
> >
> > Считаем разность:
> > $$\dfrac{x_n}{y_n} - \dfrac{a}{b}
> > = \dfrac{a + \alpha_n}{b + \beta_n} - \dfrac{a}{b}
> > = \dfrac{(a + \alpha_n) b - a(b + \beta_n)}{(b + \beta_n)\, b}
> > = \dfrac{\alpha_n b - a \beta_n}{b} \cdot \dfrac{1}{y_n}$$
> >
> > Очевидно, $\dfrac{\alpha_n b - a \beta_n}{b}$ — БМП (комбинация БМП с константами). Осталось показать, что $\dfrac{1}{y_n}$ — **ограничена**[^bounded-not-bmp]
> >
> > **$\dfrac{1}{y_n}$ ограничена.** Используем определение предела для $y_n$, взяв $\varepsilon = \dfrac{|b|}{2} > 0$:
> > $$\exists\, n_0~ \forall n \geqslant n_0~ \left( |y_n - b| < \dfrac{|b|}{2} \right)$$
> > По [[Свойства сходящихся последовательностей#Ограниченность и необходимое условие сходимости|обратному неравенству треугольника]] $\big| |y_n| - |b| \big| \leqslant |y_n - b| < \dfrac{|b|}{2}$, откуда
> > $$|y_n| > |b| - \dfrac{|b|}{2} = \dfrac{|b|}{2} \implies \left| \dfrac{1}{y_n} \right| < \dfrac{2}{|b|}, \quad \forall n \geqslant n_0$$
> >
> > Для $n < n_0$ — конечный набор. Возьмём
> > $$M = \max\left\{ \dfrac{1}{|y_1|},~ \dfrac{1}{|y_2|},~ \dots,~ \dfrac{1}{|y_{n_0 - 1}|},~ \dfrac{2}{|b|} \right\}$$
> > Тогда $\left| \dfrac{1}{y_n} \right| \leqslant M~ \forall n \in \mathbb{N}$ — $(1/y_n)$ ограничена
> >
> > Итак,
> > $$\dfrac{x_n}{y_n} = \dfrac{a}{b} + \underbrace{\dfrac{\alpha_n b - a \beta_n}{b}}_{\text{БМП}} \cdot \underbrace{\dfrac{1}{y_n}}_{\text{огр}}$$
> > Произведение БМП на ограниченную — [[Бесконечно малые и бесконечно большие последовательности#Произведение ограниченной на БМП|БМП]]. Значит, $\dfrac{x_n}{y_n} - \dfrac{a}{b}$ — БМП, и по лемме $\lim \dfrac{x_n}{y_n} = \dfrac{a}{b}$ $\quad \blacksquare$

> [!warning] Условие $\lim y_n \neq 0$ принципиально
> Без него мы бы делили на $b = 0$ и не смогли бы оценить $\dfrac{1}{y_n}$ снизу. Лектор это место подчёркивает отдельно — именно тут ломается аналогия с другими операциями

[^bounded-not-bmp]: Обратите внимание, что $1/y_n$ — именно **ограничена**, а не БМП! У БМП предел нуль, а у $1/y_n$ предел — $1/b \neq 0$. Здесь нам и нужна теорема [[Бесконечно малые и бесконечно большие последовательности#Произведение ограниченной на БМП|"огр × БМП = БМП"]]

## Разбор примера с многочленом

> [!example]+ Найти $\lim\limits_{n \to \infty} \dfrac{2n^3 - 4n^2 + 1}{7n^3 + 8n + 5}$
> Стандартный приём: вынесем $n^3$ в числителе и знаменателе:
> $$
> A = \lim_{n \to \infty} \dfrac{2n^3 - 4n^2 + 1}{7n^3 + 8n + 5}
> = \lim_{n \to \infty} \dfrac{n^3 \left( 2 - \dfrac{4}{n} + \dfrac{1}{n^3} \right)}{n^3 \left( 7 + \dfrac{8}{n^2} + \dfrac{3}{n^3} \right)}
> = \lim_{n \to \infty} \dfrac{2 - \dfrac{4}{n} + \dfrac{1}{n^3}}{7 + \dfrac{8}{n^2} + \dfrac{3}{n^3}}
> $$
>
> Знаменатель ненулевой и имеет ненулевой предел:
> $$\lim \left( 7 + \dfrac{8}{n^2} + \dfrac{3}{n^3} \right) = \lim 7 = 7 \neq 0,$$
> следовательно $7 + \dfrac{8}{n^2} + \dfrac{3}{n^3} \neq 0~ \forall n \in \mathbb{N}$ [^denominator-nonzero]
>
> Применяем теоремы 1–3 (предел суммы, частного, вынесение константы):
> $$A = \dfrac{\lim 2 - 4 \lim \dfrac{1}{n} + \lim \dfrac{1}{n^3}}{\lim 7 + 8 \lim \dfrac{1}{n^2} + 3 \lim \dfrac{1}{n^3}} = \dfrac{2 - 0 + 0}{7 + 0 + 0} = \boxed{ \dfrac{2}{7} } \quad \blacksquare$$

> [!tip] Делим на старшую степень
> Когда числитель и знаменатель — многочлены степеней $p$ и $q$:
> - Если $p < q$: предел = $0$ (числитель прижимается к нулю быстрее)
> - Если $p = q$: предел = отношение старших коэффициентов
> - Если $p > q$: предел = $\pm\infty$ (по знаку старшего коэффициента)
>
> В нашем случае $p = q = 3$, ответ — $\tfrac{2}{7}$ как отношение старших коэффициентов. Этот рецепт — прямое следствие арифметики пределов

[^denominator-nonzero]: Здесь используется [[Свойства сходящихся последовательностей#Отделение предела от числа|свойство отделения предела от числа]]: если $\lim z_n = 7 > 0$, то с некоторого номера $z_n > 7/2 > 0$, а первые конечные члены подчищаются вручную. Формально: если бы знаменатель обнулялся для каких-то $n$, мы бы выкинули эти конечные индексы — на предел они не влияют
