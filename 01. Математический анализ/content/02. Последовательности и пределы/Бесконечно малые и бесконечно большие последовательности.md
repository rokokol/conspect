# Бесконечно малые и бесконечно большие последовательности
## Арифметические действия над последовательностями

Прежде всего — что значит "складывать", "умножать" последовательности. По определению — поэлементно:

> [!note] Операции
> $$(x_n) \pm (y_n) := (x_n \pm y_n)$$
> $$(x_n)(y_n) := (x_n y_n)$$
> $$c \cdot (x_n) := (c x_n), \quad c = \mathrm{const}$$
> $$\dfrac{(x_n)}{(y_n)} := \left(\dfrac{x_n}{y_n}\right), \quad y_n \neq 0 ~\forall n$$

То есть последовательность — это **функция** $\mathbb{N} \to \mathbb{R}$, и операции с функциями переносятся на неё дословно

## Бесконечно малая последовательность (БМП)

> [!success] БМП [^numbering-mismatch]
> Последовательность $(\alpha_n)$ называется **бесконечно малой** (БМП), если
> $$\boxed{ \lim_{n \to \infty} \alpha_n = 0 }$$

> [!example] Простой пример
> $(\alpha_n) = \left(\dfrac{1}{n}\right)$ — БМП, так как $\lim \dfrac{1}{n} = 0$
>
> Так же — $\left(\dfrac{1}{n^2}\right)$, $(2^{-n})$, $\left(\dfrac{\sin n}{n}\right)$

### Сумма и разность двух БМП

> [!important] Теорема (сумма/разность БМП — БМП)
> Пусть $(\alpha_n)$ и $(\beta_n)$ — БМП. Тогда $(\alpha_n \pm \beta_n)$ — тоже БМП:
> $$\lim \alpha_n = 0,~ \lim \beta_n = 0 \implies \lim (\alpha_n \pm \beta_n) = 0$$
>
> > [!success]- Доказательство
> > Задано $\varepsilon > 0$. Поскольку $\lim \alpha_n = 0$:
> > $$\exists\, n_1(\varepsilon)~ \forall n \geqslant n_1(\varepsilon)~ \left( |\alpha_n| < \dfrac{\varepsilon}{2} \right)$$
> > Поскольку $\lim \beta_n = 0$:
> > $$\exists\, n_2(\varepsilon)~ \forall n \geqslant n_2(\varepsilon)~ \left( |\beta_n| < \dfrac{\varepsilon}{2} \right)$$
> > Положим $n(\varepsilon) = \max\{n_1(\varepsilon), n_2(\varepsilon)\}$. По неравенству треугольника
> > $$\forall n \geqslant n(\varepsilon)~~ \left( |\alpha_n + \beta_n| \leqslant |\alpha_n| + |\beta_n| < \dfrac{\varepsilon}{2} + \dfrac{\varepsilon}{2} = \varepsilon \right)$$
> > То есть $\lim (\alpha_n + \beta_n) = 0$ — сумма БМП — БМП. Для разности — аналогично $\quad \blacksquare$

> [!tip] Дробим $\varepsilon$ пополам
> Стандартный приём: когда из двух частей собираем оценку через **треугольник**, для каждой требуем $\tfrac{\varepsilon}{2}$ — получается $\varepsilon$ в сумме. Этот приём будем встречать на каждом шагу анализа

### Произведение ограниченной на БМП

> [!important] Теорема (ограниченная × БМП — БМП)
> Пусть $(\alpha_n)$ — ограниченная последовательность, $(\beta_n)$ — БМП. Тогда $(\alpha_n \beta_n)$ — БМП:
> $$\exists\, M > 0~ \forall n~ (|\alpha_n| \leqslant M),~ \lim \beta_n = 0 \implies \lim (\alpha_n \beta_n) = 0$$
>
> > [!success]- Доказательство
> > Возьмём $\varepsilon > 0$. По БМП-определению $\beta_n$ применим к $\dfrac{\varepsilon}{M}$:
> > $$\exists\, n(\varepsilon)~ \forall n \geqslant n(\varepsilon)~ \left( |\beta_n| < \dfrac{\varepsilon}{M} \right)$$
> > Тогда
> > $$\forall n \geqslant n(\varepsilon)~ \left( |\alpha_n \beta_n| = |\alpha_n| \cdot |\beta_n| < M \cdot \dfrac{\varepsilon}{M} = \varepsilon \right)$$
> > Значит, $\lim (\alpha_n \beta_n) = 0$ — $(\alpha_n \beta_n)$ — БМП $\quad \blacksquare$

> [!success] Следствие — произведение двух БМП — БМП
> Сходящаяся последовательность [[Свойства сходящихся последовательностей#Ограниченность и необходимое условие сходимости|ограничена]]. У БМП есть предел ($= 0$), значит она тоже ограничена. Применяем предыдущую теорему: ограниченная (БМП) × БМП = БМП $\quad \blacksquare$

> [!info] Двусторонняя польза ограниченности
> С одной стороны, БМП ограничена; с другой — ограниченность $\alpha_n$ позволяет "прижать" $\alpha_n \beta_n$ к нулю через $\beta_n$. Это два разных применения одного и того же факта 

## Бесконечно большая последовательность (ББП)

> [!success] ББП
> Последовательность $(\beta_n)$ называется **бесконечно большой** (ББП), если выполнено одно из эквивалентных условий:
> 1. $\forall \varepsilon > 0 ~~ \exists\, n(\varepsilon) ~~ \forall n \geqslant n(\varepsilon) ~~ (|\beta_n| > \varepsilon)$
> 2. $\lim\limits_{n \to \infty} \beta_n = \infty$

> [!note] Знаковые версии — $+\infty$ и $-\infty$
> $$\lim_{n \to \infty} \beta_n = +\infty \iff \forall \varepsilon > 0 ~ \exists\, n(\varepsilon) ~ \forall n \geqslant n(\varepsilon) ~ (\beta_n > \varepsilon)$$
> $$\lim_{n \to \infty} \beta_n = -\infty \iff \forall \varepsilon > 0 ~ \exists\, n(\varepsilon) ~ \forall n \geqslant n(\varepsilon) ~ (\beta_n < -\varepsilon)$$ [^minus-inf-typo]
>
> Без знака — общая ББП. С плюсом — "растёт неограниченно вверх", с минусом — "вниз"

> [!warning] ББП $\neq$ просто неограниченная
> Каждый член неограниченной последовательности может быть "как угодно большим" — но только **для каких-то** номеров, а не **для всех** после $n(\varepsilon)$. Пример: $a_n = n \cdot ((-1)^n + 1)/2$, то есть $0, 2, 0, 4, 0, 6, \dots$ — неограничена, но не ББП: нечётные нули портят определение

[^minus-inf-typo]: В скане 34 в строке для $-\infty$ написано "$\beta_n < \varepsilon$" — это **опечатка**. При $\varepsilon > 0$ и $\beta_n \to -\infty$ верное условие — $\beta_n < -\varepsilon$ (минус перед эпсилон). Иначе условие тривиально выполняется для любой отрицательной последовательности и не отличает "уходит в $-\infty$" от "остаётся в некоторой отрицательной полосе"

### Пример $\lim 2^{\sqrt{n}} = +\infty$

> [!success]- Доказательство
> Положим $\beta_n = 2^{\sqrt{n}}$. Хотим показать: $\forall \varepsilon > 0 ~ \exists\, n(\varepsilon) ~ \forall n \geqslant n(\varepsilon)~ (\beta_n > \varepsilon)$
>
> Запишем условие $\beta_n > \varepsilon$ через логарифм:
> $$2^{\sqrt{n}} > \varepsilon \iff \sqrt{n} > \log_2 \varepsilon$$
>
> **Случай 1:** $0 < \varepsilon < 1$. Тогда $\log_2 \varepsilon < 0 < \sqrt{n}~~ \forall n \in \mathbb{N}$, и условие выполнено всегда — возьмём $n(\varepsilon) = 1$
>
> **Случай 2:** $\varepsilon \geqslant 1$. Тогда $\log_2 \varepsilon \geqslant 0$, и
> $$\sqrt{n} > \log_2 \varepsilon \iff n > \log_2^2 \varepsilon$$
> Возьмём $n(\varepsilon) = [\log_2^2 \varepsilon] + 1$
>
> Итого:
> $$n(\varepsilon) = \begin{cases} 1, & 0 < \varepsilon < 1 \\ [\log_2^2 \varepsilon] + 1, & \varepsilon \geqslant 1 \end{cases}$$
> При $n \geqslant n(\varepsilon)$ выполняется $2^{\sqrt{n}} > \varepsilon$. Значит, $\lim 2^{\sqrt{n}} = +\infty$ $\quad \blacksquare$

> [!tip] Два случая по знаку логарифма
> "Развалили на два случая по знаку логарифма" — типичный приём. Если $\log_2 \varepsilon \leqslant 0$, левая часть тривиально больше нуля, и работает любое $n$. Если $\log_2 \varepsilon > 0$, нужен явный номер. Обе ветки сшиваются в одно $n(\varepsilon)$
