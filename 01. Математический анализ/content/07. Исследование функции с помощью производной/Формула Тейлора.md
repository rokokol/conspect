# Формула Тейлора
## Многочлен Тейлора и остаток Пеано

> [!important] Формула Тейлора с остаточным членом в форме Пеано
> Пусть существует производная $f^{(n)}(x_0)$. Тогда при $x \to x_0$
> $$f(x) = \underbrace{\sum_{k=0}^{n} \frac{f^{(k)}(x_0)}{k!}\,(x - x_0)^k}_{\text{многочлен Тейлора}} + \underbrace{o\big((x - x_0)^n\big)}_{\text{остаток Пеано}}$$

Многочлен Тейлора $T_n(x) = \sum_{k=0}^{n} \frac{f^{(k)}(x_0)}{k!}(x - x_0)^k$ совпадает с $f$ в точке $x_0$ вместе с первыми $n$ [[Производные и дифференциалы высших порядков|производными]]. Остаток **Пеано** $o((x-x_0)^n)$ — бесконечно малая [[Эквивалентные функции и символы Ландау|более высокого порядка]], чем $(x-x_0)^n$: ошибка приближения убывает быстрее любой степени до $n$-й включительно[^lagrange-remainder]

> [!note]- Без доказательства
> Лектор приводит формулу Тейлора с остатком Пеано без доказательства — оно опирается на повторное применение [[Правило Лопиталя|правила Лопиталя]] к отношению $\frac{f(x) - T_n(x)}{(x - x_0)^n}$

[^lagrange-remainder]: Кроме формы Пеано есть остаток в форме **Лагранжа**: $\frac{f^{(n+1)}(\xi)}{(n+1)!}(x - x_0)^{n+1}$ с промежуточной точкой $\xi$ между $x_0$ и $x$ — он даёт количественную оценку погрешности, тогда как форма Пеано лишь фиксирует её порядок малости. Лагранжев остаток выводится прямым обобщением [[Теоремы о среднем#Теорема Лагранжа|формулы конечных приращений]]

## Формула Маклорена

> [!note] Частный случай $x_0 = 0$ ^makloren
> При $x_0 = 0$ формула Тейлора называется **формулой Маклорена**:
> $$f(x) = \sum_{k=0}^{n} \frac{f^{(k)}(0)}{k!}\,x^k + o(x^n), \qquad x \to 0 \qquad (*)$$

## Единственность разложения

> [!important] Теорема о единственности разложения
> Пусть существует $f^{(n)}(x_0)$ и функция представлена в виде
> $$f(x) = \sum_{k=0}^{n} a_k (x - x_0)^k + o\big((x - x_0)^n\big), \qquad x \to x_0 \qquad (1)$$
> Тогда коэффициенты определены однозначно: $a_k = \dfrac{f^{(k)}(x_0)}{k!}$, $k = \overline{0, n}$
>
> > [!success]- Доказательство последовательным обнулением коэффициентов
> > Поскольку $f^{(n)}(x_0)$ существует, по [[Формула Тейлора#Многочлен Тейлора и остаток Пеано|формуле Тейлора]]
> > $$f(x) = \sum_{k=0}^{n} \frac{f^{(k)}(x_0)}{k!}(x - x_0)^k + o\big((x - x_0)^n\big), \qquad x \to x_0 \qquad (2)$$
> > Вычтем $(2)$ из $(1)$ почленно и обозначим $C_k = a_k - \frac{f^{(k)}(x_0)}{k!}$:
> > $$0 = \sum_{k=0}^{n} C_k (x - x_0)^k + o\big((x - x_0)^n\big) = C_0 + C_1(x - x_0) + \ldots + C_n(x - x_0)^n + o\big((x - x_0)^n\big)$$
> > Переходим к пределу при $x \to x_0$: все слагаемые с $(x - x_0)$ исчезают, остаётся $0 = C_0$. Делим оставшееся равенство на $(x - x_0)$:
> > $$0 = C_1 + C_2(x - x_0) + \ldots + C_n(x - x_0)^{n-1} + o\big((x - x_0)^{n-1}\big)$$
> > снова переходим к пределу: $C_1 = 0$. Продолжая процесс, получаем $C_k = 0$ при всех $k = \overline{0, n}$, то есть $a_k = \dfrac{f^{(k)}(x_0)}{k!}$ $\quad\blacksquare$

> [!tip] Раз разложение единственно, коэффициенты можно искать **любым удобным способом** — заменой переменной, перемножением известных рядов, почленным дифференцированием — результат совпадёт с тейлоровским
> Этим приёмом пользуемся в [[Формула Тейлора#Пример — логарифм дроби|примере]] ниже

## Чётные и нечётные функции

> [!faq]- Упражнение: производная меняет чётность
> Пусть $f$ определена на $(-a, a)$ и дифференцируема. Тогда:
> - если $f$ **чётна**, то $f'$ **нечётна**;
> - если $f$ **нечётна**, то $f'$ **чётна**
>
> Доказывается прямо по определению производной с заменой $\widetilde{\Delta x} = -\Delta x$ в отношении приращений

Отсюда — упрощение формулы Маклорена для функций с симметрией. Пусть $f$ бесконечно дифференцируема на $(-a, a)$:

> [!success] Чётная функция — только чётные степени
> Если $f$ чётна, то $f'$ нечётна, значит $f'(0) = -f'(0) \Rightarrow f'(0) = 0$. По индукции все нечётные производные в нуле обнуляются: $f^{(2k-1)}(0) = 0$. Разложение содержит только чётные степени:
> $$f(x) = \sum_{k=0}^{n} \frac{f^{(2k)}(0)}{(2k)!}\,x^{2k} + o\big(x^{2n+1}\big), \qquad x \to 0$$

> [!success] Нечётная функция — только нечётные степени
> Если $f$ нечётна, то аналогично $f^{(2k)}(0) = 0$, и остаются только нечётные степени:
> $$f(x) = \sum_{k=0}^{n} \frac{f^{(2k+1)}(0)}{(2k+1)!}\,x^{2k+1} + o\big(x^{2n+2}\big), \qquad x \to 0$$

## Разложения пяти элементарных функций

Подставляя производные в нуле в [[#^makloren|формулу Маклорена]] $(*)$, получаем эталонную пятёрку:

> [!example]- $e^x$ — все производные равны единице
> $f^{(k)}(x) = e^x \Rightarrow f^{(k)}(0) = 1$, поэтому
> $$e^x = \sum_{k=0}^{n} \frac{x^k}{k!} + o(x^n) = 1 + x + \frac{x^2}{2!} + \ldots + \frac{x^n}{n!} + o(x^n), \qquad x \to 0$$

> [!example]- $\sin x$ — нечётная, только нечётные степени
> $(\sin x)^{(2k+1)} = \sin\!\big(x + \tfrac{\pi}{2}(2k+1)\big)$, в нуле $\sin\!\big(\tfrac{\pi}{2}(2k+1)\big) = \cos \pi k = (-1)^k$:
> $$\sin x = \sum_{k=0}^{n} \frac{(-1)^k}{(2k+1)!}\,x^{2k+1} + o\big(x^{2n+2}\big) = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \ldots, \qquad x \to 0$$

> [!example]- $\cos x$ — чётная, только чётные степени
> $(\cos x)^{(2k)} = \cos\!\big(x + 2k\cdot\tfrac{\pi}{2}\big)$, в нуле $\cos \pi k = (-1)^k$:
> $$\cos x = \sum_{k=0}^{n} \frac{(-1)^k}{(2k)!}\,x^{2k} + o\big(x^{2n+1}\big) = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \ldots, \qquad x \to 0$$

> [!example]- $(1 + x)^\alpha$ — биномиальный ряд
> $f^{(k)}(0) = \alpha(\alpha - 1)(\alpha - 2)\cdots(\alpha - k + 1)$, $k \in \mathbb{N}$, а $f^{(0)}(0) = 1$:
> $$(1 + x)^\alpha = 1 + \sum_{k=1}^{n} \frac{\alpha(\alpha - 1)\cdots(\alpha - k + 1)}{k!}\,x^k + o(x^n), \qquad x \to 0 \quad (x > -1)$$

> [!example]- $\ln(1 + x)$ — знакочередующийся ряд
> $f^{(k)}(0) = (-1)^{k-1}(k-1)!$, $k \in \mathbb{N}$, а $f^{(0)}(0) = \ln 1 = 0$:
> $$\ln(1 + x) = \sum_{k=1}^{n} \frac{(-1)^{k-1}(k-1)!}{k!}\,x^k + o(x^n) = \sum_{k=1}^{n} \frac{(-1)^{k-1}}{k}\,x^k + o(x^n) = x - \frac{x^2}{2} + \frac{x^3}{3} - \ldots$$

С ростом $n$ многочлен Маклорена прижимается к $\sin x$ на всё более широком участке: $T_1, T_3, T_5, T_7$ по очереди приближают синус

## Пример — логарифм дроби

> [!example] Разложить по формуле Маклорена $f(x) = \ln\dfrac{2 - x}{3 - x}$
> Прямое дифференцирование громоздко — воспользуемся [[Формула Тейлора#Единственность разложения|единственностью разложения]] и готовым рядом для $\ln(1 + x)$. Раскладываем логарифм дроби в разность и выделяем множители:
> $$f(x) = \ln(2 - x) - \ln(3 - x) = \ln 2\Big(1 - \tfrac{x}{2}\Big) - \ln 3\Big(1 - \tfrac{x}{3}\Big) = \ln 2 + \ln\Big(1 - \tfrac{x}{2}\Big) - \ln 3 - \ln\Big(1 - \tfrac{x}{3}\Big)$$
> Подставляем $\ln(1 + u) = \sum \frac{(-1)^{k-1}}{k} u^k$ с $u = -\tfrac{x}{2}$ и $u = -\tfrac{x}{3}$. Каждое слагаемое $\frac{(-1)^{k-1}}{k}\big(-\tfrac{x}{2}\big)^k = -\frac{1}{k\, 2^k}\,x^k$, поэтому
> $$\ln\frac{2 - x}{3 - x} = \ln\frac{2}{3} + \sum_{k=1}^{n} \frac{1}{k}\left(\frac{1}{3^k} - \frac{1}{2^k}\right) x^k + o(x^n), \qquad x \to 0$$
> В силу единственности это и есть искомое разложение Маклорена
