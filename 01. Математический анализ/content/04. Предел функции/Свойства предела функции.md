# Свойства предела функции
Те же пять теорем, что у [[Свойства сходящихся последовательностей|сходящихся последовательностей]], доказываются почти дословно — на языке [[Предел функции#Определение по Коши|Коши]] или [[Предел функции#Определение по Гейне|Гейне]]. Везде предел **конечен**: $A \in \mathbb{R}$
## T1. Единственность

> [!success] T1. Если $\lim\limits_{x \to x_0} f(x)$ существует, то он единственен
>
> > [!success]- Доказательство от противного
> > Пусть $\lim f(x) = A$ и $\lim f(x) = A'$, причём $A \ne A'$. Возьмём любую $(x_n)$, $x_n \in (a, b)$, $x_n \ne x_0$, $x_n \to x_0$. По [[Предел функции#Определение по Гейне|Гейне]] $f(x_n) \to A$ и одновременно $f(x_n) \to A'$. Но у последовательности $(f(x_n))$ предел [[Свойства сходящихся последовательностей#Единственность предела|единственен]], значит $A = A'$ — противоречие $\blacksquare$

## T2. Локальная ограниченность

> [!success] T2. Если $\lim\limits_{x \to x_0} f(x)$ существует, то $f$ ограничена в некоторой $\mathring{U}(x_0)$
>
> > [!success]- Доказательство
> > Пусть $\lim f(x) = A$. Применим [[Предел функции#Определение по Коши|определение по Коши]] с $\varepsilon = 1$:
> > $$\exists\, \delta > 0 \ \ \forall x \in (a, b): \ |x - x_0| < \delta \ \Rightarrow\ |f(x) - A| < 1$$
> > то есть $\forall x \in \mathring{U}_\delta(x_0): \ -1 < f(x) - A < 1 \ \Leftrightarrow\ A - 1 < f(x) < A + 1$. Значит $f$ ограничена в $\mathring{U}_\delta(x_0)$ $\blacksquare$

## T3. Сохранение знака

> [!success] T3. Если $\lim\limits_{x \to x_0} f(x) = A$ и $A \ne 0$, то в некоторой $\mathring{U}(x_0)$ значения $f(x)$ имеют тот же знак, что и $A$
>
> > [!success]- Доказательство
> > Применим определение по Коши, взяв $\varepsilon = \dfrac{|A|}{2} > 0$. Тогда
> > $$\exists\, \delta > 0 \ \ \forall x \in \mathring{U}_\delta(x_0): \ |f(x) - A| < \frac{|A|}{2}$$
> > Значит $\underbrace{A - \dfrac{|A|}{2}}_{\text{того же знака, что } A} < f(x) < A + \dfrac{|A|}{2}$. Если $A > 0$, то $f(x) > \dfrac{A}{2} > 0$; если $A < 0$, то $f(x) < \dfrac{A}{2} < 0$ $\blacksquare$

## T4. Теорема о двух полицейских

> [!important] T4 (о двух полицейских / о зажатой функции)
> Пусть $f, g, h$ определены на $(a, b)$, кроме, быть может, $x_0$, и
> $$f(x) \le g(x) \le h(x) \quad \forall x \in (a, b) \setminus \{x_0\}, \qquad \lim\limits_{x \to x_0} f(x) = \lim\limits_{x \to x_0} h(x) = A$$
> Тогда $\lim\limits_{x \to x_0} g(x) = A$
>
> > [!success]- Доказательство (по Коши)
> > Для любого $\varepsilon > 0$ из $\lim f = A$ и $\lim h = A$:
> > $$\exists\, \delta_1 \ \forall x \in \mathring{U}_{\delta_1}(x_0): \ A - \varepsilon < f(x) < A + \varepsilon, \qquad \exists\, \delta_2 \ \forall x \in \mathring{U}_{\delta_2}(x_0): \ A - \varepsilon < h(x) < A + \varepsilon$$
> > Возьмём $\delta = \min(\delta_1, \delta_2)$. Тогда для всех $x \in \mathring{U}_\delta(x_0)$, пользуясь $f \le g \le h$:
> > $$A - \varepsilon < f(x) \le g(x) \le h(x) < A + \varepsilon \ \Rightarrow\ |g(x) - A| < \varepsilon$$
> > Значит $\lim g(x) = A$ $\blacksquare$

## T5. Предельный переход в неравенстве

> [!success] T5. Если $f(x) \le g(x)$ на $(a, b) \setminus \{x_0\}$, то $\lim\limits_{x \to x_0} f(x) \le \lim\limits_{x \to x_0} g(x)$
> Нестрогое неравенство сохраняется в пределе, а строгое — нет: в пределе может стать равенством
>
> > [!success]- Доказательство
> > Пусть $\lim f = A$, $\lim g = B$. Для любого $\varepsilon > 0$ найдётся $\delta$:
> > $$\forall x \in \mathring{U}_\delta(x_0): \quad A - \varepsilon < f(x) < A + \varepsilon, \qquad B - \varepsilon < g(x) < B + \varepsilon$$
> > Предположим противное, $A > B$, и возьмём $0 < \varepsilon \le \dfrac{A - B}{2}$. Тогда для таких $x$
> > $$B + \varepsilon < g(x), \quad f(x) < A - \varepsilon, \quad \text{но при } \varepsilon \le \tfrac{A-B}{2}: \ A - \varepsilon \ge B + \varepsilon$$
> > получаем $g(x) < B + \varepsilon \le A - \varepsilon < f(x)$, что противоречит $f(x) \le g(x)$. Значит $A \le B$ $\blacksquare$
