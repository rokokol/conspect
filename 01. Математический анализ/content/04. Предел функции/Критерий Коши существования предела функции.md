# Критерий Коши существования предела функции
Проверка существования предела **без знания самого предела** $A$ — как у [[Критерий Коши сходимости последовательности|последовательностей]], только близость требуется у любых двух точек из [[Топология R#Проколотая окрестность|проколотой окрестности]] $x_0$
## Критерий Коши
Пусть $f(x)$ определена на $(a, b)$ за исключением, быть может, точки $x_0 \in (a, b)$

> [!important] Критерий Коши
> Для существования конечного $\lim\limits_{x \to x_0} f(x)$ **необходимо и достаточно**, чтобы
> $$\forall \varepsilon > 0 \ \ \exists\, \delta > 0 \ \ \forall x', x'' \in \mathring{U}_\delta(x_0): \quad |f(x') - f(x'')| < \varepsilon$$
>
> > [!success]- Необходимость: предел есть $\Rightarrow$ условие Коши
> > Пусть $\lim\limits_{x \to x_0} f(x) = A$. По [[Предел функции#Определение по Коши|определению Коши]], взяв $\varepsilon/2$, найдём $\delta > 0$:
> > $$\forall x \in (a, b): \ |x - x_0| < \delta \ \Rightarrow\ |f(x) - A| < \frac{\varepsilon}{2}$$
> > то есть $\forall x \in \mathring{U}_\delta(x_0): \ |f(x) - A| < \dfrac{\varepsilon}{2}$. Тогда для любых $x', x'' \in \mathring{U}_\delta(x_0)$ по неравенству треугольника
> > $$|f(x') - f(x'')| = |(f(x') - A) - (f(x'') - A)| \le |f(x') - A| + |f(x'') - A| < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon \qquad \blacksquare$$
>
> > [!note]- Достаточность — без доказательства
> > Обратное лектор приводит без доказательства. Опирается на **полноту** $\mathbb{R}$ как у последовательностей: условие Коши даёт фундаментальность $f(x_n)$ для любой $x_n \to x_0$, а фундаментальная последовательность в $\mathbb{R}$ сходится — её предел и есть $A$

> [!note] Значение $A$ в формулировке не участвует
> Достаточно, чтобы вблизи $x_0$ функция не разбегалась: любые два аргумента из прокола дают близкие значения. Та же идея, что и [[Критерий Коши сходимости последовательности#Фундаментальная последовательность|фундаментальность последовательности]] $|x_n - x_m| < \varepsilon$, перенесённая на функцию

> [!tip] Зачем нужен, если есть определение
> Определения [[Предел функции#Определение по Гейне|по Гейне]] и [[Предел функции#Определение по Коши|по Коши]] требуют **назвать** кандидата $A$ и проверить его. Критерий Коши отвечает на вопрос о существовании предела, не предъявляя $A$ — это незаменимо, когда предел не выражается в простой форме (как для сумм рядов)
