# Первый замечательный предел
$$\boxed{\ \lim\limits_{x \to 0} \frac{\sin x}{x} = 1\ }$$
Раскрывает неопределённость $\frac00$ 
## Технические леммы

### Лемма 1 — неравенство для синуса

> [!note] Лемма 1. $\forall x \in \mathbb{R}: \ |\sin x| \le |x|$
>
> > [!success]- Геометрическое доказательство
> > **1) $x = 0$:** $|\sin 0| \le |0| \Leftrightarrow 0 \le 0$ — верно
> >
> > **2) $0 < x < \frac{\pi}{2}$:** проведём окружность радиуса $R$ с центром $O$. Точка $B$ на окружности под углом $x$, $A$ — на оси, $C$ симметрична $B$. Из прямоугольного $\triangle OBD$: $BD = OB \cdot \sin x = R\sin x$, хорда $BC = 2BD = 2R\sin x$. Длина дуги $\overset{\frown}{BAC} = 2xR$. Хорда короче стягиваемой дуги:
> > $$BC < \overset{\frown}{BAC} \ \Rightarrow\ 2R\sin x < 2Rx \ \Rightarrow\ \sin x < x$$
> >
> > **3) $-\frac{\pi}{2} < x < 0$:** тогда $0 < -x < \frac{\pi}{2}$, по пункту 2 $\sin(-x) < -x$, откуда после модулей $|\sin x| < |x|$. Итог пунктов 1–3: при $0 \le |x| < \frac{\pi}{2}$ верно $|\sin x| \le |x|$
> >
> > **4) $|x| \ge \frac{\pi}{2}$:** $|\sin x| \le 1 < \dfrac{\pi}{2} \le |x|$
> >
> > Во всех случаях $|\sin x| \le |x|$ $\blacksquare$

### Лемма 2 — непрерывность косинуса

> [!note] Лемма 2. $\forall x_0 \in \mathbb{R}: \ \lim\limits_{x \to x_0} \cos x = \cos x_0$
> $\cos$ — [[Непрерывность функции в точке|непрерывная]] функция в каждой точке $x_0 \in \mathbb{R}$
>
> > [!success]- Доказательство (по Коши, опираясь на лемму 1)
> > Для $\varepsilon > 0$ ищем $\delta > 0$. Преобразуем разность через формулу разности косинусов:
> > $$|\cos x - \cos x_0| = 2\left|\sin\frac{x - x_0}{2}\right| \cdot \underbrace{\left|\sin\frac{x + x_0}{2}\right|}_{\le\, 1} \le 2\left|\sin\frac{x - x_0}{2}\right|$$
> > По лемме 1 $\ 2\left|\sin\dfrac{x - x_0}{2}\right| \le 2 \cdot \dfrac{|x - x_0|}{2} = |x - x_0|$. Возьмём $\delta = \varepsilon$:
> > $$|x - x_0| < \delta \ \Rightarrow\ |\cos x - \cos x_0| \le |x - x_0| < \delta = \varepsilon \quad\blacksquare$$

> [!tip] Синус — тоже непрерывен
> Упражнение: аналогично $\forall x_0 \in \mathbb{R}\ (\lim\limits_{x \to x_0} \sin x = \sin x_0)$, то есть $\sin$ непрерывен всюду. Отсюда же $\lim\limits_{x \to +0} \cos x = \cos 0 = 1$ — понадобится через шаг

## Сам предел

> [!important] Первый замечательный предел $\lim\limits_{x \to 0} \dfrac{\sin x}{x} = 1$
>
> > [!success]- Доказательство через площади и двух полицейских
> > Пусть $0 < x < \dfrac{\pi}{2}$. Сравним три площади на единичной окружности — треугольника $OBA$, сектора $OBA$ и треугольника $OCA$ (с вершиной на касательной):
> > $$S_{\triangle OBA} < S_{\text{сектор } OBA} < S_{\triangle OCA}$$
> > $$\tfrac12 R^2 \sin x < \tfrac12 R^2 x < \tfrac12 R^2 \tan x$$
> >
> > ![[first-remarkable-limit.png|640]]
> >
> > Поделив на $\tfrac12 R^2 \sin x > 0$, получаем $1 < \dfrac{x}{\sin x} < \dfrac{1}{\cos x}$, откуда
> > $$\cos x < \frac{\sin x}{x} < 1 \qquad (*)$$
> > При $x \to +0$ левый край $\cos x \to 1$ (лемма 2), правый $\equiv 1$. По [[Свойства предела функции#T4. Теорема о двух полицейских|двум полицейским]]:
> > $$\lim\limits_{x \to +0} \frac{\sin x}{x} = 1$$
> > Функция $\dfrac{\sin x}{x}$ **чётна**, поэтому левый предел такой же, и $\lim\limits_{x \to 0} \dfrac{\sin x}{x} = 1$ $\blacksquare$

### Примеры — арксинус и тангенс

> [!example] Тангенс: $\lim\limits_{x \to 0} \dfrac{\tan x}{x} = 1$
> $$\lim\limits_{x \to 0} \frac{\tan x}{x} = \lim\limits_{x \to 0} \frac{\sin x}{x} \cdot \frac{1}{\cos x} = 1 \cdot \frac{1}{1} = 1$$

> [!example] Арксинус: $\lim\limits_{x \to 0} \dfrac{\arcsin x}{x} = 1$
> Замена $t = \arcsin x$: при $x \to 0$ имеем $t \to \arcsin 0 = 0$ и $x = \sin t$. Тогда
> $$\lim\limits_{x \to 0} \frac{\arcsin x}{x} = \lim\limits_{t \to 0} \frac{t}{\sin t} = \lim\limits_{t \to 0} \frac{1}{\frac{\sin t}{t}} = \frac{1}{1} = 1$$
> Упражнение тем же приёмом: $\lim\limits_{x \to 0} \dfrac{\arctan x}{x} = 1$
