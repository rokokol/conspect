# Предел функции
Предел функции в точке задаётся двумя способами — через [[Предел числовой последовательности|последовательности]] (по Гейне) и через [[Топология R#Проколотая окрестность|проколотые окрестности]] на языке $\varepsilon$–$\delta$ (по Коши). Они **эквивалентны**, поэтому в задаче берут удобное
## Определения

### Определение по Гейне
Пусть $f(x)$ определена на $(a, b)$, кроме, быть может, самой точки $x_0 \in (a, b)$

> [!note] Определение I (по Гейне)
> Число $A$ — **предел** $f(x)$ при $x \to x_0$, пишут $A = \lim\limits_{x \to x_0} f(x)$, если для **любой** последовательности $(x_n)$ такой, что $x_n \in (a, b)$, $x_n \ne x_0\ \forall n \in \mathbb{N}$ и $\lim\limits_{n\to\infty} x_n = x_0$, выполнено
> $$\lim\limits_{n\to\infty} f(x_n) = A$$

> [!tip] Гейне сводит предел функции к пределу последовательности
> Через Гейне весь аппарат [[Свойства сходящихся последовательностей|свойств]] и [[Арифметика пределов последовательностей|арифметики пределов последовательностей]] переносится на функции. Ключевое слово — **любая** последовательность: достаточно найти две с разными пределами $f(x_n)$, чтобы предела функции не было

### Определение по Коши

> [!note] Определение II (по Коши)
> Число $A$ — предел $f(x)$ при $x \to x_0$, если
> $$\forall \varepsilon > 0 \ \ \exists\, \delta = \delta(\varepsilon) > 0 \ \ \forall x \in (a, b): \quad 0 < |x - x_0| < \delta \ \Rightarrow\ |f(x) - A| < \varepsilon$$

> [!info] Та же мысль через окрестности
> Условие $0 < |x - x_0| < \delta$ — это в точности [[Топология R#Проколотая окрестность|проколотая окрестность]] $\mathring{U}_\delta(x_0)$, а $|f(x) - A| < \varepsilon$ — окрестность $U_\varepsilon(A)$. Поэтому компактная запись:
> $$\lim\limits_{x \to x_0} f(x) = A \ \Longleftrightarrow\ \forall \varepsilon > 0 \ \ \exists\, \delta > 0 \ \ \forall x \in \mathring{U}_\delta(x_0): \ f(x) \in U_\varepsilon(A)$$
> "Как близко к $A$ ни потребуй ($\varepsilon$) — найдётся прокол вокруг $x_0$ ($\delta$), куда функция уже не выходит за рамки"

#### Пример — устранимая особенность

> [!example]+ $\lim\limits_{x \to 4} \dfrac{x^2 - 16}{x^2 - 4x}$
> Здесь $f(x) = \dfrac{x^2 - 16}{x^2 - 4x}$, $x_0 = 4$, возьмём $(a, b) = (3, 5) \ni x_0$. В самой точке $x_0 = 4$ функция **не определена** (деление на ноль), но предел существует
>
> Берём произвольную $x_n \to 4$, $x_n \ne 4\ \forall n$. По Гейне:
> $$\lim\limits_{n\to\infty} f(x_n) = \lim\limits_{n\to\infty} \frac{x_n^2 - 16}{x_n^2 - 4x_n} = \lim\limits_{n\to\infty} \frac{(x_n - 4)(x_n + 4)}{x_n(x_n - 4)} = \frac{4 + 4}{4} = 2$$
> Сокращение на $(x_n - 4)$ законно: $x_n \ne 4$, множитель не ноль. Значение в точке роли не играет — предел смотрит только на **прокол** вокруг $x_0$
>

## Эквивалентность определений

> [!success] Теорема. Определения I и II равносильны
> Поэтому говорят просто "предел функции", не уточняя, по Гейне или по Коши
>
> > [!success]- Доказательство $\text{I} \Rightarrow \text{II}$ (от противного)
> > Пусть $\lim f(x) = A$ по Гейне, но **не** по Коши. Отрицание Коши:
> > $$\exists\, \varepsilon > 0 \ \ \forall \delta > 0 \ \ \exists\, x_\delta \in (a, b): \ 0 < |x_\delta - x_0| < \delta \ \&\ |f(x_\delta) - A| \ge \varepsilon$$
> > Положим $\delta = \dfrac1n$ и для каждого $n$ возьмём такой $x_n := x_\delta$. Тогда $x_n \in (a, b)$, $x_n \ne x_0$, $0 < |x_n - x_0| < \dfrac1n$, откуда $x_n \to x_0$, но $|f(x_n) - A| \ge \varepsilon$, то есть $f(x_n) \not\to A$. Это противоречит определению I $\blacksquare$
>
> > [!success]- Доказательство $\text{II} \Rightarrow \text{I}$ (напрямую)
> > Пусть $\lim f(x) = A$ по Коши. Возьмём любую $(x_n)$, $x_n \in (a, b)$, $x_n \ne x_0$, $x_n \to x_0$. По Коши для данного $\varepsilon$ есть $\delta = \delta(\varepsilon)$:
> > $$\forall x \in (a, b): \ 0 < |x - x_0| < \delta \ \Rightarrow\ |f(x) - A| < \varepsilon$$
> > Так как $x_n \to x_0$, для этого $\delta$ найдётся $n(\varepsilon)$: при $n > n(\varepsilon)$ выполнено $0 < |x_n - x_0| < \delta$. Значит $|f(x_n) - A| < \varepsilon$ при всех $n > n(\varepsilon)$ — то есть $f(x_n) \to A$. Определение I выполнено $\blacksquare$
