# Node и npm
**Node.js** — [[Типы и коэрция|JS]]-рантайм вне браузера: движок V8 из Chrome + системные [[Программный интерфейс приложения|API]] (файлы, сеть, процессы) вместо [[HTML-документ и DOM-дерево|DOM]][^1]. Для фронтендера Node — прежде всего *машина инструментов*: сборщики, линтеры, тесты — всё это Node-программы. **npm** (Node Package Manager) — менеджер пакетов и по совместительству крупнейший реестр софта в истории (3+ млн пакетов)

[^1]: Ryan Dahl показал Node на JSConf 2009; зал аплодировал стоя идее "весь I/O неблокирующий, один [[Event loop|event loop]] на сервере". Десять лет спустя тот же Dahl открыл доклад "10 things I regret about Node.js" — из сожалений родился Deno; впрочем, экосистему npm он не победил. Третий игрок — Bun (2022), гонится за скоростью

## package.json

```jsonc
{
  "name": "web-course",
  "type": "module",              // .js = ESM (иначе — CommonJS); наш случай
  "scripts": {
    "test": "vitest run",        // npm test; свои имена — npm run <имя>
    "typecheck": "tsc -p 07-typescript"
  },
  "dependencies": { "hono": "^4.6.0" },       // нужно в рантайме
  "devDependencies": { "vitest": "^2.0.0" }   // нужно только разработке
}
```

`npm install` читает этот файл и собирает `node_modules/`; `npm i <пакет>` — добавить зависимость (`-D` — в dev). Скрипты — обёртки над локальными бинарями: внутри `scripts` команда `vitest` находится в `node_modules/.bin` без глобальных установок

> [!tip] npx — запустить, не устанавливая
> `npx serve .` — временно скачает и запустит пакет; `npx vitest` — запустит локальный. Для разовых утилит (`npx create-vite`) — идеально: ничего не оседает в системе. На NixOS это особенно в тему — глобальный npm -g против нашей философии

## Semver

**Semver** (semantic versioning) `MAJOR.MINOR.PATCH`: ломающее изменение / новая фича без слома / багфикс. Диапазоны в package.json:

| Запись | Разрешает | Смысл |
|---|---|---|
| `^4.6.0` | 4.6.0 ≤ v < 5.0.0 | дефолт npm: "любой не-ломающий апдейт" |
| `~4.6.0` | 4.6.0 ≤ v < 4.7.0 | только патчи |
| `4.6.0` | ровно | прибито гвоздями |

> [!warning] Semver — обещание, а не закон природы
> Мейнтейнер обязуется не ломать в minor, но люди ошибаются, а "что считать breaking" — вопрос веры. Отсюда **package-lock.json**: точный снимок всего дерева зависимостей с хэшами
>
> Lock коммитится в git всегда — именно он гарантирует "у всех и в [[Непрерывная интеграция|CI]] одно и то же"; для честной установки по lock есть `npm ci`. Пара package.json (намерения) + lock (факты) — тот же паттерн, что flake.nix + flake.lock

## node_modules и цепочки доверия

Средний проект тянет сотни транзитивных зависимостей — папка node_modules весит как чугунный мост (это устойчивый мем[^2]). Практические следствия:

- `node_modules` — в `.gitignore` всегда: воспроизводится из lock
- каждая зависимость — чужой код с полным доступом; **supply chain** — реальный вектор атак: тайпсквоттинг (`lodahs`), угнанные аккаунты мейнтейнеров. `npm audit` — сканер известных уязвимостей; здоровая привычка — думать перед добавлением пакета "а не 10 ли это строк, которые я напишу сам"
- `npm ls <пакет>` — кто притащил; `npm outdated` — что протухло

[^2]: Легендарный инцидент: в 2016 автор удалил из npm пакет **left-pad** — 11 строк, дополняющих строку пробелами. Упала сборка половины интернета, включая React и Babel. Индустрия получила два урока: npm запретил удаление опубликованного, а фраза "а не много ли у нас зависимостей?" стала звучать чаще. Второй классический экспонат — пакет `is-odd` (500 тысяч скачиваний в неделю), зависящий от `is-number`

## Node запускает файлы

```bash
node script.js               # выполнить
node --watch server.js       # перезапуск при изменениях (встроено с v18)
node --inspect script.js     # отладчик — [[Отладка]]
node                         # REPL — консоль как в браузере, но без DOM
```

Внутри скрипта мир Node: `process.argv` (аргументы), `process.env` (переменные окружения), `import fs from "node:fs/promises"` — стандартная библиотека с префиксом `node:`. Подробно займёмся в [[Node как рантайм|модуле 10]] — сервер это оно и есть
