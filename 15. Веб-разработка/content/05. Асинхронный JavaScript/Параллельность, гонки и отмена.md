# Параллельность, гонки и отмена
## Четыре комбинатора

| Комбинатор | Ждёт | Результат | Провал |
|---|---|---|---|
| `Promise.all` | всех | массив значений в исходном порядке | **первый reject валит всё** (fail-fast) |
| `Promise.allSettled` | всех | массив `{status, value/reason}` | не бывает — собирает и успехи, и провалы |
| `Promise.race` | первого *устаканившегося* | его значение или ошибка | ошибка первого |
| `Promise.any` | первого *успешного* | его значение | AggregateError, если провалились все |

```js
const [user, posts] = await Promise.all([loadUser(id), loadPosts(id)]);
```

Выбор: связанные данные (нужны все или смысла нет) — `all`; независимые задачи (пусть выживет кто может — batch-отправка) — `allSettled`; таймауты и "кто быстрее из зеркал" — `race`/`any`. Порядок в результате `all` — порядок *массива*, не порядок завершения ✨

## Гонка состояний

Пользователь печатает в поиске: запрос на "ко" ушёл, затем на "кот". Сеть не обещает порядок ответов: "ко" может прийти *позже* и затереть правильные результаты устаревшими. Это **race condition** (состояние гонки) — и await с промисами от неё не спасают, она логическая

```js
let requestId = 0;
async function search(q) {
  const id = ++requestId;
  const results = await fetchResults(q);
  if (id !== requestId) return;      // пока ждали, ушёл более свежий запрос — молчим
  render(results);
}
```

Паттерн "последний победил" (номер запроса / сравнение токена) — минимальное лекарство; взрослое — отмена предыдущего запроса, см. ниже. Ловится такое только тестом с искусственной задержкой — в лабе будет ровно это

## Отмена

Промис отменить нельзя — он лишь пассивный контейнер. Отменяют саму *операцию*, и для этого есть штатный протокол:

```js
const controller = new AbortController();
fetch(url, { signal: controller.signal })
  .catch(err => { if (err.name !== "AbortError") throw err; });  // отмена — не авария

controller.abort();                   // сигнал всем, кто слушает
```

**AbortController** — кнопка; **AbortSignal** — провод от неё, который передают в операции. Один контроллер может отменить пачку операций разом. Сигнал принимают fetch, addEventListener (`{ signal }` — авточистка обработчиков), потоки; свои функции учат слушать `signal.addEventListener("abort", …)`[^1]

[^1]: Протокол пришёл из [[HTML-документ и DOM-дерево|DOM]]-мира (2017) после многолетнего холивара в TC39 о cancellable promises — предложение в язык так и не прошло, а прагматичный DOM-стандарт победил и расползся по всей экосистеме, включая Node

### Таймаут запроса

```js
const resp = await fetch(url, { signal: AbortSignal.timeout(5000) });   // штатно с 2022
// или вручную: Promise.race([fetch(url), wait(5000).then(() => { throw new Error("timeout") })])
```

Разница тонкая, но важная: race с таймером *бросает* по истечении, но запрос продолжает висеть в сети; `AbortSignal.timeout` действительно **обрывает** его

## Ретрай с паузой

```js
async function retryAsync(fn, { attempts = 3, delay = 500 } = {}) {
  for (let i = 1; ; i++) {
    try { return await fn(); }
    catch (err) {
      if (i >= attempts) throw err;
      await wait(delay * 2 ** (i - 1));     // экспоненциальный backoff: 500, 1000, 2000…
    }
  }
}
```

**Backoff** (нарастающая пауза) — вежливость к упавшему серверу: ретраи без пауз добивают его окончательно. Взрослые версии добавляют джиттер (случайный разброс, чтобы толпа клиентов не ретраила синхронно) — но это уже [[Дизайн REST API|серверные материи]]
