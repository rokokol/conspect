# URL и адресация
## Анатомия URL
> [!note] URL — **Uniform Resource Locator**
> Это точный **адрес** веб-страницы, картинки, документа или любого другого файла в интернете

```
https://user:pass@www.example.org:8080/notes/web?tag=http&sort=desc#top
└─┬─┘   └───┬───┘ └──────┬──────┘ └┬─┘ └───┬────┘ └──────┬───────┘ └┬─┘
схема    учётные    хост (домен)  порт    путь         query      фрагмент
         данные
```

| Часть          | Что означает                                                      | Если опущена               |
| -------------- | ----------------------------------------------------------------- | -------------------------- |
| **схема**      | протокол: `https`, `http`, `file`, `mailto`                       | не бывает опущена          |
| учётные данные | логин:пароль в URL — legacy, не использовать — очень не безопасно | обычно пусто               |
| **хост**       | доменное имя или [[IP-адрес и маска подсети\|IP]] сервера                                       | не бывает опущено          |
| **[[Порты и сокеты\|порт]]** | номер программы на сервере | 80 для http, 443 для https |
| **путь**       | какой ресурс просим; иерархия как у файлов                        | `/`                        |
| **query**      | параметры `?ключ=значение&…` — данные для сервера                 | пусто                      |
| **фрагмент**   | `#якорь` — позиция внутри страницы                                | пусто                      |

> [!warning] Фрагмент не покидает браузер
> Всё до `#` уходит на сервер, сам фрагмент — нет: браузер использует его локально для прокрутки к якорю. Поэтому **SPA**-приложения (single page application) исторически хранили состояние в `#…` — сервер его не видит, а страница не перезагружается

> [!note] Percent-encoding — спецсимволы в URL
> В URL разрешён узкий набор символов; остальное кодируется как `%XX` (байты UTF-8 в hex): пробел → `%20`, `я` → `%D1%8F`. Отсюда нечитаемые хвосты у русскоязычных ссылок Википедии[^1]

[^1]: Кириллические домены (`никспобеда.рф`) хитрее: в [[Протокол DNS|DNS]] уходит **punycode** — `xn--80abjdnmtkit.xn--p1ai`. Видел такое в адресной строке — это оно

## IP-адреса

> [!note] IP-адрес — числовой адрес машины в сети
> **IPv4** — 4 байта (`93.184.215.14`), их всего ~4.3 млрд и они закончились[^2]. **[[Адресация IPv6|IPv6]]** — адресов на порядки больше, хватит на каждую пылинку планеты. Специальный адрес `127.0.0.1` (имя `localhost`) — "эта же машина": на нём будет жить наш [[Node как рантайм|сервер]] при разработке

[^2]: Формально исчерпаны в 2011–2019 (по регионам). Интернет выживает на [[Статический и динамический NAT|NAT]] — целые сети прячутся за одним публичным IP; поэтому "мой IP" дома и "IP, который видит сервер" — обычно разные адреса

## Имя хоста

Хост в URL — доменное имя или IP. Имя браузер превращает в адрес протоколом DNS до первого байта [[HTTP]]: [[Протокол DNS|иерархия, резолвер, записи и кеш]] разобраны в курсе сетей. Руками это упражняет `ex02-url-dns` в `web-course/01-how-web-works/`
