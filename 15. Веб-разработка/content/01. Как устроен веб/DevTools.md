# DevTools
DevTools — главная лаборатория курса: [[Node как рантайм|REPL]], микроскоп для чужих сайтов и профайлер в одном окне. Открытие — `F12` / `Ctrl+Shift+I`, выбор элемента курсором — `Ctrl+Shift+C`. В Zen — DevTools Firefox[^1]

[^1]: Родословная: в 2006 для Firefox вышел плагин **Firebug** — первый настоящий веб-отладчик; его интерфейс (дерево элементов, вкладка сети, консоль) скопировали все браузеры, а сам он умер в 2017, выполнив миссию

	## Панели

| Панель            | Что делает                                                                                 | Когда нужна                                                           |
| ----------------- | ------------------------------------------------------------------------------------------ | --------------------------------------------------------------------- |
| **Inspector**     | живое [[HTML-документ и DOM-дерево\|DOM]]-дерево + стили каждого элемента                                                  | вёрстка, "почему оно так выглядит"                                    |
| **Console**       | [[Типы и коэрция\|JS]]-REPL + лог ошибок и предупреждений страницы                                             | эксперименты, отладка, [[Типы и коэрция\|весь модуль 04]] |
| **Network**       | все [[HTTP]]-запросы: тайминги, заголовки, размеры                                         | "что и куда грузится", лабы модуля                                    |
| **Debugger**      | точки останова в JS, шаг за шагом                                                          | [[Отладка\|отладка]]                       |
| **Storage**       | cookies, Local Storage, IndexedDB                                                          | сессии и кэши данных                                                  |
| **Performance**   | запись и разбор [[Как браузер превращает ответ в пиксели\|пайплайна рендеринга]] по кадрам | [[Производительность страницы\|модуль 09]]                             |
| **Accessibility** | дерево доступности, контраст                                                               | [[Доступность]]                                                       |

## Приёмы, которые экономят часы

- **Правка вживую**: в Inspector можно менять текст, атрибуты, стили — страница обновляется мгновенно. Это песочница: правится локальная DOM-копия, `Ctrl+R` всё откатывает
- **`$0`** в консоли — элемент, выбранный сейчас в Inspector; `$$("селектор")` — короткий `querySelectorAll`
- **`copy(x)`** — положить значение из консоли в буфер обмена
- `console.table(массивОбъектов)` — данные таблицей; `console.time("метка")` / `console.timeEnd("метка")` — замер времени
- **Network → throttling** — эмуляция медленной сети: так выглядит твой сайт с телефона в поезде
- **`view-source:URL`** — исходный [[HTML-документ и DOM-дерево|HTML]] как его прислал сервер, до всякого JS; разница с Inspector — это работа скриптов (задачка ★3 модуля)
- Правый клик по запросу в Network → **Copy as cURL** — воспроизвести запрос браузера в терминале

> [!warning] Inspector ≠ исходник
> Inspector показывает **текущий DOM** — уже распарсенный, починенный браузером и перекроенный скриптами. Что реально пришло по сети — `view-source:` или вкладка Network → Response
