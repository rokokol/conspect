# Медиа и таблицы
## Картинки

```html
<img src="graph.png" alt="Рост числа запросов с 10 до 117 за год" loading="lazy">
```

- `src` — [[URL и адресация|URL]] (абсолютный, относительный) — каждая картинка это отдельный [[HTTP]]-запрос из [[Как браузер превращает ответ в пиксели#Докачка ресурсов|водопада загрузки]]
- **`alt` обязателен**: текст-замена для скринридеров, поисковиков и упавшей загрузки. Пишется содержанием ("график роста…"), не названием файла; чисто декоративной картинке — пустой `alt=""`, чтобы скринридер её молча пропустил
- `loading="lazy"` — не грузить, пока не доскроллили
- `width`/`height` — браузер резервирует место до загрузки, страница не прыгает
- Форматы: старые [[Преобразование Фурье и анализ сигналов|JPEG]]/PNG (Portable Network Graphics)/GIF, современные **WebP**/**AVIF** (в разы легче; AVIF — AV1 Image File Format), **SVG** (Scalable Vector Graphics) — вектор, идеален для иконок и схем[^1]. Разные версии под разные экраны — `srcset`, оставим до [[f11. Свой сайт — MOC|модуля 11]]

[^1]: **GIF** (Graphics Interchange Format) при этом бессмертен, хотя формат 1987 года: анимации в нём весят чудовищно, и почти все "гифки" в интернете давно перекодированы в mp4 — только называются по-старому

**`<figure>` + `<figcaption>`** — иллюстрация с подписью как единый блок: картинка, схема, код, цитата

## Видео и аудио

```html
<video controls width="640" poster="preview.jpg">
  <source src="talk.webm" type="video/webm">
  <source src="talk.mp4" type="video/mp4">
  Браузер не поддерживает видео — <a href="talk.mp4">скачать файл</a>
</video>
```

- `controls` обязателен практически всегда — иначе у пользователя нет кнопок
- несколько `<source>` — браузер берёт первый формат, который умеет; текст внутри — запасной вариант для незнающих тег браузеров
- `autoplay` работает только вместе с `muted` — браузеры заблокировали звуковое самовоспроизведение после эпохи орущих сайтов
- `<audio>` — то же самое без картинки; `<track>` — субтитры

## Встраивание

**`<iframe src="…">`** — окно в чужую страницу: карты, видео с youtube, виджеты. Это полноценная вложенная страница со своими запросами и своим [[Типы и коэрция|JS]], поэтому:

- тяжёлый iframe = тяжёлая страница (`loading="lazy"` работает и тут)
- `sandbox` ограничивает права вложенной страницы; сайты могут запрещать своё встраивание заголовком — почему и как, разберём в [[Безопасность в браузере|безопасности браузера]]

## Таблицы

Таблица — для **табличных данных** (сетки чисел/фактов с осмысленными строками и столбцами), не для раскладки страницы[^2]

```html
<table>
  <caption>Прогресс по модулям на 2026-07-09</caption>
  <thead>
    <tr><th scope="col">Модуль</th><th scope="col">Заметок</th></tr>
  </thead>
  <tbody>
    <tr><th scope="row">01. Как устроен веб</th><td>5</td></tr>
  </tbody>
  <tfoot>
    <tr><th scope="row">Итого</th><td>10</td></tr>
  </tfoot>
</table>
```

| Тег | Роль |
|---|---|
| `<caption>` | заголовок таблицы — что это и на какую дату |
| `<thead>` / `<tbody>` / `<tfoot>` | шапка / данные / итоги |
| `<th scope="col/row">` | заголовочная ячейка столбца/строки — скринридер объявляет её перед значением |
| `colspan` / `rowspan` | растягивание ячейки на несколько столбцов/строк |

[^2]: До [[Каскад и селекторы|CSS]]-раскладок весь дизайн держался на невидимых таблицах: сайт 1998 года — это `<table>` в `<table>` в `<table>`. Задачка ★4 предлагает раскопать такое в веб-архиве; узнаешь верстальщика той эпохи по привычке к `<td valign="top">`
