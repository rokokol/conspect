# Формы
Форма — единственный способ отправить данные на сервер без единой строчки [[Типы и коэрция|JS]]: браузер сам собирает значения полей и делает [[HTTP]]-запрос

## Механика отправки

```html
<form action="/search" method="get">
  <label for="q">Запрос</label>
  <input type="text" id="q" name="q">
  <button>Искать</button>
</form>
```

Сабмит собирает пары `name=значение` **всех полей с атрибутом `name`** и шлёт на `action`:

| `method` | Куда попадают данные | Когда |
|---|---|---|
| `get` | в [[URL и адресация#Анатомия URL\|query string]]: `/search?q=веб` | поиск, фильтры — всё, что можно шарить ссылкой и повторять |
| `post` | в тело запроса | создание и изменение: логины, заказы, загрузка файлов[^1] |

[^1]: Для файлов форме нужен `enctype="multipart/form-data"` — тело собирается из частей-вложений, а не строкой `ключ=значение`

> [!warning] Поле без `name` не отправляется
> `id` связывает поле с label и нужен JS, `name` — ключ в отправляемых данных. Забытый `name` — классика: форма "работает", сервер получает пустоту

## Поля

Почти всё — один тег `<input>`, поведение задаёт `type`:

| `type` | Что даёт |
|---|---|
| `text`, `password` | строка; пароль маскируется (но летит открытым без [[HTTP#HTTPS\|HTTPS]]!) |
| `email`, `url`, `tel` | строка + встроенная проверка формата + правильная клавиатура на телефоне |
| `number`, `range` | число со стрелками / ползунок, `min`/`max`/`step` |
| `date`, `time` | нативные пикеры |
| `checkbox` | независимые галочки |
| `radio` | выбор одного из группы — **группа = одинаковый `name`** |
| `file` | выбор файла |
| `hidden` | невидимое поле — служебные данные |

Не-`input`: **`<select>`** с `<option>` — выпадающий список, **`<textarea>`** — многострочный текст, **`<button>`** — по умолчанию `type="submit"` (кнопка "просто кнопка" — `type="button"`)

## Подписи и группировка

> [!note] Каждому полю — свой `<label>`
> Связь через `for` = `id` поля (или оборачиванием поля в label). Даёт: клик по подписи фокусирует поле, скринридер объявляет подпись при фокусе — [[Доступность|двойная выгода]] бесплатно

Родственные поля собираются в `<fieldset>` с заголовком `<legend>` — особенно radio-группы: legend озвучивается перед каждым вариантом

## Встроенная валидация

Браузер сам не даст отправить невалидное и подсветит поле:

- `required` — обязательное; `minlength`/`maxlength`, `min`/`max`
- `pattern="[0-9]{6}"` — регулярка (про регулярки — в [[f04. Язык JavaScript — MOC|модуле 04]])
- типы `email`/`url` валидируют формат сами

Этого хватает на удивление часто; кастомные сообщения и сложные правила — через JS в [[Формы из JavaScript|модуле 06]]

> [!warning] Клиентская валидация — удобство, не защита
> Любую браузерную проверку обходит `curl` за секунду: сервер обязан валидировать всё заново. Сделаем сами в [[Сервер на Hono и SQLite|модуле 10]]
