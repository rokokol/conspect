# used to и be used to
Три похожих на вид конструкции с разным смыслом — их легко перепутать

## used to + инфинитив — привычка в прошлом

> [!note] **used to + V** — раньше делал, а сейчас нет
> В отрицании и вопросе **used** теряет **-d** (появляется *do/did*):
> - **+** *I **used to** work there.* — раньше работал
> - **−** *She **didn't use to** work there.*
> - **?** *Did you **use to** work there?*

Действие-привычка с глаголами действия передаётся и через **would**: *We **would** play in the country* — но would не годится для состояний (*used to be, used to have*)

## be used to и get used to — привыкание

> [!note] **be used to + -ing/сущ.** — привычка уже сформирована
> *I **am used to** such weather.* — привык, мне не в новинку

> [!note] **get used to + -ing/сущ.** — процесс привыкания
> *I **got used to** such weather.* — постепенно привык
> С глаголом после **to** идёт [[Герундий|-ing]], а не инфинитив:
> *It is impossible to **get used to sleeping** with the light on*

> [!warning] be used to в прошедшем времени по смыслу = get used to
> Оба про то, что привычка возникла; отличие — **be used to** описывает состояние, **get used to** — переход к нему
