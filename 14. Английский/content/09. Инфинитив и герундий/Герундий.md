# Герундий
Герундий — **неличная форма глагола** на **-ing**, совмещающая свойства глагола и существительного: может быть подлежащим или дополнением

> [!note] Герундий — **V + -ing**, отвечает на "что делать?" как существительное
> *I like **dancing**.*
> ***Reading** is interesting.* — герундий как подлежащее
> В отличие от [[Инфинитив|инфинитива]], передаёт процесс и факт действия, а не намерение

> [!note] 1. После глаголов предпочтения → -ing
> **love, like, dislike, hate, enjoy**
> *I enjoy **reading**.*

> [!note] 2. После **go** при физической деятельности → -ing
> go **swimming** / go **cycling** / go **golfing** / go **sailing** / go **diving** / go **slimming**
> *I like going **swimming** on weekends.*

> [!note] 3. После длинного ряда глаголов → -ing

| | | | | | |
|---|---|---|---|---|---|
| admit | appreciate | avoid | begin | consider | continue |
| delay | deny | discuss | escape | excuse | finish |
| forgive | imagine | involve | mention | mind | miss |
| object to | practise | prevent | save | start | stop |
| suggest | understand | | | | |

> Глаголы **start, begin, continue, intend** принимают обе формы без смены смысла; глаголы **stop, mind** и другие — меняют — подробнее [[Глаголы со сменой смысла — remember, forget, regret, stop|тут]]

> [!note] 4. После **see, hear, listen, watch** → -ing (незаконченное / длящееся действие)
> *I saw her **crossing** the street.* — действие в процессе

> [!note] 5. После предлогов **without** и **in** → -ing
> *She left **without taking** the dog.*
> *I'm interested **in doing** it.*

> [!success] Устойчивые выражения с герундием
> - **It's not worth** + -ing
> - **It's no use** + -ing / **It's (no) good** + -ing
> - **I'm busy** + -ing
> - **What's the use of** + -ing
> - **Can't help** + -ing (не могу не...)
> - **Can't stand** + -ing (не переношу)
> - **Look forward to** + -ing (с нетерпением жду)
> - **In addition to** / **as well as** + -ing
