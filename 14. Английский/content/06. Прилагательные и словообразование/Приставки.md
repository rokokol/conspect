# Приставки

Приставки — ключевой механизм [[f13. Лексика — MOC|словообразования]]: меняют значение, не меняя часть речи

## Отрицательные приставки (прилагательные и существительные)

Выбор между **un-, dis-, il-, ir-, im-, in-** зависит от первого звука основы:

| Приставка | Условие | Примеры |
|:--|:--|:--|
| **un-** | общее отрицание (нейтральное) | unhappy, unfair, unbelievable, unclear |
| **dis-** | противоположное (более активное) | disagree, dishonest, disconnect, disappear |
| **il-** | перед **l** | illogical, illegal, illiterate, illegible |
| **ir-** | перед **r** | irresponsible, irregular, irrational, irrelevant |
| **im-** | перед **m, p** | impossible, impolite, immature, impatient |
| **in-** | перед остальными | inactive, informal, incorrect, incomplete |

> [!warning] **un-** vs **dis-** — не одно и то же
> **Un-** просто отрицает: *unhappy* = "не счастливый"
> **Dis-** подчёркивает активное противодействие: *disagree* = активно не соглашаться, *dishonest* = умышленная нечестность

## Прочие приставки существительных и прилагательных

| Приставка | Значение | Примеры | Дефис |
|:--|:--|:--|:--|
| **anti-** | против | anti-racist, anti-clockwise, anti-war | да |
| **auto-** | само- | autobiography, autocomplete, autopilot | нет |
| **mid-** | середина | midday, midnight; mid-October, mid-term | нет / да* |
| **post-** | после | post-war, post-modern; post-election | нет / да* |
| **super-** | сверх- | supermodel, supernatural, superstar | нет |
| **extra-** | за пределами | extraterrestrial, extraordinary | нет |
| **inter-** | взаимодействие | international, interactive, internet | нет |

*Mid- и post- пишутся через дефис перед именами собственными и отдельными словами: mid-October, post-election

## Глагольные приставки

| Приставка | Значение | Примеры |
|:--|:--|:--|
| **de-** | обратное действие | declassify, decode, defrost, deactivate |
| **over-** | с избытком | overrate, overcharge, overestimate, overwork |
| **under-** | недостаточно, не до конца | undercook, underestimate, undervalue |
| **re-** | снова, пере- | reconsider, redo, rewrite, review, rebuild |
| **en-/em-** | превратить в действие | encourage, enable, enforce; empower, embark |

> [!note] **En- / em-** — выбор по первому звуку основы
> **Em-** перед b, p, m: *empower, embark, embrace*
> **En-** перед остальными: *encourage, enable, enforce, enrich*
