Песочница случайного леса

Случайный лес — бэггинг деревьев плюс случайное подмножество признаков в каждой вершине (max_features). Фон — доля деревьев за класс, линия — граница, залитые точки — обучение, полые — тест

Внизу ошибка по мере роста числа деревьев: на обучении, OOB (каждый объект оценивают только деревья, которые его не видели) и на тесте. В данных два признака, поэтому max_features = 2 — это обычный бэггинг, а 1 — один случайный признак на вершину

Показывать тест

Ошибка OOB считается по объектам, у которых есть хотя бы одно дерево без них: при N = 1 таких 37 %, при N ≥ 30 почти все. Число деревьев выбирают по плато OOB или валидации, а не по тесту

Кнопка ρ обучает по 10 лесов из 25 деревьев на свежих выборках двух лун (новый шум) при обоих значениях max_features и оценивает по 49 точкам σ² (дисперсию одного дерева) и ρ (корреляцию двух деревьев) в формуле ρσ² + (1 − ρ)σ²/N. Это замер на одной задаче, у других данных ρ другой
