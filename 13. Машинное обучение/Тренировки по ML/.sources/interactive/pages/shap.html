Песочница значений Шепли

Четыре признака — четыре игрока, предсказание — выигрыш. Значение Шепли φᵢ — средний прирост предсказания в момент, когда признак i становится известным, по всем способам собрать вокруг него остальные признаки

Выигрыш коалиции S признаков — v(S) = E[f(z) | z_S = x_S]: известные признаки берутся из объекта, остальные пробегают по фону и усредняются. Здесь v(S) считается интервенционно: фон — обучающие объекты, в каждую строку фона подставлены x_S, и по строкам берётся среднее f

Значения Шепли получаются перебором всех 2⁴ = 16 коалиций, переобучать ничего не нужно

Объект: щёлкни по точке (кольца — отложенные, бледные точки — фон)
Значения признаков объекта (0 или 1). Фон — все 16 комбинаций четырёх признаков: ровно независимые монеты с вероятностью ½
сравнить с правилом пропусков дерева (слайд 27, path-dependent)
