# Исходники рисунков курса "Численные методы"

Каждый PNG во вложениях тем курса собирается из этой папки. Тема ddlc и шрифты волта приходят из общего набора `Scripts/ddlc_figures/`, его на `sys.path` ставит `course.py`, он же задаёт корень курса

- `figures/` — скрипты рисунков по темам (`01/` … `04/`) и общий модуль `nmfig.py`: роли цветов, папки тем, сохранение
- `course.py` — корень курса; от него строятся все пути вывода

## Окружение

```bash
uv venv -p 3.12 <venv>
uv pip install --python <venv>/bin/python -r requirements.txt
```

Версии в `requirements.txt` закреплены: другая версия matplotlib меняет пиксели

## Рисунок

Скрипт рисунка называется так же, как файл: `figures/01/<имя>.py` пишет `<имя>.png` во вложения темы `01. Итерационные методы и неподвижная точка`. Если такого скрипта нет, имя ищется в коде: `grep -l "<имя>" figures/*/*.py`

```bash
<venv>/bin/python figures/01/<имя>.py
```

## Песочницы

Страница `<тема>-песочница.html` лежит во вложениях темы и собирается из `interactive/`. Логика курса — один модуль `interactive/nmcore.js` (чистые функции, ES-модуль), шаблоны страниц — `interactive/pages/`, примеры — `interactive/presets.json`. Общее с другими курсами лежит в vault: шрифты, тема ddlc, сборка и headless-проверка страницы — `Scripts/sandbox_kit/`, числовые механизмы (парсер формул, квадратура, LU, собственные числа) и линейный и логарифмический график — `Scripts/numkit/`, его README описывает состав и встраивание. `nmcore.js` берёт общее из numkit строкой `import`, сборка убирает её и вставляет `numkit.js` маркером `/*NUMKIT*/` перед `/*NMCORE*/`

```bash
PY=<venv>/bin/python                              # numpy, scipy и sympy из requirements.txt
$PY interactive/export_fixtures.py                # эталоны numpy и scipy, пишет fixtures.json (не в git)
$PY "$HOME/Projects/conspect/Scripts/numkit/export_fixtures.py"   # эталоны numkit
node --test interactive/nmcore.test.mjs           # nmcore.js против эталонов и чисел заметок
PY=<питон с fonttools и brotli> bash interactive/install_pages.sh   # пересобрать все страницы курса во вложения тем
$PY "$HOME/myWiki/.agents/skills/conspect/tools/check_page.py" <страница.html> <папка снимков> [шаг ...]
```

Шаги `check_page.py` описаны в README линала. Список страниц и тем лежит в `install_pages.sh`; новая страница — это `pages/<имя>.html`, строка в обоих массивах скрипта и, если нужны примеры, записи `presets.json` с полем `pages`

Страницы:

- `iterations` — тема `01. Итерационные методы и неподвижная точка`. Матрица перехода $S=I-\tau B^{-1}A$ собирается из канонической формы $B,\tau$ и сверяется с шагами по покомпонентным формулам заметок (1.3), (1.6), (1.9): это два вычисления разной формы. Спектральный радиус даёт `eigenvalues` из numkit. Положительную определённость проверяет разложение Холецкого со строгим пивотом, условие Самарского — положительная определённость $B_1-\frac\tau2A$ с допуском $10^{-12}$ от элементов, поэтому $\omega=2$ и $\omega=2-4\cdot10^{-16}$ считаются нарушением. Оптимальный параметр — узел сетки с наименьшим $\rho$ и золотое сечение в двух соседних ячейках, для $B=I$ и положительно определённой $A$ рядом показаны $\tau_0=2/(M+m)$ и $(M-m)/(M+m)$
- `second-kind` — тема `02. Квадратурные методы`, одна страница на темы 2–3. Уравнение Фредгольма, Вольтерра и нелинейное Вольтерра $K(x,s,y)$ (переменная `y` разрешена парсером numkit для таких ядер). Методы: квадратуры (трапеции, Симпсон), простая итерация на сетке трапеций, вырожденные ядра, Галёркин–Петров, коллокация. Число неизвестных $N$ — узлы, члены ряда или базисные функции, график погрешности по $N$ строится для всех выбранных методов сразу
  - Вырожденные ядра. Ряд Тейлора ядра по $x$ в точке $x_0$ строится без символьного дифференцирования: дерево формулы из парсера numkit вычисляется на отрезках ряда (арифметика струй, функции `exp`, `log`, `sin`, `cos`, `sqrt`, `atan`, `asin` и другие, степени с целым и нецелым показателем). Это точнее конечных разностей и не требует `eval`; ядро, не аналитическое в центре (`abs(x)` в нуле, `log(x)` в нуле), получает сообщение с полем `kernel`. Берутся первые $M$ ненулевых членов ряда, как в заметке: для $e^{-x^2s^2}$ нечётных степеней нет. Член считается нулевым, если его наибольший вклад на отрезке меньше $10^{-15}$ от размера ядра; когда ненулевых членов меньше $M$, `exhausted` сообщает, что ряд кончился. Оценка теоремы ($\|A\|$, $\|A-A_M\|$ по 41 значению $x$, $q$, $q/(1-q)\|y\|$) показана для выбранного $M$
  - Эталон. Точная формула, если её ввели. Иначе для Фредгольма — Нюстрём на составной формуле Гаусса из 16 узлов на панель, число панелей удваивается до совпадения двух соседних расчётов в $10^{-14}$ или до 32; для Вольтерра — трапеции на 2049 и 1025 узлах, шаг Ричардсона и кубическая интерполяция. Страница показывает, на сколько последний расчёт отличается от предыдущего: меньшие погрешности методов не различимы
  - Погрешность. У квадратур и простой итерации — наибольшая в узлах (как в таблицах заметок), у остальных — наибольшая по 401 точке отрезка. Галёркин–Петров строится один раз на $N_{\max}$ функций, решение для меньшего $N$ берёт ведущий блок: базисы вложены. Двойные интегралы $(K\varphi_j,\psi_i)$ считает адаптивный G7K15 numkit, внутренние интегралы запоминаются по $x$. Формула Симпсона в строках Вольтерра с нечётным числом промежутков заканчивается трапецией с весом $5h/6$, поэтому порядок схемы — третий, а не четвёртый
  - Система с $\operatorname{cond}_1>10^{12}$ помечена звёздочкой в таблице: пивот LU не равен нулю точно, но цифры решения ненадёжны
- `spectral` — тема `04. Спектральные задачи`. Симметричное ядро $K(x,s)$ на $[a,b]$ (разрыва производной на диагонали допустимы: $\min(x,s)$ пишется через `abs`). Блоки: эталон характеристических чисел, Келлог, следы, Ритц, затем метод вращений Якоби для вещественной симметричной матрицы до $5\times5$
  - Эталон. Собственные числа симметричной матрицы Нюстрёма $W^{1/2}KW^{1/2}$ на составной формуле Гаусса из 8 узлов на панель, панелей $1,2,4,\dots,32$, затем экстраполяция по шагу: последнее значение, если оно устоялось, иначе таблица Ричардсона для ошибки порядка $h^2$ и $h^4$ с наименьшим расхождением двух последних значений. У ядра с изломом на диагонали ошибка порядка $h^2$, Ричардсон даёт $10^{-9}$–$10^{-10}$ для $\min(x,s)$ и функции Грина. Собственные функции — обратная итерация на самой мелкой сетке и формула Нюстрёма, их точность около $10^{-4}$
  - Келлог и следы работают на 256 узлах без экстраполяции, их погрешность у ядра с изломом около $10^{-5}$, ниже на графике сходимости видна квадратура, а не метод. Отношение норм $r_n$ считается как $1/\|T v_{n-1}\|$ для нормированных $v$, а корень — из суммы логарифмов норм, поэтому 400 шагов не переполняют. Следы — $A_{2m}=\|S^m\|_F^2$ для той же матрицы $S$, без собственных чисел
  - Ритц. Матрицы $G$ и $M$ строятся один раз на $N_{\max}$ функций, внутренние интегралы $(K\varphi_k)(x)$ считает адаптивный G7K15 numkit с разрезом в точке $s=x$: без него ядро с изломом вблизи конца отрезка принималось за гладкое (ошибка $10^{-7}$ в одном интеграле), внешние идут на общей составной формуле Гаусса. Пучок приводится разложением Холецкого $M=LL^\top$ к симметричной матрице $L^{-1}GL^{-\top}$; корень ниже шума $10^{-11}\max|G|/\min M_{jj}$ считается нулевым, как $\sigma=0$ в заметке
  - Якоби. Шаг строит $Q$ явно и считает $Q^\top AQ$, а не по формулам заметки: тесты проверяют тождество $S(\hat A)=S(A)-2|a_{kl}|^2$, лемму $S(A_p)\leqslant\rho^pS(A_0)$, зануление выбранного элемента и $A_p=T_p^\top AT_p$. Угол $\varphi=\tfrac12\operatorname{atan2}(2a_{kl},a_{kk}-a_{ll})$ совпадает с числами заметки ($0{,}9079$)
