# Устойчивость по первому приближению

Устойчивость нулевого решения нелинейной системы определяет её [[f03. Динамические системы#Линеаризация|линеаризация]], если у матрицы линеаризации нет собственных чисел на мнимой оси. Определения [[f06. Наконец-то динамические системы#6.2 Теория устойчивости|устойчивости по Ляпунову и асимптотической устойчивости]] даны в матмоде, достаточные условия через функцию Ляпунова — в [[Теоремы Ляпунова и Четаева]]

## Нулевое решение нелинейной системы

### Система в отклонениях

Устойчивость решения $x=\varphi(t)$ системы $\dot x=f(t,x)$ сводится к устойчивости нулевого решения: для $y=x-\varphi(t)$ получаем $\dot y=f\bigl(t,y+\varphi(t)\bigr)-f\bigl(t,\varphi(t)\bigr)$, и $y\equiv0$ — решение. Выделим из правой части линейную часть с постоянной матрицей:
$$\dot y_i=a_{i1}y_1+\dots+a_{in}y_n+R_i(t,y_1,\dots,y_n),\quad i=\overline{1,n}$$
Матрица $A=(a_{ij})$ — **матрица первого приближения**. Остаток мал по сравнению с $|y|$ равномерно по $t$: $\sup\limits_{t\geqslant t_0}|R(t,y)|=o(|y|)$ при $y\to0$

Для автономной системы $\dot x=f(x)$ с $f\in C^1$ и положением равновесия $x^*$, $f(x^*)=0$, подстановка $y=x-x^*$ даёт такой вид с матрицей Якоби
$$A=\left(\frac{\partial f_i}{\partial x_j}\right)\Bigg|_{x=x^*}$$
Остаток есть $o(|y|)$ по определению дифференцируемости. Это та же [[f03. Динамические системы#Линеаризация|линеаризация]], что в матмоде

### Критерий по собственным числам

> [!success] Знаки вещественных частей собственных чисел $\lambda_i$ матрицы $A$ решают устойчивость нулевого решения
> 1. $\operatorname{Re}\lambda_i<0$ при всех $i$ — нулевое решение асимптотически устойчиво
> 2. $\operatorname{Re}\lambda_i>0$ хотя бы при одном $i$ — нулевое решение неустойчиво
> 3. $\operatorname{Re}\lambda_i\leqslant0$ при всех $i$ и $\operatorname{Re}\lambda_i=0$ хотя бы при одном $i$ — по первому приближению вывода нет, [[Устойчивость по первому приближению#Критический случай|решает остаток]] $R$
>
> > [!success]- Доказательство пункта 1 через квадратичную функцию Ляпунова
> > Положим $P=\displaystyle\int_0^{\infty}e^{A^{T}s}e^{As}\,ds$. Интеграл сходится: при $\operatorname{Re}\lambda_i<0$ найдутся $c,\mu>0$ с $\|e^{As}\|\leqslant ce^{-\mu s}$. Матрица $P$ симметрична и положительно определена: $y^TPy=\displaystyle\int_0^\infty|e^{As}y|^2ds>0$ при $y\neq0$. Интегрируя тождество $\dfrac{d}{ds}\bigl(e^{A^{T}s}e^{As}\bigr)=A^{T}e^{A^{T}s}e^{As}+e^{A^{T}s}e^{As}A$ по $s\in[0,\infty)$, получаем $A^TP+PA=-E$
> >
> > Пусть $v=y^TPy$ и $m=\lambda_{\min}(P)>0$, тогда $m|y|^2\leqslant v\leqslant\|P\|\,|y|^2$. Производная в силу системы
> > $$\frac{dv}{dt}=y^T(A^TP+PA)y+2y^TPR=-|y|^2+2y^TPR\leqslant-|y|^2+2\|P\|\,|y|\,|R|$$
> > Выберем $\rho>0$ так, что $|R|\leqslant\dfrac{|y|}{4\|P\|}$ при $|y|<\rho$ и всех $t$. В шаре $|y|<\rho$
> > $$\frac{dv}{dt}\leqslant-\frac12|y|^2\leqslant-\frac{v}{2\|P\|}$$
> > Возьмём $\varepsilon<\rho$ и $\delta=\varepsilon\sqrt{m/\|P\|}$. Если $|y(t_0)|<\delta$, то $v(t_0)<m\varepsilon^2$; пока решение в шаре, $v$ убывает, поэтому $m|y(t)|^2\leqslant v(t)<m\varepsilon^2$ и решение остаётся в шаре $|y|<\varepsilon$ при всех $t\geqslant t_0$. Там же $v(t)\leqslant v(t_0)e^{-(t-t_0)/(2\|P\|)}\to0$, откуда $y(t)\to0$ $\blacksquare$
>

### Критический случай

Если у $A$ есть собственное число с $\operatorname{Re}\lambda=0$ и нет чисел с $\operatorname{Re}\lambda>0$, нелинейные члены способны изменить исход[^crit]

> [!example] Центр линейной части при трёх остатках
> Система $\dot x=y+\varepsilon x(x^2+y^2)$, $\dot y=-x+\varepsilon y(x^2+y^2)$ имеет при любом $\varepsilon$ матрицу $A=\begin{pmatrix}0&1\\-1&0\end{pmatrix}$ с числами $\lambda=\pm i$. Для $r=\sqrt{x^2+y^2}$
> $$r\dot r=x\dot x+y\dot y=xy+\varepsilon x^2r^2-xy+\varepsilon y^2r^2=\varepsilon r^4\implies\dot r=\varepsilon r^3$$
> При $\varepsilon<0$ радиус убывает, $r^{-2}=r_0^{-2}-2\varepsilon t\to\infty$, и нулевое решение асимптотически устойчиво. При $\varepsilon=0$ траектории — окружности, и решение устойчиво, но не асимптотически. При $\varepsilon>0$ радиус растёт и за конечное время уходит из любого шара: решение неустойчиво

[^crit]: Не из лекции и практики: пример с тремя остатками

## Положения равновесия нелинейной системы

Для автономной системы $\dot x=f(x)$ порядок такой:

1. Положения равновесия — решения $f_1=\dots=f_n=0$ ([[f03. Динамические системы#Особые точки|особые точки]])
2. Матрица Якоби $\left(\dfrac{\partial f_i}{\partial x_j}\right)$ в общем виде, затем её значение в каждой точке
3. Собственные числа из $\det(A-\lambda E)=0$
4. Вывод по [[Устойчивость по первому приближению#Критерий по собственным числам|критерию]] отдельно для каждой точки

Для $n=2$ характеристическое уравнение — $\lambda^2-\operatorname{tr}A\,\lambda+\det A=0$, по формулам Виета $\lambda_1+\lambda_2=\operatorname{tr}A$, $\lambda_1\lambda_2=\det A$

> [!success] При $n=2$ нулевое решение асимптотически устойчиво при $\operatorname{tr}A<0$, $\det A>0$ и неустойчиво при $\det A<0$ или $\operatorname{tr}A>0$, $\det A>0$
> При $\det A<0$ числа вещественны и разных знаков. При $\det A>0$ они вещественны одного знака или комплексно сопряжены, и в обоих случаях знак $\operatorname{Re}\lambda_{1,2}$ совпадает со знаком $\operatorname{tr}A$. Это критерий [[f03. Динамические системы#Критерий Рауса-Гурвица|Рауса–Гурвица]] при $n=2$

## Тип особой точки

Уравнение $y'=\dfrac{Q(x,y)}{P(x,y)}$ — система $\dot x=P$, $\dot y=Q$ с исключённым временем: интегральные кривые уравнения — траектории системы. Особая точка — решение $P=Q=0$. Если оно не нулевое, $(x_0,y_0)\neq(0,0)$, замена $\xi=x-x_0$, $\eta=y-y_0$ переносит точку в начало, а матрицу $A$ берут из линейной части по $\xi,\eta$

Тип точки задают собственные числа $A$: [[f03. Динамические системы#Узел при различных вещественных числах одного знака|узел]] — вещественные числа одного знака, [[f03. Динамические системы#Седло|седло]] — вещественные числа разных знаков, [[f03. Динамические системы#Центр и фокус|фокус]] — комплексные числа с $\operatorname{Re}\lambda\neq0$, центр — чисто мнимые $\pm i\beta$

Для устойчивости смотрят на знак $\lambda$ или $\operatorname{Re}\lambda$: отрицательный — устойчивая точка, положительный — неустойчивая; седло неустойчиво, центр линейной системы устойчив, но не асимптотически. У нелинейной системы центр линейной части — [[Устойчивость по первому приближению#Критический случай|критический случай]]

При $\lambda_1=\lambda_2=\lambda\neq0$ точка — [[f03. Динамические системы#Кратное собственное значение|дикритический или вырожденный узел]]. Для $n=2$ дикритический при $A=\lambda E$ (два независимых собственных вектора), вырожденный при $A\neq\lambda E$, то есть при $\operatorname{rank}(A-\lambda E)=1$

Если одно из чисел равно нулю, $\det A=0$, и особые точки заполняют прямую $\ker A$. При $\lambda_2\neq0$ траектории — лучи на прямых, параллельных собственному вектору числа $\lambda_2$: они пересекают прямую особых точек. При $\lambda_1=\lambda_2=0$, $A\neq0$ траектории — прямые, параллельные $\ker A$; при $A=0$ неподвижна вся плоскость ([[f03. Динамические системы#Кратное собственное значение|кратное собственное значение]])

## Задачи

> [!example]- Задача 899. $\dot x=2xy-x+y,\ \dot y=5x^4+y^3+2x-3y$
> Нулевое решение: правые части в $(0,0)$ равны нулю, нелинейные члены $2xy$, $5x^4+y^3$ имеют порядок выше первого. Матрица первого приближения
> $$A=\begin{pmatrix}-1&1\\2&-3\end{pmatrix},\quad\lambda^2+4\lambda+1=0,\quad\lambda_{1,2}=-2\pm\sqrt3$$
> Оба числа отрицательны ([[Устойчивость по первому приближению#Критерий по собственным числам|критерий]])
> **Ответ:** нулевое решение асимптотически устойчиво

> [!example]- Задача 900. $\dot x=x^2+y^2-2x,\ \dot y=3x^2-x+3y$
> Линейная часть в нуле:
> $$A=\begin{pmatrix}2x-2&2y\\6x-1&3\end{pmatrix}\Bigg|_{(0,0)}=\begin{pmatrix}-2&0\\-1&3\end{pmatrix},\quad\lambda^2-\lambda-6=0,\quad\lambda_{1,2}=\frac{1\pm5}{2}=3,\ -2$$
> Число $\lambda_1=3$ положительно ([[Устойчивость по первому приближению#Критерий по собственным числам|критерий]], пункт 2)
> **Ответ:** нулевое решение неустойчиво

> [!example]- Задача 902. $\dot x=\ln(4y+e^{-3x}),\ \dot y=2y-1+\sqrt[3]{1-6x}$
> В нуле $\ln1=0$ и $-1+1=0$, то же положение равновесия. Матрица Якоби:
> $$A=\begin{pmatrix}\dfrac{-3e^{-3x}}{4y+e^{-3x}}&\dfrac{4}{4y+e^{-3x}}\\[2mm]\dfrac{-2}{(1-6x)^{2/3}}&2\end{pmatrix}\Bigg|_{(0,0)}=\begin{pmatrix}-3&4\\-2&2\end{pmatrix}$$
> $$\lambda^2+\lambda+2=0,\quad\lambda_{1,2}=\frac{-1\pm i\sqrt7}{2},\quad\operatorname{Re}\lambda_{1,2}=-\frac12<0$$
> **Ответ:** нулевое решение асимптотически устойчиво

> [!example]- Задача 904. $\dot x=\operatorname{tg}(y-x),\ \dot y=2^y-2\cos\left(\dfrac\pi3-x\right)$
> В нуле $\operatorname{tg}0=0$ и $1-2\cos\frac\pi3=0$. Матрица Якоби:
> $$A=\begin{pmatrix}-\dfrac1{\cos^2(y-x)}&\dfrac1{\cos^2(y-x)}\\[2mm]-2\sin\left(\dfrac\pi3-x\right)&2^y\ln2\end{pmatrix}\Bigg|_{(0,0)}=\begin{pmatrix}-1&1\\-\sqrt3&\ln2\end{pmatrix}$$
> $$\lambda^2+(1-\ln2)\lambda+\sqrt3-\ln2=0$$
> Дискриминант $(1-\ln2)^2-4(\sqrt3-\ln2)<0$, числа комплексные с $\operatorname{Re}\lambda_{1,2}=\dfrac{\ln2-1}{2}<0$. Тот же вывод даёт [[Устойчивость по первому приближению#Положения равновесия нелинейной системы|критерий через след и определитель]]: $\operatorname{tr}A=\ln2-1<0$, $\det A=\sqrt3-\ln2>0$
> **Ответ:** нулевое решение асимптотически устойчиво

> [!example]- Задача 915. $\dot x=y-x-x^2,\ \dot y=3x-y-x^2$
> Положения равновесия: сложение уравнений $0=y-x-x^2$ и $0=3x-y-x^2$ даёт $2x-2x^2=0$, откуда $x=0$ или $x=1$, а $y=x+x^2$. Точки $(0,0)$ и $(1,2)$. Матрица Якоби:
> $$A=\begin{pmatrix}-1-2x&1\\3-2x&-1\end{pmatrix}$$
> В точке $(0,0)$ матрица $\begin{pmatrix}-1&1\\3&-1\end{pmatrix}$, $\lambda^2+2\lambda-2=0$, $\lambda_{1,2}=-1\pm\sqrt3$: числа вещественны и разных знаков, точка — седло. В точке $(1,2)$ матрица $\begin{pmatrix}-3&1\\1&-1\end{pmatrix}$, $\lambda^2+4\lambda+2=0$, $\lambda_{1,2}=-2\pm\sqrt2$: оба числа отрицательны
> **Ответ:** $(0,0)$ неустойчива, $(1,2)$ асимптотически устойчива

> [!example]- Задача 916. $\dot x=(x-1)(y-1),\ \dot y=xy-2$
> Из $(x-1)(y-1)=0$ либо $x=1$ и тогда $y=2$, либо $y=1$ и тогда $x=2$. Точки $(1,2)$ и $(2,1)$. Матрица Якоби:
> $$A=\begin{pmatrix}y-1&x-1\\y&x\end{pmatrix}$$
> В точке $(1,2)$ матрица $\begin{pmatrix}1&0\\2&1\end{pmatrix}$, $(\lambda-1)^2=0$, $\lambda_{1,2}=1>0$. В точке $(2,1)$ матрица $\begin{pmatrix}0&1\\1&2\end{pmatrix}$, $\lambda^2-2\lambda-1=0$, $\lambda_{1,2}=1\pm\sqrt2$: одно число положительно
> **Ответ:** обе точки, $(1,2)$ и $(2,1)$, неустойчивы

> [!example]- Задача 918. $\dot x=\ln(-x+y^2),\ \dot y=x-y-1$
> Положения равновесия: $-x+y^2=1$ и $x=y+1$ дают $y^2-y-2=0$, $y=2$ или $y=-1$. Точки $(3,2)$ и $(0,-1)$, в обеих $y^2-x=1>0$. Матрица Якоби:
> $$A=\begin{pmatrix}\dfrac{-1}{y^2-x}&\dfrac{2y}{y^2-x}\\[2mm]1&-1\end{pmatrix}$$
> В точке $(3,2)$ матрица $\begin{pmatrix}-1&4\\1&-1\end{pmatrix}$, $\lambda^2+2\lambda-3=0$, $\lambda_{1,2}=1,\ -3$: седло. В точке $(0,-1)$ матрица $\begin{pmatrix}-1&-2\\1&-1\end{pmatrix}$, $\lambda^2+2\lambda+3=0$, $\lambda_{1,2}=-1\pm i\sqrt2$, $\operatorname{Re}\lambda_{1,2}=-1<0$
> **Ответ:** $(3,2)$ неустойчива, $(0,-1)$ асимптотически устойчива

> [!example]- Задача 966. $y'=\dfrac{2x-y}{x-y}$
> Система $\dot x=x-y$, $\dot y=2x-y$, особая точка $(0,0)$. Метод — [[Устойчивость по первому приближению#Тип особой точки|тип по собственным числам]]:
> $$A=\begin{pmatrix}1&-1\\2&-1\end{pmatrix},\quad\lambda^2+1=0,\quad\lambda_{1,2}=\pm i$$
> **Ответ:** центр

> [!example]- Задача 981. $\dot x=3x,\ \dot y=2x+y$
> $$A=\begin{pmatrix}3&0\\2&1\end{pmatrix},\quad\lambda^2-4\lambda+3=0,\quad\lambda_{1,2}=\frac{4\pm2}{2}=1,\ 3$$
> Числа вещественны, различны и положительны ([[Устойчивость по первому приближению#Тип особой точки|тип по собственным числам]])
> **Ответ:** неустойчивый узел

> [!example]- Задача 962. $y'=\dfrac{x-4y}{2y-3x}$
> Система $\dot x=2y-3x$, $\dot y=x-4y$, особая точка $(0,0)$ единственна, так как $\det A\neq0$:
> $$A=\begin{pmatrix}-3&2\\1&-4\end{pmatrix},\quad\lambda^2+7\lambda+10=0,\quad\lambda_{1,2}=\frac{-7\pm3}{2}=-5,\ -2$$
> Числа вещественны, различны и отрицательны ([[Устойчивость по первому приближению#Тип особой точки|тип по собственным числам]])
> **Ответ:** устойчивый узел

> [!example]- Задача 973. $\dot x=x+3y,\ \dot y=-6x-5y$
> $$A=\begin{pmatrix}1&3\\-6&-5\end{pmatrix},\quad\lambda^2+4\lambda+13=0,\quad D=16-52=-36,\quad\lambda_{1,2}=\frac{-4\pm6i}{2}=-2\pm3i$$
> Числа комплексные с $\operatorname{Re}\lambda=-2<0$ ([[Устойчивость по первому приближению#Тип особой точки|тип по собственным числам]])
> **Ответ:** устойчивый фокус

> [!example]- Задача 963. $y'=\dfrac{-2x+y}{y}$
> Система $\dot x=y$, $\dot y=-2x+y$, особая точка $(0,0)$:
> $$A=\begin{pmatrix}0&1\\-2&1\end{pmatrix},\quad\lambda^2-\lambda+2=0,\quad D=1-8=-7,\quad\lambda_{1,2}=\frac{1\pm i\sqrt7}{2}$$
> Числа комплексные с $\operatorname{Re}\lambda=\dfrac12>0$ ([[Устойчивость по первому приближению#Тип особой точки|тип по собственным числам]])
> **Ответ:** неустойчивый фокус

> [!example]- Задача 972. $\dot x=2x-y,\ \dot y=x-1$
> Равновесие: $x-1=0$ и $2x-y=0$ дают точку $(1,2)$. Замена $\xi=x-1$, $\eta=y-2$ приводит к системе $\dot\xi=2\xi-\eta$, $\dot\eta=\xi$:
> $$A=\begin{pmatrix}2&-1\\1&0\end{pmatrix},\quad\lambda^2-2\lambda+1=0,\quad\lambda_{1,2}=1$$
> Кратное число, $A\neq E$: $\operatorname{rank}(A-E)=1$, один собственный вектор ([[Устойчивость по первому приближению#Тип особой точки|тип по собственным числам]])
> **Ответ:** точка $(1,2)$ — неустойчивый вырожденный узел

> [!example]- Задача 976. $\dot x=3x+y,\ \dot y=-x+y$
> $$A=\begin{pmatrix}3&1\\-1&1\end{pmatrix},\quad\lambda^2-4\lambda+4=0,\quad\lambda_{1,2}=2$$
> Кратное число, $A-2E=\begin{pmatrix}1&1\\-1&-1\end{pmatrix}\neq0$ имеет ранг 1: собственный вектор один, матрица не скалярная ([[Устойчивость по первому приближению#Тип особой точки|тип по собственным числам]])
> **Ответ:** неустойчивый вырожденный узел

> [!example]- Задача 979. $y'=\dfrac{2y-x}{3x+6}$
> Система $\dot x=3x+6$, $\dot y=2y-x$. Особая точка: $3x+6=0$ и $2y-x=0$ дают $(-2,-1)$. Замена $\xi=x+2$, $\eta=y+1$:
> $$\dot\xi=3\xi,\quad\dot\eta=2\eta-\xi,\qquad A=\begin{pmatrix}3&0\\-1&2\end{pmatrix}$$
> $$\lambda^2-5\lambda+6=0,\quad\lambda_{1,2}=\frac{5\pm1}{2}=2,\ 3$$

> **Ответ:** точка $(-2,-1)$ — неустойчивый узел

> [!example]- Задача 980. $y'=\dfrac{2x+y}{x-2y-5}$
> Система $\dot x=x-2y-5$, $\dot y=2x+y$. Особая точка: $x-2y=5$ и $2x+y=0$ дают $x=1$, $y=-2$. Замена $\xi=x-1$, $\eta=y+2$:
> $$\dot\xi=\xi-2\eta,\quad\dot\eta=2\xi+\eta,\qquad A=\begin{pmatrix}1&-2\\2&1\end{pmatrix}$$
