# Методы пристрелки и прогонки

## Постановка

> [!note] Краевая задача для $y''+p(x)\,y'+q(x)\,y=f(x)$ на $[x_1,x_2]$ с однородными условиями
> $$\begin{cases}y'(x_1)+\alpha\,y(x_1)=0\\[2pt]y'(x_2)+\beta\,y(x_2)=0\end{cases}$$
> Предполагается, что однородная задача — $f\equiv0$ при тех же условиях — имеет только нулевое решение, тогда [[Краевая задача для линейного уравнения второго порядка#Единственность решения неоднородной задачи|неоднородная задача имеет единственное решение]]

Эти условия получаются из [[Краевая задача для линейного уравнения второго порядка#Краевые условия|краевых условий]] при $\alpha_k\neq0$ делением на $\alpha_k$: $\alpha=\beta_1/\alpha_1$, $\beta=\beta_2/\alpha_2$. Буквы $\alpha$, $\beta$ здесь значат другое, чем там, а условие первого рода ($\alpha_k=0$) этой формой не покрыто

Оба метода сводят краевую задачу к [[Теорема существования и единственности решения задачи Коши#Задача Коши|задачам Коши]]

## Метод пристрелки

> [!summary] Пристрелка: решение — комбинация $y_1+\varepsilon y_2$ двух решений задач Коши с условиями при $x=x_1$
> 1. $y_1$ — решение неоднородного уравнения с условиями Коши $y_1(x_1)=\gamma$, $y_1'(x_1)=-\alpha\gamma$, где $\gamma$ — любое число
> 2. $y_2$ — решение однородного уравнения с условиями Коши $y_2(x_1)=\delta$, $y_2'(x_1)=-\alpha\delta$, где $\delta\neq0$ — любое число
> 3. $y=y_1+\varepsilon y_2$ при $\forall\varepsilon$ решает уравнение и первое краевое условие, а $\varepsilon$ подбирается под второе:
> $$\boxed{\,\varepsilon=-\frac{y_1'(x_2)+\beta\,y_1(x_2)}{y_2'(x_2)+\beta\,y_2(x_2)}\,},\qquad y_2'(x_2)+\beta\,y_2(x_2)\neq0$$
>
> > [!success]- Доказательство подстановкой в уравнение и условия
> > Первое условие выполнено при любом $\varepsilon$:
> > $$y'(x_1)+\alpha\,y(x_1)=\bigl[-\alpha\gamma+\alpha\gamma\bigr]+\varepsilon\bigl[-\alpha\delta+\alpha\delta\bigr]=0$$
> > Уравнение тоже: $L[y]=L[y_1]+\varepsilon L[y_2]=f+\varepsilon\cdot0=f$ по [[Линейное уравнение порядка n#Линейность|линейности]] оператора $L[y]=y''+p\,y'+q\,y$. Второе условие при $x=x_2$:
> > $$y_1'(x_2)+\varepsilon\,y_2'(x_2)+\beta\bigl(y_1(x_2)+\varepsilon\,y_2(x_2)\bigr)=0$$
> > $$\bigl[y_1'(x_2)+\beta\,y_1(x_2)\bigr]+\varepsilon\bigl[y_2'(x_2)+\beta\,y_2(x_2)\bigr]=0,$$
> > откуда $\varepsilon$ — формула выше
> >
> > > [!important] Знаменатель не равен нулю
> > > Функция $y_2$ не нулевая: $y_2(x_1)=\delta\neq0$. Если бы знаменатель обращался в нуль, $y_2$ удовлетворяла бы и второму условию, то есть была бы ненулевым решением однородной краевой задачи. Это противоречит предположению $\blacksquare$

Все кривые выходят из $x_1$ с наклоном $-\alpha y$, потому что $y'(x_1)=-\alpha\,y(x_1)$ у каждой. Второе условие $y'(x_2)+\beta y(x_2)=0$ выполняет одна из них[^fig]

## Метод прогонки

> [!summary] Прогонка раскладывает оператор уравнения в произведение двух операторов первого порядка
> $$\Bigl[\frac{d}{dx}+\mu\Bigr]\Bigl[\frac{d}{dx}+\nu\Bigr]y=f(x)$$
> Функции $\mu(x)$ и $\nu(x)$ подбираются так, чтобы произведение совпало с левой частью исходного уравнения:
> $$\begin{cases}\mu+\nu=p\ \Rightarrow\ \mu=p-\nu\\[2pt]\nu'+\mu\nu=q\end{cases}$$
>
> > [!success]- Доказательство раскрытием скобок
> > $$\Bigl[\frac{d}{dx}+\mu\Bigr]\bigl(y'+\nu y\bigr)=y''+\nu'y+\nu y'+\mu y'+\mu\nu y=y''+(\mu+\nu)\,y'+(\nu'+\mu\nu)\,y,$$
> > что равно $y''+p\,y'+q\,y$ при условиях на $\mu$ и $\nu$ $\blacksquare$

Подстановка $\mu=p-\nu$ во второе условие даёт для $\nu$ уравнение Риккати $\nu'+\nu\,(p-\nu)=q$. Метод строится из трёх задач Коши

> [!summary] Прогонка сводит краевую задачу к трём задачам Коши
> 1. Для $\nu$: $\ \nu'+\nu\,[p-\nu]=q$, $\ \nu(x_1)=\alpha$
> 2. Для $z=y'+\nu y$: $\ z'+[p-\nu]\,z=f$, $\ z(x_1)=0$
> 3. Для $y$: $\ y'+\nu y=z$, $\ y(x_2)=A$
>
> Условие $\nu(x_1)=\alpha$ вместе с первым краевым условием даёт $z(x_1)=y'(x_1)+\alpha\,y(x_1)=0$

Подстановка $z=y'+\nu y$ в левую часть уравнения для $z$ и уравнение Риккати для $\nu$ возвращают левую часть исходного уравнения:
$$z'+(p-\nu)\,z=y''+\nu'y+\nu y'+(p-\nu)\,y'+(p-\nu)\,\nu\,y=y''+p\,y'+\bigl(\nu'+p\nu-\nu^2\bigr)\,y=y''+p\,y'+q\,y$$

> [!success] Значение $A=y(x_2)$ определяется вторым краевым условием
> $$\begin{cases}y'(x_2)+\beta\,y(x_2)=0\\[2pt]y'(x_2)+\nu(x_2)\,y(x_2)=z(x_2)\end{cases}\ \Rightarrow\ \boxed{\,A=y(x_2)=\frac{z(x_2)}{\nu(x_2)-\beta}\,}$$
> Вычитание первого уравнения из второго даёт $\bigl(\nu(x_2)-\beta\bigr)\,y(x_2)=z(x_2)$

Порядок решения: $\nu$ и $z$ — слева направо от $x_1$ до $x_2$, затем $y$ — справа налево от $x_2$ до $x_1$ по условию $y(x_2)=A$[^ex]

[^ex]: Пример не из лекции: для уравнения и параметров из рисунка $\nu(x_2)-\beta\approx0.061$, а $A=y(2)\approx5.917$ совпадает со значением решения пристрелки

> [!warning] Прогонка требует, чтобы решение $\nu$ уравнения Риккати существовало на всём $[x_1,x_2]$[^ric]
> Если $\nu$ определена на $[x_1,x_2]$, то $\nu(x_2)\neq\beta$ — иначе однородная задача имела бы ненулевое решение. Решение нелинейного уравнения Риккати может уйти в бесконечность внутри отрезка, и тогда прогонка не применима
>
> > [!success]- Доказательство от противного
> > Пусть $\nu(x_2)=\beta$. Решение $y$ задачи Коши $y'=-\nu y$, $y(x_2)=1$ не нулевое, и для него $z=y'+\nu y\equiv0$. Тогда $y''+p\,y'+q\,y=z'+(p-\nu)\,z=0$, то есть $y$ решает однородное уравнение. Краевые условия:
> > $$y'(x_1)+\alpha\,y(x_1)=\bigl(\alpha-\nu(x_1)\bigr)\,y(x_1)=0,\qquad y'(x_2)+\beta\,y(x_2)=\bigl(\beta-\nu(x_2)\bigr)\,y(x_2)=0$$
> > Это ненулевое решение однородной краевой задачи, что противоречит предположению $\blacksquare$

[^ric]: Пример не из лекции: при $p=1+x$, $q=2+\cos x$, $\alpha=0.7$ на $[0,2]$ решение $\nu$ уходит в бесконечность около $x\approx1.01$
