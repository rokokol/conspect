# Метод Чернова
$$\boxed{P(S_n\geqslant a)\leqslant\min_{\lambda>0}e^{-\lambda a}\,\prod_{i=1}^n\mathsf{E}e^{\lambda\xi_i}}$$
В отличие от степенных оценок Чебышёва, метод даёт **экспоненциально** убывающий хвост — то, что нужно для теории больших уклонений и [[Случайное блуждание на прямой|концентрации сумм]]

Метод стоит на [[Моменты#Производящая функция моментов|производящей функции моментов]] $M_\xi(\lambda)=\mathsf{E}e^{\lambda\xi}$ — из неё берём оценку сверху для одного слагаемого и [[Моменты#Мультипликативность по независимости|мультипликативность по независимости]] $M_{S_n}(\lambda)=\prod_i M_{\xi_i}(\lambda)$, превращающую функцию суммы в произведение

## Общая схема [52:58](https://www.youtube.com/watch?v=TmN-kgWhB_E&t=3178s)

> [!success] Граница Чернова для суммы независимых величин
> Пусть $\xi_1,\dots,\xi_n$ [[Независимость случайных величин|независимы]] и у каждой существует $M_{\xi_i}(\lambda)$ при $\lambda>0$. Тогда для любого $a$
> $$P(S_n\geqslant a)\leqslant e^{-\lambda a}\prod_{i=1}^n M_{\xi_i}(\lambda)\quad ~ \forall \lambda>0 \implies P(S_n\geqslant a)\leqslant\min_{\lambda>0}\Big(e^{-\lambda a}\prod_i M_{\xi_i}(\lambda)\Big)$$
>
> > [!success]- Три шага: экспонента → Марков → оптимизация
> > **1. Экспонента + [[Неравенство Маркова|Марков]].** Экспонента монотонна, поэтому событие не меняется, а под Маркова попадает заведомо положительная величина:
> > $$P(S_n\geqslant a)=P\big(e^{\lambda S_n}\geqslant e^{\lambda a}\big)\leqslant\frac{\mathsf{E}e^{\lambda S_n}}{e^{\lambda a}}=e^{-\lambda a}\,M_{S_n}(\lambda)$$
> > **2. Факторизация** [55:18](https://www.youtube.com/watch?v=TmN-kgWhB_E&t=3318s)**.** По мультипликативности момент-функции $M_{S_n}(\lambda)=\prod_i M_{\xi_i}(\lambda)$ — здесь и нужна независимость
> > **3. Оптимизация** [1:03:29](https://www.youtube.com/watch?v=TmN-kgWhB_E&t=3809s)**.** Неравенство верно при *каждом* $\lambda>0$, значит верно и для наилучшего — берём $\min_\lambda$. Обычно показатель оказывается выпуклым по $\lambda$, и минимум находится из $\tfrac{d}{d\lambda}=0$ явно $\blacksquare$

Метод не использует никаких предельных переходов — в отличие от [[Центральная предельная теорема|ЦПТ]], которая лишь *подсказывает* форму ответа, но не даёт строгой оценки скорости

## Субгауссовость [1:01:16](https://www.youtube.com/watch?v=TmN-kgWhB_E&t=3676s)

Чтобы схема заработала, нужна оценка момент-функции одного слагаемого сверху. Для ограниченных величин она гауссова по форме

> [!important] Субгауссова оценка момент-функции
> Случайную величину зовут **субгауссовой**, если её момент-функция мажорируется гауссовой:
> $$M_\xi(\lambda)=\mathsf{E}e^{\lambda\xi}\leqslant e^{\sigma^2\lambda^2/2}\qquad\text{при всех }\lambda$$
> Тогда метод Чернова сразу даёт хвост $P(S_n\geqslant a)\leqslant e^{-a^2/(2n\sigma^2)}$ — ровно гауссовский по форме, хотя сами $\xi_i$ гауссовыми не были

> [!example] Симметричный $\pm1$ субгауссов с $\sigma^2=1$ [1:01:16](https://www.youtube.com/watch?v=TmN-kgWhB_E&t=3676s)
> Для $\xi=\pm1$ равновероятно момент-функция есть [[Гиперболические функции|гиперболический косинус]]
> $$M_\xi(\lambda)=\tfrac12 e^{\lambda}+\tfrac12 e^{-\lambda}=\operatorname{ch}\lambda$$
> Нечётные степени в разложении гасятся, а из элементарного $(2k)!\geqslant 2^k\,k!$ получаем
> $$\operatorname{ch}\lambda=\sum_{k=0}^\infty\frac{\lambda^{2k}}{(2k)!}\leqslant\sum_{k=0}^\infty\frac{(\lambda^2/2)^k}{k!}=e^{\lambda^2/2}$$
> Это **лемма Хёффдинга** в простейшем виде: $\pm1$ субгауссова с $\sigma^2=1$. Именно она превращает общую схему в оценку $e^{-a^2/2n}$ для [[Случайное блуждание на прямой|блуждания]]

### Неравенство Хёффдинга

> [!tip] Тот же приём — для любых ограниченных независимых [56:00](https://www.youtube.com/watch?v=TmN-kgWhB_E&t=3360s)
> Общая лемма Хёффдинга утверждает: если $\xi_i\in[c_i,d_i]$ независимы, то $\mathsf{E}e^{\lambda(\xi_i-\mathsf{E}\xi_i)}\leqslant e^{\lambda^2(d_i-c_i)^2/8}$, откуда
> $$\boxed{P\big(S_n-\mathsf{E}S_n\geqslant a\big)\leqslant\exp\!\left(-\frac{2a^2}{\sum_i(d_i-c_i)^2}\right)}$$
> — **неравенство Хёффдинга**, рабочая лошадка концентрации в статистике и машинном обучении (оценки обобщающей способности, [[Доверительный интервал|доверительные интервалы]] для частот)
