# Исходники рисунков курса "Компьютерные сети"

Здесь лежат скрипты тех рисунков курса, чей исходник удалось восстановить. Тема ddlc и шрифты волта приходят из общего набора `Scripts/ddlc_figures/`, его на `sys.path` ставит `course.py`, он же задаёт корень курса. Роли заливок у схем заголовков общие и живут в `netfig.py`

| Скрипт | Рисунки |
| --- | --- |
| `tcp_header.py` | `Раскладка заголовка TCP.png` |
| `cwnd.py` | `Окно перегрузки Tahoe и Reno.png` |
| `rip_timers.py` | `Таймеры RIP после последнего апдейта.png` |
| `ipv6_header.py` | `Раскладка заголовка IPv6.png` |
| `tunnels.py` | `Заголовки IP-in-IP и GRE.png`, `Кадр VXLAN поверх IPv4.png` |

Остальные рисунки курса (кабели, Ethernet, 802.1Q, IPv4) сделаны в августе 2026, их скрипты не сохранились ни в git, ни в журналах сессий, и они пока в старой теме

## Запуск

Окружение — venv курса "Тренировки по ML" с закреплёнными версиями, его `.sources/README.md` говорит, как его собрать

```bash
~/.cache/ml-trainings-digitization/.venv/bin/python tcp_header.py
```
