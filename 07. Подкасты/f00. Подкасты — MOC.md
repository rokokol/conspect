# Подкасты — MOC

> Конспекты подкастов и интервью. Связанные с ними мысли
```dataview
TABLE WITHOUT ID
  file.link AS "Эпизод",
  summary AS "О чём",
  published AS "Дата"
FROM "07. Подкасты"
WHERE !contains(file.path, "00. Вложения") AND file.name != this.file.name
SORT published DESC, file.name ASC
```
