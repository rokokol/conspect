# Модификация документов
`update` принимает **два документа**: первый — условие (какую выборку менять), второй — инструкция (как менять). По умолчанию обновляется **только один** документ, а операторы вроде `$inc` атомарны на уровне документа

## $set, $inc, $unset [36:26](https://www.youtube.com/watch?v=_I9vLOAsFew&t=2186s)
- **`$set`** — устанавливает значение; ключ создаётся, даже если его не было (комбинация set и update)
- **`$inc`** — увеличивает поле на любое значение (фактически `+=`); **атомарная** операция на уровне документа. Если поля не было — создаст
- **`$unset`** — удаляет атрибут из документов (значение в `$unset` не важно — пишешь что угодно, поле всё равно удаляется)

> [!warning] update по умолчанию трогает один документ — нужен multi ^multi
> Чтобы обновить **все** документы по условию, надо явно передать `{multi: true}` (или соответствующий позиционный аргумент). Забыл — изменится только первый совпавший

## upsert = update + insert [45:47](https://www.youtube.com/watch?v=_I9vLOAsFew&t=2747s)
**upsert** (`{upsert: true}`): документа нет — вставить, есть — обновить по заданным атрибутам. Прямой аналог [[Модификация данных (DML)#INSERT [2 12 59](https //www.youtube.com/watch?v=dGwkG2VyDTY&t=7979s)|`INSERT ... ON CONFLICT` в PostgreSQL]]

## Операции с массивами [38:18](https://www.youtube.com/watch?v=_I9vLOAsFew&t=2298s)
[[Документы и коллекции|BSON]] — расширенный [[Слабоструктурированные данные и JSON|JSON]], массивы в нём есть, и с ними работают как с динамическими:

- **`$push`** — добавить в конец массива (массив создастся, если его не было)
- **`$pop`** — вынуть элемент с конца или с начала массива
- **`$pull`** — вынуть элементы **по условию/значению** (удалить нехороший комментарий по его содержимому)
- **`$addToSet`** — добавить, трактуя массив как **математическое множество**: элемент добавится, только если его там ещё нет (без дублей, если это не мультимножество)
