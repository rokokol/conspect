# Генерация строк на лету
Иногда в запросе нужна **последовательность значений, которой нет в таблицах** — например, чтобы отчёт по дням не терял даты без продаж. `GROUP BY` по дате выкинет "пустые" дни; чтобы они попали в отчёт, серию дат генерируют и соединяют с данными через [[Соединения JOIN|LEFT JOIN]]

## Четыре способа получить серию [1:07:58](https://www.youtube.com/watch?v=nbmEBvoVAp0&t=4078s)
От самого громоздкого к самому коротком — все четыре дают одинаковый результат:

> [!example] Последовательность 1…5
> **Через `UNION ALL`** — в лоб, но на сотню чисел утомительно:
> ```sql
> SELECT 1 UNION ALL SELECT 2 UNION ALL SELECT 3
> UNION ALL SELECT 4 UNION ALL SELECT 5;
> ```
>
> **Через [[Подзапросы и обобщённые табличные выражения|рекурсивный CTE]]** — стандарт [[Определение данных (DDL)|SQL]], без расширений: якорь даёт стартовое значение, рекурсивная часть прибавляет 1, пока меньше $N$:
> ```sql
> WITH RECURSIVE seq(n) AS (
>     SELECT 1
>     UNION ALL
>     SELECT n + 1 FROM seq WHERE n < 5
> )
> SELECT n FROM seq;
> ```
>
> **Через `unnest()`** — развернуть массив в строки, по картежу на элемент:
> ```sql
> SELECT unnest(ARRAY[1, 2, 3, 4, 5]) AS n;
> ```
>
> **Через `generate_series()`** [1:10:24](https://www.youtube.com/watch?v=nbmEBvoVAp0&t=4224s) — "волшебная" функция Postgres, самый короткий путь:
> ```sql
> SELECT n FROM generate_series(1, 5) AS n;          -- 1..5
> SELECT d FROM generate_series('2017-01-01'::date,
>                               '2017-01-31'::date,
>                               '1 day') AS d;        -- все даты месяца
> ```

> [!note] generate_series — три аргумента
> `generate_series(start, stop, step)`: начало, конец и шаг. Шаг по умолчанию — единица; работает не только для чисел, но и для дат/времени (`interval`). `unnest` и `generate_series` в `FROM` ведут себя как таблица — им можно дать алиас столбца через `AS имя(столбец)`
