# Оконные функции
**Оконная функция** считает значение строки, зависящее от **порядка и группы соседних строк** — номер по порядку, ранг, первое/последнее значение в группе. В отличие от агрегата с `GROUP BY`, она **не схлопывает строки**: возвращает столько же строк, сколько было, добавляя к каждой посчитанную колонку

## Синтаксис OVER [23:17](https://www.youtube.com/watch?v=nbmEBvoVAp0&t=1397s)
Окно задаётся в `OVER (...)`: `PARTITION BY` режет строки на группы, `ORDER BY` задаёт порядок пробега внутри группы
```sql
SELECT name,
       department,
       row_number() OVER (PARTITION BY department ORDER BY salary DESC) AS rn
FROM employees;
```
![[Оконные функции.png]]

> [!warning] Без ORDER BY порядок не определён [23:47](https://www.youtube.com/watch?v=nbmEBvoVAp0&t=1427s)
> Если у `row_number()` нет `OVER (ORDER BY …)`, значения `1..N` всё равно присвоятся всем строкам, но **в произвольном порядке** — не обязательно `1, 2, 3` сверху вниз. Порядок сортировки внутри окна может **не совпадать** с сортировкой самого запроса (`ORDER BY` снаружи)

## Именованное окно [24:27](https://www.youtube.com/watch?v=nbmEBvoVAp0&t=1467s)
Чтобы не дублировать длинный `OVER (...)` у каждой функции, окно объявляют **один раз** в секции `WINDOW` (идёт после `FROM`) и ссылаются по имени
```sql
SELECT name,
       row_number() OVER w,
       rank()       OVER w
FROM employees
WINDOW w AS (PARTITION BY department ORDER BY salary DESC);
```

## Набор функций [25:12](https://www.youtube.com/watch?v=nbmEBvoVAp0&t=1512s)
| Функция | Что возвращает |
|---|---|
| `row_number()` | сквозной номер строки в окне |
| `rank()` | ранг с **пропусками** при совпадениях (1, 1, 3) |
| `dense_rank()` | ранг **без** пропусков (1, 1, 2) |
| `percent_rank()` | относительный ранг группы в долях $[0, 1]$ |
| `first_value(x)` | первое значение `x` в окне |
| `last_value(x)` | последнее значение `x` в окне |
| `nth_value(x, n)` | `n`-е значение `x` в окне |

> [!example] Любой сотрудник из каждого отдела [25:57](https://www.youtube.com/watch?v=nbmEBvoVAp0&t=1557s)
> Нужно по одному сотруднику на отдел — неважно какому. Вместо громоздкого `group by` с `first_value(name)`, `first_value(age)` Postgres даёт упрощённый синтаксис `DISTINCT ON`:
> ```sql
> SELECT DISTINCT ON (department) department, name, age
> FROM employees
> ORDER BY department;
> ```
> Перечисленное в `DISTINCT ON` поле должно быть уникальным в выводе; какая именно строка попадёт первой — определяет `ORDER BY` (а если порядок не задан — как повезёт)

> [!tip] FILTER — агрегат по части строк [25:01](https://www.youtube.com/watch?v=nbmEBvoVAp0&t=1501s)
> К оконной (и обычной) агрегатной функции можно добавить `FILTER (WHERE …)` — она учтёт только строки, прошедшие условие: `count(*) FILTER (WHERE active)`
