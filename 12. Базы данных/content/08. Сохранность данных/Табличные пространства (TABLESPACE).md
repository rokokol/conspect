# Табличные пространства (TABLESPACE)
**Табличное пространство** — именованное место на диске, куда физически кладутся данные. По умолчанию всё лежит в одном каталоге кластера, но таблицы и индексы можно раскидать по разным носителям [01:09:17](https://www.youtube.com/watch?v=ocmHxM52CLo&t=4157s)

```sql
CREATE TABLESPACE fastspace LOCATION '/ssd1/postgresql/data';
CREATE TABLE cinemas (...) TABLESPACE fastspace;        -- таблицу на быстрый диск
CREATE INDEX code_idx ON films (...) TABLESPACE indexspace;  -- индекс отдельно
```

> [!tip] Горячее — на [[Стоимость операций|SSD]], холодное — на дешёвый диск
> Простой способ управлять производительностью на уровне железа: часто читаемую таблицу или её [[Индекс B-tree\|индекс]] размещают на быстром SSD, а редкий архив — на ёмком [[Стоимость операций|HDD]]. Разнести индекс и таблицу по разным физическим дискам — ещё и способ распараллелить ввод-вывод
