# Физические резервные копии (pg_basebackup и снапшоты)
**Физическая копия** — побайтовое копирование файлов кластера. Восстановление быстрое (файлы просто кладутся на место), но копия привязана к версии и архитектуре и **не проверяет целостность** данных [15:19](https://www.youtube.com/watch?v=ocmHxM52CLo&t=919s)

## pg_basebackup
Штатный инструмент: стримит весь каталог данных по протоколу репликации, не требуя останавливать сервер
```sql
pg_basebackup -D /tmp/backup -Ft -z -P    -- в каталог: tar, gzip, прогресс
pg_basebackup -D - -Ft -P > backup.tar    -- потоком в один tar-архив
```
Вместе с файлами уезжают и [[Журнал транзакций (WAL)\|журналы]], так что копию потом можно **докатить** до нужного момента — то, чего логическая копия не умеет

## Снимок тома (LVM, ZFS, btrfs)
> [!note] Консистентная копия живой файловой системы через copy-on-write
> Чтобы скопировать файлы базы, которая прямо сейчас работает, файловая система делает **снимок** — мгновенную фиксацию состояния. Дальше система продолжает писать, а изменённые блоки сохраняются отдельно (copy-on-write), и снимок остаётся согласованным на момент создания. Этот снимок и копируют не спеша
> ```bash
> lvcreate --size 100M --snapshot --name snap /dev/vg00/lvol1   # LVM
> zfs snapshot datapool/docs@version1                            # ZFS
> ```

> [!danger] Целостность не проверяется
> Файлы копируются как есть. Если на диске уже завелась тихая порча, [[Логические резервные копии (pg_dump)#Чем хороша\|логическая копия]] поймала бы её при восстановлении, а физическая — добросовестно перенесёт битые байты в бэкап

## Обновление мажорной версии [34:28](https://www.youtube.com/watch?v=ocmHxM52CLo&t=2068s)
Между мажорными версиями физическая раскладка файлов меняется, поэтому новый сервер старый каталог данных просто так не прочитает. Перенос делает `pg_upgrade`: на вход — старый и новый каталоги данных, на выходе — мигрированный кластер
```bash
pg_upgrade --old-datadir ... --new-datadir ...   # ванильный PostgreSQL
pg_upgradecluster 9.5 main                        # обёртка Debian/Ubuntu
```
