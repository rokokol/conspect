# Реляционная алгебра
Операции реляционной алгебры берут отношения и возвращают **новое отношение** — поэтому их можно сцеплять. Каждая операция отвечает конструкции [[Определение данных (DDL)|SQL]]: запрос — это и есть запись алгебраического выражения

> [!important] SQL декларативен — описывает результат, а не алгоритм [35:13](https://www.youtube.com/watch?v=SfYaAQ9-RnE&t=2113s)
> Запрос на SQL — не императивная инструкция для движка ("открой таблицу, пробеги строки, сравни…"), а **запись того, какое отношение хочется получить**. *Как* его вычислить — забота [[Оптимизатор запросов\|оптимизатора]], он сам выбирает план. Отсюда же простор для оптимизации: один и тот же результат движок волен получить разными путями

## Сводка операций
| Операция | Что делает | SQL |
|---|---|---|
| **Выборка** (selection, $\sigma$) | оставляет строки по условию | `WHERE` |
| **Проекция** (projection, $\pi$) | оставляет столбцы, убирает дубли | `SELECT DISTINCT col…` |
| **Объединение** (union, $\cup$) | строки из обоих отношений | `UNION` |
| **Пересечение** (intersect, $\cap$) | строки, что есть в обоих | `INTERSECT` |
| **Разность** (minus, $\setminus$) | строки первого, которых нет во втором | `EXCEPT` / `MINUS` |
| **Произведение** ($\times$) | все пары строк двух отношений | `FROM a, b` |
| **Соединение** (join, $\bowtie$) | произведение + выборка по условию | `JOIN … ON` |
| **Деление** ($\div$) | строки, связанные со *всеми* строками второго | — (вручную) |

## Унарные операции: выборка и проекция [31:20](https://www.youtube.com/watch?v=SfYaAQ9-RnE&t=1880s)
**Выборка** фильтрует кортежи по условию — отношение трансформируется в подмножество своих же строк:
```sql
SELECT * FROM persons WHERE age >= 34;
```
**Проекция** выбирает подмножество атрибутов. Так как результат — отношение (множество), повторившиеся кортежи схлопываются — отсюда `DISTINCT`:
```sql
SELECT DISTINCT age, weight FROM persons;
```

## Теоретико-множественные операции [33:58](https://www.youtube.com/watch?v=SfYaAQ9-RnE&t=2038s)
[[Элементы теории множеств#Операции над множествами|Объединение, пересечение и разность]] требуют **совместимости по схеме** — оба отношения должны иметь одинаковый набор атрибутов с одинаковыми доменами:

![[Реляционная алгебра — теоретико-множественные операции.png]]

```sql
SELECT * FROM persons UNION     SELECT * FROM characters;  -- ∪
SELECT * FROM persons INTERSECT SELECT * FROM characters;  -- ∩
SELECT * FROM persons EXCEPT    SELECT * FROM characters;  -- разность
```

## Произведение, соединение, деление [40:31](https://www.youtube.com/watch?v=SfYaAQ9-RnE&t=2431s)
**Декартово произведение** даёт все комбинации строк двух отношений (`FROM a, b` без условия — частая причина случайно раздутых выдач).

**Соединение (join)** — это произведение, отфильтрованное выборкой по условию совпадения атрибутов. Самая ходовая операция при работе с несколькими таблицами; подробный разбор видов — в [[Соединения JOIN]]:
```sql
SELECT * FROM cartoons JOIN channels ON cartoons.channel_id = channels.id;
```

**Деление** возвращает строки, связанные со *всеми* строками второго отношения (запрос вида "кто заказывал все товары из списка"). Прямого оператора в SQL нет, на практике почти не используется — собирается вручную через группировку
