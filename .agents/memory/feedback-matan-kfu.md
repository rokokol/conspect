В заметках по курсу матанализа Сидорова А. М. использовать тег `кфу`, а не `мфти`

**Why:** Сидоров А. М. — лектор КФУ. Я по ошибке проставил тег `мфти`, опираясь на тег предыдущего оцифрованного курса (Райгородский, тервер — МФТИ)

**How to apply:** При создании новых заметок по матанализу Сидорова — `tags: [..., кфу, ...]`. При создании любого нового конспекта проверять источник лектора, не копировать тег вуза автоматически из предыдущего курса
