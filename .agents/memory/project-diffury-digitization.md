Решения Хозяина по курсу: динамическими системами, особыми точками и устойчивостью владеет матмод `f03`/`f06`; характеристический многочлен скалярного уравнения и матрицы — разные заметки; ДУ, ОДУ, ФСР, МВПП, Штурм–Лиувилль — алиасы в курсе, соседние курсы ссылаются (ФСР потом перешла линалу); решения, теряемые при делении, — "потерянные" (tip `^lost-solutions` в "Уравнения с разделяющимися переменными"), "особое" — только касание другим решением; на `p64` зачёркивание — описка Хозяина
