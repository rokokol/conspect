Курс `05. Конспекты/05. Линейная алгебра` (Карчевский Е. М., КФУ, "Алгебра и геометрия") оцифрован с фото тетради p001–p231: 74 заметки в 16 темах и "Метод главных компонент" (не из лекции, по просьбе Хозяина; владелец алиаса PCA). Тема 16 "Теория Фредгольма" — старые заметки Хозяина, переписанные по Colab-блокнотам Карчевского 2.1–2.4; блокноты снова скачиваются по id из `sources` заметок. Песочницы — `.sources/interactive/` (`lacore.js` поверх общего `numkit`). Волноводы и курс 18 — [[project-waveguides-numerics]]

Пособие `04. Книжная полка/Алгем Карчевский.pdf` — источник курса. Его известные ошибки: с. 203 единственность ЖФ, (5.12), с. 256/265 знак $\hat a$ через инварианты, с. 280 $1<k<n$

Владельцы: ФСР — линал ("Система линейных алгебраических уравнений"); Вандермонд, критерий Сильвестра, сопряжённый оператор — линал, соседние курсы ссылаются. Блокноты Карчевского — из двух курсов КФУ: "Спектральные задачи" (волноводы) и "Линейные операторы и интегральные уравнения" (Фредгольм, численные методы)

**How to apply:** при правках курса; процесс оцифровки — скилл `digitize`
