В блоках кода (SQL и пр.) таблицы и столбцы называть **по-английски, нормальными production-именами**, а не русской калькой из слайдов лектора: `Персоны` → `persons`, `Возраст` → `age`, `Мультфильмы`/`Каналы` → `cartoons`/`channels`, join по `cartoons.channel_id = channels.id`

**Why:** конспект — рабочий справочник; код должен выглядеть так, как пишут на практике, а не как учебный пример на русском

**How to apply:** прозу можно вести по-русски, но всё внутри ` ```sql ``` ` и инлайн-`code` — английские осмысленные идентификаторы (snake_case, `id`, `*_id` для внешних ключей). Правило родилось на курсе `05. Конспекты/12. Базы данных` и касается любого кода в волте
