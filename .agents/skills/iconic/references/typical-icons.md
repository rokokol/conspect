# Справка — типичные иконки волта

Источник истины по *выбору* иконки: какой эмодзи/lucide класть на заметку. Механика правки `data.json` — в `SKILL.md`

## Человечки на именных теоремах

Заметки с **именем учёного в названии** помечаются эмодзи-человечком (профессия/типаж), символизирующим этого учёного. Главное правило:

> [!important] Один учёный — один человечек, **сквозной по всем курсам**
> Кластеризация идёт по **названию заметки**: есть фамилия учёного → ставим его человечка. Один и тот же учёный получает **тот же** эмодзи в любом курсе (Коши-повар и в матане, и в тервере). Так заметки одного автора визуально слипаются в дереве

Каламбуры вместо человечка, где фамилия сама просится в образ: Жегалкин → 🔥 (жечь, зажигалка), Пост → 📮 (post), Кёниг → 🤴 (König), Хэмминг → 🔨 (hammer), Хаффман → 🌬️ (huff), Мур → 🐮, Карацуба → 🗡️ (цуба — гарда меча), Грин → 💚 (green), Штурм → ⛈️ (storm), Галёркин → 🎭 (галёрка), Ритц → 🏨 (отель Ritz), Келлог → 🥣 (хлопья Kellogg's)

Разовая вариация: **Радикальный признак Коши** — 🧝‍♂️ эльф (отступление от повара ради разнообразия среди множества признаков Коши). Системно держись таблицы

> [!tip] При добавлении нового учёного
> Подбери незанятый человечек (эмодзи-профессия `👨‍…`, `🧙‍♂️`/`🧔‍♂️`/`🧝‍♂️`, `👴`) с лёгкой ассоциацией, занеси сюда в таблицу и ставь его **на все** заметки с этой фамилией. Перед выбором — `grep '👨' data.json`, чтобы не задвоить

## Предметные эмодзи-метафоры (тервер)

Где имени учёного нет, тервер берёт **предметную** метафору по сути темы. Самые удачные — каламбуры и образы:

| Эмодзи | Заметка | Логика |
|---|---|---|
| 🪙 | Схема Бернулли | монетка — независимые испытания |
| 🍺 | Распределение Стьюдента | Госсет публиковался как "Student", работая пивоваром в Guinness |
| 🎣 | Распределение Фишера | Fisher → рыбалка |
| ⛓️ | Цепи Маркова | цепи |
| 🌊 | Характеристическая функция | волна (преобразование Фурье) |
| 🔔 | Нормальное распределение | колокол |
| ⛺ | Распределение Лапласа | острый шатёр двойной экспоненты (контраст к колоколу 🔔) |
| ⏳ | Показательное распределение | время до события |
| 🎯 | Геометрическое; неравенство Чебышёва | попадание / концентрация |
| 🧮 | Выборочное среднее и дисперсия | счёт по выборке |
| 🏆 | Метод максимального правдоподобия | максимум — победитель |
| 🥾 | Метод bootstrap | bootstrap — "сам себя за шнурки" |
| 🥊 | Критерий Неймана–Пирсона | две ошибки, бой гипотез |
| 🕸️ | Случайный граф | паутина (yellow) |

Принцип: иконка-метафора, читаемая с одного взгляда; цвет (`color`) — для немногих характерных (см. `SKILL.md` → "Цвета и цветные эмоджи")

## Lucide-метафоры (матан и общее)

Где эмодзи не точнее — lucide по смыслу темы: ряды → `lucide-sigma`, интеграл → `math-integral-x`, дробь → `math-x-divide-y-2`, экстремум → `lucide-mountain`, кривая → `lucide-route`, мера → `lucide-ruler`, сравнение → `lucide-diff`, 3D/дифференцируемость → `lucide-rotate-3d`, цепное правило → `lucide-waypoints`. Полный список конвенций — в `SKILL.md` → "Конвенции волта"
