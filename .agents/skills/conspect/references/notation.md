# Справка — математическая нотация (Obsidian MathJax)

Конвенции, на которых сошлись матан-корпус (f01–f25) и тервер/матстат (f01–f15). Источник истины по символам: сомневаешься, как писать — смотри сюда. Общие правила ниже, вероятностная нотация — в `## Теория вероятностей и статистика`. Графика, графики, схемы — в `math.md`

## Жёсткие предпочтения — вариант, который всегда выигрывает

| Пиши | НЕ пиши | Заметка |
|---|---|---|
| `\varepsilon` | `\epsilon` | ε-δ везде через `\varepsilon` (679 раз против 0) |
| `\varphi` | `\phi` | (245 против 0) |
| `\varnothing` | `\emptyset` | пустое множество |
| `\geqslant` `\leqslant` | `\geq` `\leq` | скруглённые знаки — стандарт корпуса (почти 100 %) |
| `\setminus` | `\backslash` | разность множеств |
| `\tan \arctan \cot \arccot` | `\tg \arctg \ctg \arcctg` | русские/европейские макросы в Obsidian MathJax **не определены** и выводятся голым текстом; в подписи скана внутри YAML-строки `sources` — двойной слэш `\\tan` |
| `\lvert x\rvert` | модуль палками внутри ячейки таблицы | таблица режет строку по палке раньше, чем MathJax видит формулу, и ячейка распадается; вне таблиц обычный модуль нормален |

## Дроби — `\dfrac` / `\tfrac` / `\frac`

- `\dfrac{a}{b}` — дробь **полного размера в инлайне** `$...$`, когда мелкая нечитаема (472 раза)
- `\tfrac{a}{b}` — **мелкая** дробь в строке, индексе, тесном месте: `\tfrac12`, `\tfrac\varepsilon2` (239 раз)
- `\frac` — по умолчанию в `$$...$$` display
- Дробь в **заголовке/якоре** — только `\frac{...}{...}`, никогда `0/0`: слэш `/` ломает якорь оглавления

## Ключевые символы и обозначения

| Конструкция | Запись | Смысл |
|---|---|---|
| Конец доказательства | `\blacksquare` в конце последней строки вывода | QED (177 раз) |
| Главный результат | `$$\boxed{...}$$` | headline-формула под H1 / итог раздела (106 раз) |
| Проколотая окрестность | `\mathring{U}_\delta(x_0)` | окрестность без самой точки (37 раз) |
| Шар | `B_r(x_0)` | стандарт вместо лекторского $Ш_r$ (оригинал — в сноску) |
| Равномерная сходимость | `f_n\overset{X}{\rightrightarrows} f`, `a_n\overset{X}{\rightrightarrows} 0` | множество **над** стрелкой через `\overset` |
| Поточечная сходимость | `f_n\xrightarrow{X} f` | множество над стрелкой |
| Несобственный интеграл | `\int_a^{\to b} f\,dx` | стремление к особой точке $b$ (44 раза) |
| Типизированное отображение | `f\colon X\to Y` | `\colon` (33 раза), не голый `:` |
| Числовые множества | `\mathbb{R}`, `\mathbb{Q}`, `\mathbb{N}`, `\mathbb{Z}` | |
| Расширенная прямая | `\overline{\mathbb{R}}` | |

## Теория вероятностей и статистика

Конвенции курса тервера/матстата (f01–f15). Вероятностные операторы — **через `\mathsf`**, не `\mathbb` и не `\mathrm`; вероятность — голым `P`

| Пиши | НЕ пиши | Смысл |
|---|---|---|
| `\mathsf{E}\xi` | `\mathbb{E}`, `\mathrm{E}`, `M\xi` | матожидание (273 раза, `\mathbb{E}` — 0) |
| `\mathsf{D}\xi` | `\mathbb{D}`, `\operatorname{Var}` | дисперсия (107 раз) |
| `P(A)` | `\mathsf{P}`, `\mathbb{P}` | вероятность — **голое** `P` (350 раз против 0) |
| `\mathbb{I}\{A\}`, `\mathbb{I}_A` | `\mathbf{1}`, `\mathbb{1}` | индикатор события (62 раза) |
| `\mathrm{cov}(\xi,\eta)` | `\operatorname{Cov}` | ковариация (10 раз) |
| `\rho` | `\operatorname{corr}` | коэффициент корреляции |
| `\widehat{\theta}` | `\hat{\theta}` | оценка параметра (184 против 8) |
| `\widehat F` | `\hat F`, `F_n^*` | эмпирическая функция распределения (15 раз) |
| `\binom{n}{k}` | `C_n^k`, `\dbinom` по умолчанию | биномиальный коэффициент (`\dbinom` — только где мелко) |
| `\ell(\theta)` | `\log L` голым | лог-функция правдоподобия |

### Распределения

`\mathrm{...}` для дискретных и именованных, `\mathcal{N}` для нормального; "распределено как" — `\sim`:

| Запись | Распределение |
|---|---|
| `\mathrm{Bin}(n,p)` | биномиальное |
| `\mathrm{Pois}(\lambda)` | пуассоновское |
| `\mathrm{Exp}(\lambda)` | показательное |
| `\mathrm{U}[a,b]` | равномерное |
| `\mathrm{Beta}(\alpha,\beta)` | бета |
| `\mathcal{N}(a,\sigma^2)` | нормальное |
| `\chi^2_n` | хи-квадрат с $n$ степенями свободы |
| `t_n`, `F_{n,m}` | Стьюдента, Фишера (квантили — `t_\alpha`) |

### Сходимости случайных величин

Тип сходимости — **над стрелкой** через `\xrightarrow{...}`:

| Запись | Смысл |
|---|---|
| `\xrightarrow{d}` | по распределению (17 раз) |
| `\xrightarrow{P}` | по вероятности (14 раз) |
| `\xrightarrow{\text{п.н.}}` | почти наверное (8 раз) |
| `\xrightarrow[n\to\infty]{}` | предел **под** стрелкой, когда тип не нужен |
| `\overset{d}{=}` | равенство по распределению |

## Дискретная математика

Конвенции курса Алексеева (`~/Projects/conspect/04. Дискретная математика`); где лектор пишет иначе, чем общий стандарт выше, выигрывает стандарт (`\binom{n}{k}`, а не его $C_n^k$)

| Пиши | НЕ пиши | Смысл |
|---|---|---|
| `E_2=\{0,1\}`, `E_2^n`, `E_k` | `\mathbb{E}_2^n`, `\{0,1\}^n` | множество значений и наборов |
| `\tilde\alpha=(\alpha_1,\dots,\alpha_n)` | `\bar\alpha`, `\vec\alpha` | набор: черта занята отрицанием |
| `\overline{x}`, `\overline{f(x,y)}` | `\neg x` | отрицание, черта накрывает подформулу |
| `xy`, `x\cdot y`; `\&` только в составе системы `\{\&,\vee,\neg\}` | `x\wedge y` | конъюнкция; большие операции по множеству — `\bigwedge`, `\bigvee`, `\bigoplus` |
| `\oplus`, `\sim`, `\to`, `\mid`, `\downarrow` | `\equiv` для эквивалентности, `/` для штриха | сумма по модулю 2, эквивалентность, импликация, штрих Шеффера, стрелка Пирса |
| `x^\sigma` | `x^{(\sigma)}` | $x$ при $\sigma=1$, $\overline{x}$ при $\sigma=0$ |
| `P_2`, `P_k`, `[A]`, `T_0`, `T_1`, `L`, `S`, `M` | `\mathcal{P}_2`, `\langle A\rangle` | все функции, замыкание, классы Поста; `[[A]]` писать как `[\,[A]\,]`, иначе Obsidian примет его за ссылку |
| `f^*` | `f^\vee` | двойственная функция |
| `G=(V,E)`, `p=\lvert V\rvert`, `q=\lvert E\rvert`, `r` — число граней, `\deg v` | `n`, `m` для числа вершин и рёбер | обозначения лектора на весь курс |
| `K_n`, `K_{m,n}`, `K_{3,3}` | `K_{33}` | полный и полный двудольный граф |
| `A^*`, `B^*`, `\Lambda` | `\varepsilon` для пустого слова | слова над алфавитом и пустое слово |
| `\rho(\tilde\alpha,\tilde\beta)`, `\rho_{\min}(K)` | `d(\cdot,\cdot)` | расстояние Хэмминга и кодовое расстояние |
| `a\vdots k`, `a\equiv b\pmod k` | `k\mid a` | делимость и сравнение по модулю |
| `(x_1\dots x_n)_2` | `\overline{x_1\dots x_n}` | число в двоичной записи |

## Пробелы и мелочи

- Инлайн-математика **без пробелов у `$`** — правило и примеры в `math.md` → "Базовое"
- Дифференциал в интеграле — `\,dx` (тонкий пробел перед `d`)
- `\,` тонкий · `\;` средний · `\quad` / `\qquad` крупные пробелы
- Кусочные функции — `\begin{cases}…\end{cases}`; системы и многострочные выводы — `\begin{multline}` / выравнивание по `=`
