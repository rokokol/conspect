# Анатомия матзаметки — теорема, доказательство, пример

Как в матане (f01–f25) собираются утверждения и их выводы. Роли callout по типам и свёрнутость по роли — в `callouts.md`, символы — в `notation.md`; здесь — как куски складываются

## Канонический блок: формулировка и доказательство

```markdown
> [!success] <результат одной фразой>
> <точная формулировка; при необходимости $$\boxed{...}$$>
>
> > [!success]- Доказательство
> > <вывод, развёрнутые шаги, в конце $\blacksquare$>
```

- **Формулировка → голый `[!success]`** (или `[!important]` / `[!summary]`+`boxed` для крупной теоремы). Видна всегда, без `+`/`-`
- **Доказательство → вложенный `[!success]-`** через `> >` **внутрь** утверждения, не соседним блоком; перед ним — строка-разделитель `>` (`callouts.md` → "Вложенные callout")
- Конец доказательства — `\blacksquare` (`notation.md` → "Ключевые символы и обозначения")

## Теорема без доказательства

Теорема приведена без вывода → **единый вид**: внутри её callout-а вложенный свёрнутый `note`:

```markdown
> [!summary] <Теорема>
> $$\boxed{...}$$
>
> > [!note]- Без доказательства
> > Идея: … (если лектор её обозначил; иначе только заголовок)
```

- **Только один вид.** НЕ `*(без доказательства)*` инлайном, НЕ отдельная сноска `[^…]`, НЕ `[!quote]`/`[!warning]` — всё это приводим к `> > [!note]- Без доказательства`
- Идея доказательства и "оставлено на учебник" — в теле note, а не в сноске
- Опущена лишь **часть** (например, достаточность) → заголовок `Достаточность — без доказательства`
- Это **пометка-плашка**, а не живая проза: фразу "лектор приводит … без доказательства" в потоке текста или подпись скана не трогаем

## Эталонные заметки (смотреть как образец)

- `Поточечная и равномерная сходимость` — формулировка `[!success]` + вложенное `[!success]-` доказательство по кругу
- `Точные грани множества` — теорема `[!important]` + `[!note]- Без доказательства` + следствие с вложенным доказательством; зонтичная группировка заголовков
- `Первый замечательный предел` — эталон boxed-лида под H1
- `Гамма-функция Эйлера` — boxed-лид, результаты-хайлайты `[!success]-` с выводом в теле
