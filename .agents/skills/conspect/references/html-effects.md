# Справка — html-эффекты, эмодзи, каомоджи

Это "цветные ручки и наклейки" в живой тетради. Стилизованные `<span class="...">` через плагин `text-snippets-obsidian`. CSS — в `.obsidian/snippets/`

> [!important] Когда уместно ✨
> - **Эмоциональный пик** в тексте (срыв, восторг, акцент на важном) — да
> - **Игровой элемент** в дневнике / Zettel — да
> - **Крик** в важном предупреждении (БЖД "ДЕРЖАТЬ ПОДАЛЬШЕ ОТ ДЕТЕЙ") — да
> - На каждом термине / каждом абзаце — нет, эффект ради эффекта не нужен ⚠️

## Шаблоны вставки

```html
<span class="neon-sign-text">АКЦЕНТ</span>

<span class="tv-glitch" data-text="ОШИБКА СИСТЕМЫ">ОШИБКА СИСТЕМЫ</span>

<span class="tv-glitch-full tv-static">срыв или мат</span>

<span class="rainbow-text">игривое</span>

<span class="wave-text"><span style="--i:0">в</span><span style="--i:1">о</span><span style="--i:2">л</span><span style="--i:3">н</span><span style="--i:4">а</span></span>

<span class="pixel-marquee">
<span style="--i:0">ВНИМАНИЕ</span>
<span style="--i:1">ВНИМАНИЕ</span>
<span style="--i:2">ВНИМАНИЕ</span>
</span>
```

### Эффекты с обязательным `data-text`

`psycho`, `vhs`, `glitch` — требуют атрибут `data-text` (он рисуется поверх как дублированный/искажённый слой):

```html
<span class="psychosis-text" data-text="АХАХАХАХАХАХА">АХАХАХАХАХАХА</span>
<span class="tv-glitch" data-text="ОШИБКА">ОШИБКА</span>
```

## Где какой эффект — практика

### Дневник

- Крик / громкая мысль / лозунг → `neon-sign-text`:
  ```html
  <span class="neon-sign-text">Возможна ли революция, где участниками будет бизнес?</span>
  ```
- Срыв / мат / пробой → `tv-glitch-full tv-static`:
  ```html
  <span class="tv-glitch-full tv-static">БЛЯЯЯЯТЬ</span>
  ```
- "Стрёмно" / отвращение → `sick-glow-text` или `tv-glitch-full tv-static`
- Игривое → `rainbow-text`

### Учебная заметка (БЖД, медицина)

- Сильное предупреждение для запоминания → `neon-sign-text`:
  ```html
  <span class="neon-sign-text">ДЕРЖАТЬ ПОДАЛЬШЕ ОТ ДЕТЕЙ ГОРЯЧИЙ ЧАЙ И ХИМИКАТЫ</span> (¬д¬。)
  ```
- В формальных математических конспектах — обычно нет

### Zettelkasten / стих

- Кульминация эмоционального текста → `tv-glitch` / `vortex-text` / `psychosis-text`
- Цветовой/политический акцент → `russia-text` / `ukraine-text` / `rainbow-text`

## Эмодзи — для акцента и живости

Используются как маркеры эмоций и тематик в конце смысловых блоков. Не злоупотребляем — это акценты, не фон. В учебной заметке — умеренно: красивый вывод, хитрый манёвр, наконец понятый сложный кусок, рефлексия в конце; в стене формальной матчасти их нет

### Тематические эмодзи

| Эмодзи | Используется для |
|---|---|
| ✨ | красивый вывод, элегантный результат |
| ⚠️ | внимание, предупреждение |
| ⛔ | запрет |
| 🪨 | твердость, грубость |
| 🪑 | скудность |
| 🫗 | заглушка, пустота |
| 🫥 | смущение, "ну ладно" |
| 😏 | хитрый манёвр, "я так и знал" |
| 😐 | стоицизм |
| 💀 | смех, нелепость, страх |

## Каомоджи — ＼(＾▽＾)／

Каомоджи (японские эмотиконы) — **любимая часть стиля**. Это та самая живость, которую дают цветные ручки и стикеры в живой тетради 🌈

Используй их свободно — после смыслового блока, как реакцию, как акцент, как настроение. Особенно в дневнике / Zettel, но и в учебных заметках с эмоциональной подложкой (БЖД, рефлексия в конце математической заметки)

### `:-)` — отдельная история 🎓

`:-)` — это **отсылка к преподавателю**, который писал ровно так. Он любил говорить, что что-то "очевидно", и придумывал необычные подходы к задачам. Поэтому `:-)` ставится:
- Чтобы подчеркнуть **причастность препода** к стилю мысли в этом месте ("очевидно, что...", изящный нестандартный приём)
- Для лёгкой **комичности**, ироничного подмигивания, "ну ты понял"

Уместно особенно в математических конспектах после красивого вывода или хитрого манёвра — там, где будто слышен голос препода :-)

**Канон — только `:-)`**. Сам препод писал именно его. Другие формы с дефисом (`:-D`, `:-(`, `:-P`, гибриды вроде `:->`) — уже производные: они наследуют дух канона, но строго преподовскими не являются. Используются как стилизованные потомки

Без дефиса (`:)`, `)`, `:D`) — обычные нейтральные смайлы без подтекста

### Комбинирование

Можно склеивать части в свои гибриды для нужного оттенка:

| Источники | Результат | Оттенок |
|---|---|---|
| `:>` + `:-)` | `:->` | хитрая улыбка с тем самым преподовским подтекстом |
| `>_>` + `>:3` | `>:3` | хитрющее подглядывание |

Каомоджи — конструктор. Собирай под настроение

### Шпаргалка каомоджи

| Каомоджи | Настроение |
|---|---|
| `:-)` | "очевидно" в стиле препода + комический подтекст (см. выше) |
| `:->` | гибрид: преподовский подтекст + лукавство |
| `:)` `)` | обычная нейтральная улыбка |
| `:-D` `:D` | смех |
| `:3` | милое лицо |
| `>:3` | лукавое |
| `^_^` | счастье |
| `(¬_¬)` | подозрительный взгляд |
| `(¬_¬;)` | напряжённое подозрение |
| `(¬д¬。)` | пренебрежительное "ну да, конечно" |
| `(;¬_¬)` | усталое подозрение |
| `(°_°)` | удивление / шок |
| `(°□°)` | "что?!" |
| `(ノಠ益ಠ)ノ` | ярость |
| `(╯°□°）╯︵ ┻━┻` | переворачивание стола |
| `┬─┬ノ( º _ ºノ)` | возвращение стола |
| `(´;ω;｀)` | плач |
| `(T_T)` | слёзы |
| `(つ﹏⊂)` | смущение / стыд |
| `(´∀｀)` | приятная улыбка |
| `(⌐■_■)` | "deal with it" |
| `(°▽°)` | весёлое |
| `(¯\\_(ツ)_/¯)` | пожатие плечами |
| `＼(＾▽＾)／` | радость / руки вверх |
| `(っ◔◡◔)っ ♥` | обнимашки |
| `(*≧ω≦)` | восторг |
| `(>ω<)` | смущённое восторженное |

Не ограничивайся списком — каомоджи можно собирать как угодно. Главное — настроение

## Комбинации эмодзи + каомоджи + html

В живых блоках норма ставить несколько маркеров подряд: для усиления, как живую подпись. Пример из дневника:

```markdown
Задумило заставиться 🫥🫥
```

```markdown
<span class="neon-sign-text">ДЕРЖАТЬ ПОДАЛЬШЕ ОТ ДЕТЕЙ ГОРЯЧИЙ ЧАЙ И ХИМИКАТЫ</span> (¬д¬。)
```

```markdown
И стать чуть мудрее. Снова 😏
```
