# Справка — чекбоксы

Расширенный набор чекбоксов из плагина (источник в волте — [[Доступные чекбоксы и callouts]])

## Базовые

```markdown
- [ ] to-do — нерешённая задача
- [/] incomplete — частично сделано
- [x] done — выполнено
- [-] canceled — отменено
- [>] forwarded — перенесено
- [<] scheduling — запланировано
```

## Расширенные

```markdown
- [?] question — вопрос
- [!] important — важно
- [*] star — звезда / выделение
- ["] quote — цитата
- [l] location — место
- [b] bookmark — закладка
- [i] information — информация
- [S] savings — сбережения
- [I] idea — идея
- [p] pros — плюсы
- [c] cons — минусы
- [f] fire — огонь / горячее
- [k] key — ключ / ключевое
- [w] win — победа
- [u] up — вверх
- [d] down — вниз
- [D] draft pull request — черновик PR
- [P] open pull request — открытый PR
- [M] merged pull request — слитый PR
```

## Где применять

| Сценарий | Чекбоксы |
|---|---|
| Список задач дня (Things Dump) | `[ ]`, `[x]`, `[-]`, `[>]` |
| Список правок по проекту (как `НИР`) | `[ ]`, `[x]`, `[/]` |
| Чтение источников при подготовке | `[x]` после прочтения, `[?]` если возник вопрос |
| Pros/cons список | `[p]` / `[c]` |
| Идеи в Zettel-инбоксе | `[I]` |
| Закладки внутри длинной заметки | `[b]` |
| Связанное с PR (если в Zettel есть рабочая заметка) | `[D]`, `[P]`, `[M]` |

## В смешанных списках

Можно мешать в одном списке для трекинга разных аспектов:

```markdown
- [x] Прочитал статью
- [I] Идея для развития: применить к задаче Фредгольма
- [?] Не понял доказательство леммы 2
- [b] Сюда вернуться при подготовке к зачёту
- [ ] Спросить у [[Федотов Павел Евгеньевич|Федотова]]
```
