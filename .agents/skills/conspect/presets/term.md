# Пресет — заметка-термин

Заметка-термин — владелец расшифровки сквозного термина: `ОС`, `CPU`, `RFC`. Все остальные заметки ставят на неё ссылку `[[Операционная система|ОС]]` и сами термин не расшифровывают

## Когда термин уходит сюда

Нужны оба условия:

- **Термин сквозной**: на него ссылаются заметки нескольких курсов или ядер, или это общее понятие, которое не принадлежит ни одной теме (`ПО`, `API`)
- **Естественного владельца нет**: ни одна заметка не объясняет термин по существу, а только расшифровывает его мимоходом. Владелец по имени или по содержанию — `Заголовок TCP и установление соединения` для TCP, `Золотое правило механики. КПД` для КПД, заметка `PIN в прошивке` для PIN кибер-сейфа — термин держит у себя, сюда он не уходит

Термин одного курса или ядра сюда не идёт: им владеет заметка этого курса, которая его объясняет, а без такой заметки он расшифровывается мимоходом там, где встретился (`SKILL.md` → "У расшифровки один владелец"). Если естественный владелец есть, но в другой заметке того же курса, термин переезжает к нему, а не сюда

## Имя файла

- **Устоявшееся русское название** для общего понятия: `Операционная система`, `Центральный процессор`, `Файловая система`
- **Сама аббревиатура** для стандарта, протокола, формата или технологии, которые и известны по аббревиатуре: `RFC`, `SSH`, `YAML`, `CUDA`. Так же названы курсовые `USB`, `SCSI`, `HTTP`. Ссылка на такую заметку — `[[RFC]]`, без подписи

## Метаданные

```yaml
---
created: 2026-10-03
aliases:
  - ОС                # аббревиатура, если имя файла — полное название
---
```

- `created` обязателен. `aliases` — аббревиатура, если имя файла — полное название, и её варианты, которые правда встречаются в волте (`CPU` и `ЦП`). Если имя файла — сама аббревиатура, в алиас идёт полное имя, только если по нему станут искать (`Secure Shell`)
- `title`, `summary`, `up`, `prev`, `next`, `lectures`, `sources` не пишутся: у папки нет MOC и цепи, а одну строку определения `summary` только повторил бы
- Тег не ставится: термин, который назвал бы тег, — это алиас заметки (`SKILL.md` → "### Теги")

## Тело

H1 — имя заметки. Под ним сразу один callout `[!note]`: в заголовке — расшифровка, в теле — определение:

```markdown
# Операционная система
> [!note] **Операционная система** (ОС)
> Комплекс системных программ, который распределяет ресурсы компьютера между программами и даёт им единый интерфейс к ним через системные вызовы
```

- **Расшифровка жирным в заголовке callout** — по форме из `SKILL.md` → "Аббревиатуру расшифровывать при первом появлении"
- **Расшифровка — на языке аббревиатуры** (`SKILL.md`, сноска `[^abbr-forms]`), и русское имя заметки её не заменяет: `**Центральный процессор** (ЦП, **CPU** — Central Processing Unit)`
- **Определение** — одна-три фразы: точное, с ключевым признаком понятия, со ссылками на заметки курсов, которые раскрывают его части (`[[Арифметико-логическое устройство|АЛУ]]`)
- **Списка "где встречается" нет** — его дают входящие ссылки. Заметка не перечисляет курсы и не пересказывает их материал

## Перенос термина от прежнего владельца

1. У прежнего владельца снять алиас аббревиатуры. Его расшифровку мимоходом заменить ссылкой на термин (`[[Операционная система|операционной системы]]`), текст остаётся грамотным; сноску, которая только расшифровывала, удалить
2. Входящие `[[Прежний владелец|ABC]]` с подписью ровно `ABC` перевести на `[[Термин|ABC]]` — по всему волту, кроме дневника. Ссылку, где прежний владелец выбран по смыслу (`[[Дизайн REST API|модуль 10]]`), не трогать
3. Проверка — `tools/lint.py` с `abbrev-no-alias`, `abbrev-redecoded`, `alias-collision` и `broken-link`: новых находок нет. Забытый у прежнего владельца алиас ловит `alias-collision`: свою расшифровку прежний владелец снял, а повтор аббревиатуры молчит, только если её расшифровывают обе заметки (`SKILL.md` → "### Связность")
