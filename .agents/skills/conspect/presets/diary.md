# Пресет — дневник

Применяй для `~/myWiki/03. Записки/01. Дневник/01. Daily/<YYYY-MM-DD DayOfWeek>.md` и периодических заметок

> [!tip] Дневник — пространство свободы 🫥
> Тут стиль самый раскрепощённый. Поток мыслей, рефлексия, риторические вопросы к самому себе, эмоциональные срывы и принятие чего-то нового
>
> Можно писать длинные потоки сознания, можно тезисно. Можно с эмодзи, html-эффектами, мат уместен в редких пиках. Главное — честность с собой

## Имя файла

`YYYY-MM-DD DayOfWeek.md`, например `2026-05-22 Friday.md`

## Метаданные

Базовый шаблон из `~/myWiki/01. Data/03. Templates/02. Dated Templates/daily_note_template.md`:

```yaml
---
tags:                                      # опционально — теги-настроения/темы дня:
  - рефлексия                              # продуктивность / ии / мысли / личное / ...
mark: 6                                    # субъективная оценка дня 0-10, можно с дробями (5.5, 6.3)
created: 2026-05-22                        # дата записи, шаблон ставит её сам
sleep hours: 9.5
weight: 84.4
neighbours:
  - "[[YYYY-MM-DD-1 DayOfWeek]]"           # предыдущий день
  - "[[YYYY-MM-DD+1 DayOfWeek]]"           # следующий
mood music: "[[<название трека>.mp3]]"
---
```

Любое поле кроме `created` можно оставить пустым, если данных нет; год записи несёт `created` и имя файла, тега года нет

`created`, где он есть, может не совпадать с датой в имени файла: запись сделана в другой день, чем описывает (`2025-01-14 Tuesday.md` несёт `2025-05-02`), и подгонять его под имя нельзя

## Структура

````markdown
# <Тема дня>
> Сегодня я <обобщающая вводка дня — что было, как самочувствие, какое настроение>

## <H2 — первая тема дня>
Поток мыслей. Можно с [[wiki-ссылками]] на людей через ядра, на смежные заметки

> [!tip] <короткая мысль или вывод>
> Развёрнутый комментарий

## <H2 — следующая тема>
...

---

# Media Dump
```media-gallery
columns: 2
type: vertical
-
```
---
# Things Dump
````

`# Media Dump` и `# Things Dump` после `---` — стандартные хвостовые секции из шаблона

## Заголовок дня

- `# ...` — нормально, если дня без явной темы
- `# Тема дня` — если что-то задало настрой ("Шум и скука", "Глупые действия", "...")

## Цитата-вводка

После H1 — блок `>` (без callout-типа) с обобщением дня. Это вместо классического "Dear diary" — сухое перечисление событий и общее настроение:

```markdown
> Сегодня я поздно проснулся. Встал разбитым. Сдали с горем пополам контрольную, потом сел играть в Crossout и совершил пару действий, о которых хотел бы порассуждать
```

## Callout-ы в дневнике

Полная справка по типам — `references/callouts.md`. В дневнике — так:

| Callout | Когда |
|---|---|
| `[!tip]` | мысль, осознание, что-то понял ("в прошлый раз я бы..., а сейчас...") |
| `[!important]` | важная мысль/реплика, особенно от кого-то значимого ("[[Женя]] сказал, почему не пользуется ИИ-агентами") |
| `[!question]` | риторический вопрос к себе ("Совершал ли ты действия, о которых жалел?") |
| `[!question]-` | свёрнутый — для разбора "что именно произошло" под спойлером, когда основной поток рассуждений выше |
| `[!fail]` / `[!failure]` | самокритика, признание ошибки ("у меня это происходит постоянно") |
| `[!faq]` | "а что если..." — гипотезы, развилки рассуждений |
| `[!bug]` | отметка косяка, странной детали ситуации |
| `[!success]` | когда что-то получилось, или признание правильного действия |
| `[!summary]` / `[!warning]` | реже, но возможны |
| `[!quote]` | прямая цитата кого-то значимого |

### Эскалация callout

В дневнике — мощный приём. Каскад одинаковых типов передаёт нарастающее переживание, и глубина вложенности тут может доходить до трёх уровней и дальше:

```markdown
> [!fail] У меня это происходит постоянно
> И когда я думаю в первое время...
> > [!fail] И вот у тебя уже "новая веха эволюции"
> > Но ты *снова* идёшь наперекор...
> > > [!fail] И еще хуже, когда после прогиба собственной осознанности...
> > > И ты делаешь еще хуже. Хуже. Хуже...
```

## Wiki-ссылки на людей и проекты

Через ядра (`~/myWiki/03. Записки/02. Ядра/`). Используй подпись для разговорного имени:

```markdown
с [[Леонид Митрофанов|Леней]] и [[Уфаев Евгений Сергеевич|Женей]]
оцифровал [[Лекция 01. Введение, основные понятия|лекции по БЖД]]
```

В дневнике это особенно важно — благодаря этому ядра обрастают входящими ссылками и становятся живыми хабами

## HTML-эффекты и эмодзи в дневнике 🌈

Полная справка — `references/html-effects.md`. В дневнике — **свободно**, это и есть "цветные ручки" живой тетради. Конкретные паттерны использования:

- `neon-sign-text` — крик, громкая мысль, риторический возглас:
  ```html
  <span class="neon-sign-text">Возможна ли революция, где участниками будет бизнес?</span>
  ```
- `tv-glitch-full tv-static` — срыв, нецензурное, "пробой реальности":
  ```html
  Это <span class="tv-glitch-full tv-static">стрёмно</span>
  ```
- `tv-glitch` — глитчевый акцент с `data-text`
- `rainbow-text` — игривый акцент
- Эмодзи в конце смысловых блоков: 🫥🫥, 😏, 🥶, :-), `(¬д¬。)`, `(;¬_¬)`

## Поток сознания — нормально

Дневник — не отчёт. Если мысль скачет — пусть скачет. Если нужно повторить слово десять раз для эмоционального эффекта — повтори:

```markdown
И ты делаешь еще хуже. Хуже. Хуже. Хуже. Хуже. Хуже. Хуже. Хуже...
Не понимаю
Не понимаю
Не понимаю
Не понимаю
```

## Мат и грубость

Допустимо как эмоциональный пик, не как фон. Хорошо — один-два сильных слова в моменте срыва. Плохо — мат через слово

## Скрытие личного через `%%`

`%%текст%%` прячет фрагмент из reading view, но не из исходника — используется в дневнике для того, что слишком личное для обычного чтения (не для служебных пометок себе, для них — обычный текст или `[!todo]`). Синтаксис — `obsidian-markdown`

## Подведение и принятие

В конце большого блока самокритики часто идёт:
- `### СТОП` — буквальное остановиться, дальше принятие
- Разбор "что было хорошего" / "что извлечь" / "как поступить в будущем"
- Подзаголовки с конкретными уроками: `#### Прислушиваться внутреннему голосу`, `#### Плохая покупка?`

## Хвост дня

````markdown
---

# Media Dump
```media-gallery
columns: 2
type: vertical
-
```
---
# Things Dump
````

- Media Dump — для скриншотов и медиа дня (заполняется в течение дня через media-gallery плагин)
- Things Dump — для свободных заметок, которые не сложились в блок выше

Медиафайлы для daily кладутся в **локальную** `~/myWiki/03. Записки/01. Дневник/01. Daily/00. Вложения/` (и аналогично для weekly/monthly/...). Не в корневую `~/myWiki/00. Вложения/01. Gallery/` — туда идёт только материал, не привязанный к конкретной заметке

## Периодические заметки (weekly / monthly / quarterly / yearly)

В `~/myWiki/03. Записки/01. Дневник/` параллельно daily лежат:
- `02. Weekly/` — `YYYY-Week ww.md`
- `03. Monthly/` (если есть) — `YYYY-MM.md`
- `04. Quarterly/` (если есть) — `YYYY-QN.md`
- `05. Yearly/` — `YYYY.md`

### Общий шаблон

````yaml
---
tags:
mark:                                  # субъективная оценка периода
created: <начало периода>
neighbours:
  - "[[предыдущий период]]"
  - "[[следующий период]]"
mood music:
---
# ...

---

# Media Dump
```media-gallery
columns: 2
type: vertical
-
```
````

Отличия от daily:
- Нет `sleep hours` и `weight` — это посуточные метрики
- `mark` — оценка всего периода
- `Things Dump` обычно опускается — итог периода это уже консолидация
- В теле — рефлексия за период, ключевые события, выводы. Активные wiki-ссылки на daily-заметки, которые в этот период вошли

### Тон периодических заметок

Чуть собраннее чем daily, но не строже. Тут уместно делать выводы, ставить акценты, выделять самое важное из потока ежедневок
