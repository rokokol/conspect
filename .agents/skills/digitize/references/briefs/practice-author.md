## Задачи — раздел `## Задачи`

- В конце заметки-получателя (после всей теории, перед `# Вне курса`, если он есть) — раздел `## Задачи`. В нём каждая задача — свёрнутый callout, порядок — по ходу темы, от простых к сложным, а не по страницам:

  ```markdown
  > [!example]- Задача 51. $xy\,dx+(x+1)\,dy=0$
  > Разделяем переменные, деля на $y(x+1)$:
  > $$\frac{dy}{y}=-\frac{x\,dx}{x+1}\implies\ln|y|=-x+\ln|x+1|+\ln|C|$$
  > **Ответ:** $y=C(x+1)e^{-x}$; [[Уравнения с разделяющимися переменными#^lost-solutions|потерянное]] решение $x=-1$
  ```

  Титул — "Задача N." и условие формулой, вместе с начальными или краевыми условиями. Внутри — ключевые шаги многострочно (замена, к чему свелось, интегрирование, константы), не каждое тождественное преобразование, и строка `**Ответ:**`. Метод назван ссылкой на раздел теории этой же заметки — с полным именем файла, как требует lint (`[[Линейные уравнения первого порядка#Уравнение Бернулли|Бернулли]]`), — или другой заметки
- Берёшь все задачи своего блока из `map.md`. Оборванную или частично решённую задачу дорешай. Задачу, которую тетрадь решает дважды, пиши один раз
- Каждый ответ проверь сам до записи: подстановкой в уравнение (`sympy.checkodesol` или `simplify` невязки), для задачи Коши — и начальных условий, для типа особой точки — собственными числами и векторами. Окружение: `~/.cache/diffury-digitization/.venv/bin/python`. Скрипты проверки — в scratchpad. В заметке не пиши, как проверял
- Ошибки тетради (знак, коэффициент, константа, неверный ответ, неверный тип точки, неверная область) исправляй молча: в заметке только верное решение. Перечисли их в отчёте для верификатора
- "Особыми" тетрадь зовёт и решения, потерянные при делении. "Потерянное" — название по происхождению: решение, теряемое при делении (ссылка выше), даже если в выбранной записи общего интеграла оно входит при $C=0$ — тогда так и скажи ("потерянное решение $y=0$ входит при $C=0$"); "особое решение" (`[[Особые решения|особое решение]]`) — только если в каждой его точке его касается другое решение. Проверь по определению, а не по слову тетради
- Если задача совпадает с примером из лекционной заметки (583 — в "Преобразование Лапласа", 786 — в "Матричная экспонента…"), всё равно пиши её и добавь в callout строку-ссылку на тот пример
- Пометки на полях (эмоции, мат, рисунки-шутки, "Д/З", "очевидно крч") в заметку не идут. Номер ДЗ не пишется

## Frontmatter

- Существующая заметка: добавь в `lectures` последним элементом `"С"`, в `sources` — по строке на каждую страницу практики, откуда что-то взято: `"[[00. Вложения/practice/p31.jpg|Практика — понижение порядка, задача 421]]"`, в `tags` — `стехина`. `title`, `up`, `prev`, `next`, `order` не трогай

  ```yaml

  created: 2026-10-19
  summary: <одно предложение>

    - кфу
  ```

  Имя MOC темы бери из корня курса (`ls`). `order` не ставь — его проставит сессия
