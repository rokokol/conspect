# Исходники рисунков курса "Биология поведения"

Тема ddlc и шрифты волта приходят из общего набора `Scripts/ddlc_figures/`, его на `sys.path` ставит `course.py`, он же задаёт корень курса

| Скрипт | Рисунки |
| --- | --- |
| `chemotaxis.py` | `Стратегии хемотаксиса — расстояние до источника.png`, `Стратегии хемотаксиса — три агента.gif` |

Остальные рисунки курса (модель прокрастинации) сделаны в мае 2026, их скрипты не сохранились, и они пока в старой теме

## Запуск

Окружение — venv курса "Тренировки по ML" с закреплёнными версиями, его `.sources/README.md` говорит, как его собрать

```bash
~/.cache/ml-trainings-digitization/.venv/bin/python chemotaxis.py
```
