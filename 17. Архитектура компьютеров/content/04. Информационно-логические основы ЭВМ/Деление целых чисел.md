# Деление целых чисел

Деление целых чисел в [[Электронно-вычислительная машина|ЭВМ]] реализуется через вычитание и сдвиг. Вычитание — это [[Прямой, обратный и дополнительный код#Сложение и вычитание в дополнительном коде|сложение с отрицательным числом в дополнительном коде]], сдвиг — операция [[Регистры#Последовательный регистр|сдвигового регистра]], так что деление опирается на те же аппаратные операции, что и [[Умножение целых чисел|умножение]]

## От деления столбиком к вычитаниям

Столбиком из делимого вычитают делитель и смотрят, помещается ли он или нужно "занять" следующий разряд; последовательность вычитаний приводит к остатку. Если остаток нулевой, делимое кратно делителю, иначе результат — целая часть и остаток, меньший делителя. В двоичной системе вариантов меньше: очередная цифра частного — 0 или 1, делитель либо помещается, либо нет

> [!note] Деление — последовательное вычитание делителя из делимого до получения наименьшего положительного остатка
> $A$ — **делимое**, $B$ — **делитель**, $C$ — **частное**. Алгоритмов два: **с восстановлением остатка** и **без восстановления остатка**

## Условие $|A|<|B|$

Для деления двоичных чисел нужно, чтобы выполнялось $|A|<|B|$, иначе уже на первом шаге, после первого вычитания, возникает переполнение разрядной сетки. Условие записано для чисел, выровненных как дроби: частное $A/B<1$, и его разряд целой части обязан быть нулём

Если делимое по модулю больше делителя, делитель предварительно **сдвигают влево**, пока условие не выполнится. Сдвиг делителя на $k$ разрядов делает частное в $2^k$ раз меньше, поэтому в конце результат возвращают к исходной значимости: $C$ читается как целое, а остаток сдвигается на те же $k$ разрядов вправо[^ovf-cond]

[^ovf-cond]: Та же проверка у B. Parhami для деления $2k$-разрядного делимого $z$ на $k$-разрядный делитель $d$: переполнения нет, если старшая половина делимого меньше делителя, "No overflow, because $(0111)_{two}<(1010)_{two}$" — [Computer Arithmetic, слайды к гл. 13, "Example of Restoring Unsigned Division"](https://web.ece.ucsb.edu/~parhami/pres_folder/f31-book-arith-pres-pt4.pdf)

## Деление с восстановлением остатка

$$
A_i=A_{i-1}-B\cdot2^{-i}
$$

- $A_i\geqslant0$ — разряд частного $C_i=1$, переход к следующему шагу
- $A_i<0$ — $C_i=0$, и остаток **восстанавливается**: $A_{i-1}=A_i+B\cdot2^{-i}$

Множитель $2^{-i}$ — не рекурсивное деление внутри деления: умножение на $2^{-1}$, как и умножение на $2$, — это сдвиг, только вправо. $B\cdot2^{-i}$ — делитель, сдвинутый на $i$ разрядов вправо. На практике вместо сдвига делителя вправо остаток сдвигают влево — это то же соотношение, умноженное на $2^i$: $R_i=2R_{i-1}-B$, где $R_i=2^iA_i$

### Пример $48:9$

$A=48_{10}=110000_2$, $B=9_{10}=1001_2$, $-B=1\,0111_2$ в дополнительном коде со знаковым разрядом. Регистр 8 разрядов, разряд 7 — знак. Выписанный в разрядах 6–3 делитель равен $9\cdot2^3=72>48$ — условие выполнено сдвигом на $k=3$, и шагов $k+1=4$. Оба операнда положительны, их прямой код совпадает с дополнительным

| Действие | 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 | $C$ |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Исходное состояние | 0 | 0 | 1 | 1 | 0 | 0 | 0 | 0 | 0000 |
| $-B$ | 1 | 0 | 1 | 1 | 1 |  |  |  |  |
| Остаток $<0$ | **1** | 1 | 1 | 0 | 1 | 0 | 0 | 0 | 000**0** |
| Восстановление ($+B$) | 0 | 1 | 0 | 0 | 1 |  |  |  |  |
| Восстановленный остаток | 0 | 0 | 1 | 1 | 0 | 0 | 0 | 0 |  |
| Сдвиг | 0 | 1 | 1 | 0 | 0 | 0 | 0 | 0 |  |
| $-B$ | 1 | 0 | 1 | 1 | 1 |  |  |  |  |
| Остаток $\geqslant0$ | **0** | 0 | 0 | 1 | 1 | 0 | 0 | 0 | 00**01** |
| Сдвиг | 0 | 0 | 1 | 1 | 0 | 0 | 0 | 0 |  |
| $-B$ | 1 | 0 | 1 | 1 | 1 |  |  |  |  |
| Остаток $<0$ | **1** | 1 | 1 | 0 | 1 | 0 | 0 | 0 | 0**010** |
| Восстановление | 0 | 0 | 1 | 1 | 0 | 0 | 0 | 0 |  |
| Сдвиг | 0 | 1 | 1 | 0 | 0 | 0 | 0 | 0 |  |
| $-B$ | 1 | 0 | 1 | 1 | 1 | 0 | 0 | 0 |  |
| Остаток $\geqslant0$ | **0** | 0 | 0 | 1 | 1 | 0 | 0 | 0 | **0101** |

Сложение идёт по разрядам 7–3, перенос из разряда 7 отбрасывается: например, $01100+10111=1\,00011$. Знак остатка определяет очередной разряд частного, который вдвигается в $C$ справа. В строке второго восстановления на слайде сразу записан его результат

В регистре остался код $00011000$ — остаток, сдвинутый на $k=3$ разряда влево. Возвращаем значимость сдвигом вправо[^frac]:

$$
\boxed{C=0101_2=5_{10},\qquad R=00011_2=3_{10}},\qquad 48=5\cdot9+3
$$

[^frac]: Лектор (запись 25.11.2024) называет разряды, оставшиеся в регистре, дробной частью результата деления, а затем нормализует их в остаток. Это не дробная часть частного ($48/9=5.333\ldots$, дробная часть $0.333\ldots$), а остаток $R$, умноженный на $2^k$: $00011000_2=24=3\cdot2^3$

## Деление без восстановления остатка

Восстановление — лишнее сложение на каждом отрицательном остатке. Без восстановления отрицательный остаток оставляют как есть, а на следующем шаге не вычитают, а **прибавляют** делитель: знак предыдущего остатка выбирает между $-B$ и $+B$, и каждый шаг — ровно одно сложение

$$
R_i=\begin{cases}2R_{i-1}-B, & R_{i-1}\geqslant0\\ 2R_{i-1}+B, & R_{i-1}<0\end{cases}\qquad C_i=\begin{cases}1, & R_i\geqslant0\\ 0, & R_i<0\end{cases}
$$

Результат тот же: восстановление с последующим вычитанием даёт $2(R+B)-B=2R+B$, а это и есть одно прибавление $B$ к сдвинутому отрицательному остатку. Если последний остаток отрицателен, его один раз корректируют: $R+B$[^nonrest]

[^nonrest]: Лектор (запись 25.11.2024) говорит, что к отрицательному остатку нужно прибавить минус $B$. К отрицательному остатку прибавляют $+B$, а $-B$ — к положительному. Обоснование и финальная коррекция — B. Parhami, [Computer Arithmetic, слайды к гл. 13, "Justification for Nonrestoring Division" и "Quotient Conversion and Final Correction"](https://web.ece.ucsb.edu/~parhami/pres_folder/f31-book-arith-pres-pt4.pdf): "Keep the incorrect partial remainder $u-2^kd$, shift left, and add to get $2(u-2^kd)+2^kd=2u-2^kd$"; "Final correction step if sign(s) ≠ sign(z): Add d to, or subtract d from, s"

От восстановления алгоритм отличается только тем, что на анализ и сравнение уходит меньше времени, поэтому реализация эффективнее
