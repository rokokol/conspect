# Модули и адресация оперативной памяти

## Модуль и банк памяти

![[Архитектура компьютеров Мосин.pdf#page=299&rect=209,13,606,205|380]]

> [!note] **Модуль памяти** — микросхема [[Характеристики ЗУ и типы ПЗУ|ЗУ]] или совокупность микросхем, обеспечивающая разрядность слова, которую требуют тип и архитектура процессора. Один или несколько модулей образуют **банк памяти**
> Модуль отвечает за длину слова: $n$ микросхем [[Третье поколение ЭВМ|ИС]] ЗУ$_0$…ИС ЗУ$_{n-1}$ с общими адресом $A_0$…$A_m$ и сигналами $\overline{CS}$, $\overline{WR}$ дают по разряду $D_0$…$D_{n-1}$ — как [[SRAM и DRAM#Слово из запоминающих элементов|слово из ЗЭ]], только на уровне микросхем. Банк отвечает за число слов

## Структура микросхемы памяти

![[Архитектура компьютеров Мосин.pdf#page=300&rect=269,12,711,338|440]]

Внутри микросхема — трёхмерная матричная структура: каждая матрица ЗЭ хранит один разряд слова, и для $N$-разрядного слова в микросхеме $N$ матриц

На схеме матрица $2048\times 2048=2^{22}$ ЗЭ, т.е. 4 Мбит, а матриц четыре — по числу линий данных $D_0$…$D_3$: микросхема хранит $2^{22}$ четырёхразрядных слов, 16 Мбит[^micron-4x4]

Адрес ячейки — $\log_2 2^{22}=22$ разряда, но выводов адреса у микросхемы только 11, $A_0$…$A_{10}$: адрес подаётся в два шага по тем же выводам — сначала 11 разрядов номера строки в буфер адреса строки, затем 11 разрядов номера столбца в буфер адреса столбца

Шина адреса вдвое уже, а 22-разрядная шина расширила бы корпус и разводку. Строку выбирает дешифратор строки, столбец — дешифратор столбца, данные проходят через усилители чтения-записи и входной и выходной буферы данных

| Сигнал | Расшифровка | Назначение |
| --- | --- | --- |
| **RAS** | Row Address Strobe[^ras-cas] | Строб адреса строки: защёлкивает номер строки |
| **CAS** | Column Address Strobe | Строб адреса столбца: защёлкивает номер столбца |
| **WE** | Write Enable | Разрешение записи |
| **OE** | Output Enable | Разрешение чтения — выдачи данных на выход |
| **CS** | Chip Select | Разрешение работы микросхемы; без него микросхема не реагирует на обращения |

Черта над обозначением на схеме — активный низкий уровень

[^micron-4x4]: Такую же организацию имеет, например, Micron MT4LC4M4E8 — "16,777,216 bits organized in a x4 configuration", "11 row, 11 column addresses (2K refresh)" — [Micron, 4 MEG x 4 EDO DRAM datasheet, rev. 6/98](http://vigir.missouri.edu/~gdesouza/ece4270/Manuals/DRAM.pdf)

[^ras-cas]: В записях 17.12 и 23.12.2024 RAS и CAS расшифрованы как "row access signal" и "column access signal", а CS — как "crystal select". Принятые расшифровки — row address strobe и column address strobe: "A clock signal row address strobe (RAS) strobes in a row address and then, on the same set of address pins, a clock signal column address strobe (CAS) strobes in a column address at a different time" — B. Keeth, R. J. Baker, [DRAM Circuit Design: A Tutorial, IEEE Press, 2001, Chapter 1](https://catalogimages.wiley.com/images/db/pdf/0780360141.excerpt.pdf); CS# — "Chip select" — [Micron, 256Mb SDRAM datasheet, Rev. W 05/15](https://www.alliancememory.com/wp-content/uploads/Micron_256M_SDRAM_PartNo.MT48LC16M16A2.pdf), Table 4

## Распределение адресов между банками

Одна микросхема не может расти бесконечно, поэтому нужный объём [[Иерархия памяти|ОП]] набирают из нескольких банков меньшей ёмкости — на планке просто ставят больше микросхем. При $N$ банках адрес слова $A$ преобразуют в пару $(n,\ a)$: $n$ — номер банка, $a$ — адрес ячейки внутри банка. Способ распределить разряды адреса между $n$ и $a$ — одна из трёх схем

Все примеры на слайдах: ОП из 1024 слов, адрес $A_9$…$A_0$, четыре банка по 256 слов

### Блочная схема

![[Архитектура компьютеров Мосин.pdf#page=303&rect=170,22,614,229|420]]

Адресное пространство разбито на группы последовательных адресов, каждую группу обслуживает свой банк. Старшие разряды $A_9A_8$ через дешифратор выбирают банк, младшие $A_7$…$A_0$ — ячейку в нём

| Банк | Адреса |
| --- | --- |
| 0 | 0–255 |
| 1 | 256–511 |
| 2 | 512–767 |
| 3 | 768–1023 |

Схема простая и исторически основная для наращивания объёма, но **не позволяет группового чтения**: соседние адреса лежат в одном банке, и пока не завершено чтение одного слова, следующее из того же банка не прочитать, иначе возникнет конфликт за ресурс — тот же [[Конвейер команд#Три вида рисков (конфликтов)|структурный риск]]. А программа — последовательность команд, расположенных рядом, и читать её выгодно сразу большими порциями

### Циклическая схема расслоения

![[Архитектура компьютеров Мосин.pdf#page=304&rect=258,7,665,293|400]]

Адреса чередуются между банками: 0, 1, 2, 3 — по одному в каждый банк, затем 4, 5, 6, 7 и так далее

$$n=A\bmod N,\qquad a=A\operatorname{div}N$$

Младшие разряды $A_1A_0$ выбирают банк, старшие $A_9$…$A_2$ — ячейку

| Банк | Адреса |
| --- | --- |
| 0 | 0, 4, 8, …, 1020 |
| 1 | 1, 5, 9, …, 1021 |
| 2 | 2, 6, 10, …, 1022 |
| 3 | 3, 7, 11, …, 1023 |

> [!success] Групповое чтение: за одно обращение читается блок из $K$ слов, где $K$ — число банков
> Последовательные слова лежат в одной и той же строке разных, физически независимых банков. Адрес строки $A_9$…$A_2$ заносится в регистры адреса РгА всех банков сразу, строка читается во всех банках параллельно, слова попадают в буферные регистры данных РгД и уходят на шину данных через мультиплексор

Недостаток — наращивать объём сложно: добавление банка меняет модуль $N$ и перераспределяет все адреса

### Блочно-циклическая схема

Каждый банк состоит из нескольких модулей: внутри банка адреса распределены между модулями по циклической схеме, между банками — по блочной. Адрес состоит из трёх полей — номер банка, номер модуля, адрес ячейки в модуле

| Банк | Модуль 0 | Модуль 1 |
| --- | --- | --- |
| 0 | 0, 2, …, 254 | 1, 3, …, 255 |
| 1 | 256, 258, …, 510 | 257, 259, …, 511 |
| 2 | 512, 514, …, 766 | 513, 515, …, 767 |
| 3 | 768, 770, …, 1022 | 769, 771, …, 1023 |

Разряды: $A_9A_8$ — банк, $A_0$ — модуль, $A_7$…$A_1$ — ячейка в модуле. Объём наращивается добавлением банков, как в блочной схеме, а внутри банка сохраняется групповое чтение из его модулей

> [!example] Адрес 679 в трёх схемах
> $679=1010100111_2$
>
> | Схема | Поля | Результат | Проверка |
> | --- | --- | --- | --- |
> | Блочная | $\underbrace{10}_{n}\ \underbrace{10100111}_{a}$ | банк 2, ячейка 167 | $512+167=679$ |
> | Циклическая | $\underbrace{10101001}_{a}\ \underbrace{11}_{n}$ | банк 3, ячейка 169 | $679=4\cdot 169+3$ |
> | Блочно-циклическая | $\underbrace{10}_{\text{банк}}\ \underbrace{1010011}_{\text{ячейка}}\ \underbrace{1}_{\text{модуль}}$ | банк 2, модуль 1, ячейка 83 | $513+2\cdot 83=679$ |
>
> В циклической схеме адреса 676–679 — одна строка 169 во всех четырёх банках, и все четыре слова читаются за одно обращение

Разрядность адреса во всех трёх схемах одна и та же — 10 бит на 1024 слова: схема меняет только то, какие разряды что выбирают[^addr-width]

[^addr-width]: В записи 17.12.2024 о блочно-циклической схеме сказано, что три поля "банк, модуль, слово" в итоге имеют меньшую длину разрядов, необходимую для идентификации каждого элемента. Для одного и того же числа слов длина адреса не зависит от схемы: $2+1+7=10$ разрядов, как $2+8$ в блочной и циклической — это видно из разрядов на стр. 303–305
